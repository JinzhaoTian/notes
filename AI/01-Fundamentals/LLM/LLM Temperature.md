大模型的 temperature（温度）是控制生成结果“随机性/创造性”的一个采样参数，它通常用在生成文本时，对模型输出的概率分布进行调节。
## 原理

大模型在预测下一个 token 时，会先输出一组原始分数，叫 **logits**。然后通过 softmax 把这些 logits 转换成概率分布：

$$
p_i = \frac{\exp(z_i / T)}{\sum_j \exp(z_j / T)}
$$

其中：
- $z_i$：第 $i$ 个 token 的 logits
- $T$：temperature
- $p_i$：第 $i$ 个 token 被选中的概率

## 影响

| 温度值                | 效果                            | 适用场景           |
| ------------------ | ----------------------------- | -------------- |
| $T < 1$，例如 0.2     | 概率分布更尖锐，高概率词更容易被选中，输出更确定、保守   | 代码生成、事实问答、翻译   |
| $T = 1$            | 原始 softmax 分布，不调整             | 默认生成           |
| $T > 1$，例如 1.2、1.5 | 概率分布更平坦，低概率词也有机会被选中，输出更多样、有创意 | 创意写作、头脑风暴、生成灵感 |

简单理解：

- **温度越低，模型越“保守”**，倾向选择它认为最可能的词。
- **温度越高，模型越“冒险”**，更容易输出意想不到的内容，但也可能更不稳定、跑题或出现废话。

## 举例

假设模型对下一个词的 logits 是：

- “猫”：2.0
- “狗”：1.0
- “鱼”：0.5

当 temperature 很低时，模型几乎总是选“猫”。  
当 temperature 很高时，“狗”“鱼”被选中的概率会明显上升，输出更多样。

## 实际使用建议

- 需要稳定、准确：temperature 设低，例如 0.0～0.3  
- 需要平衡：0.7～1.0  
- 需要创意、发散：1.0～1.5，甚至更高

注意：temperature 通常与 **top-p、top-k** 等参数一起使用。temperature 改变整个概率分布，而 top-p/top-k 是限制候选 token 的范围。实际生成时，可以组合调参。
