Hermes Agent 是一个能够**自我进化**的开源 AI 智能体框架。简单来说，它就像一位住在你服务器里的数字实习生，不仅能执行任务，更能**从每一次任务中吸取经验，不断成长，变得越来越懂你的需求**。

## 核心特点

1. **自我进化，越用越聪明**：这是 Hermes Agent 最大的亮点。不同于每次对话都"失忆"的传统 AI，Hermes 在执行完任务后，会自动把解决问题的有效步骤提炼成一个可复用的 **"技能"**（Skill）。下次遇到类似任务时，它就能直接调用，无需从头开始，真正做到与你共同成长。
2. **超强记忆，跨平台同步**：Hermes 拥有一个分层的持久化记忆系统，它能记住你的偏好、项目背景甚至 API 密钥。更重要的是，这些记忆是跨平台的，无论你在终端、网页、Telegram 还是微信上使用，Hermes 都能保持连贯的上下文，无缝衔接你的任务。
3. **低成本高灵活**：Hermes 的设计非常注重成本控制。它支持动态路由，可以根据任务复杂程度自动选择使用高性能大模型或便宜的小模型。官方甚至表示，你可以在每月仅5美元的廉价服务器上让它7x24小时运行，或在闲置时自动休眠，有效控制 Token 消耗。
4. **专为自动化而生**：Hermes 的目标是成为能真正干活的自主智能体，而非简单的聊天工具。它可以调度子代理并行处理任务，执行定时计划（如每天早上自动生成日报并发送），甚至通过 CDP 协议操作 Chrome 浏览器，完成复杂的网页操作。
