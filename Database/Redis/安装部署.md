官网：[Redis](https://redis.io/)


## 使用


### 文件

1. `redis-server` - redis服务器
2. `redis-cli` - redis命令行客户端
3. `redis-benchmark` - redis性能测试工具
4. `redis-check-aof` - aof文件修复工具
5. `redis-check-dump` - rdb文件检查工具

### 命令

1. 命令行进入：
```
redis-cli
```

2. 设置密码，首先进入命令行模式，然后输入命令：
```
config set requirepass 123456
```
或者修改配置文件，找到 `redis.conf` （Windows 下或许为 `redis.windows.config`），找到 `requirepass` 字段，取消注释进行修改。

默认配置文件是 `redis.config`，更改到 `redis.windows.config` 需要在启动redis-server时显式给出。

下次登录时可以选择带密码登录：
```
redis-cli -a 123456
```
或者连接上再输入密码：
```
redis-cli
auth 123456
```



3. 停止 redis
```
redis-cli shutdown
```

4. 启动 redis，设置配置文件，并后台启动：
```
redis-server [./redis.conf] --daemonize yes
```


5. 安装为 Windows 服务：
```
redis-server --service-install redis.windows.conf
```

- 开启服务：`redis-server --service-start`
- 卸载服务：`redis-server --service-uninstall`
- 停止服务：`redis-server --service-stop`





## Docker

DockerHub 上直接获取 Redis 镜像，[redis - Official Image | Docker Hub](https://hub.docker.com/_/redis)。

![](imgs/Pasted%20image%2020240223151901.png)

然后运行命令：
```
$ docker run --name some-redis -p 6379:6379 -d redis
```

或者使用 `docker-compose.yml` 进行配置：
```yaml
version: '3.8'
services:
  cache:
    image: redis:6.2-alpine
    restart: always
    ports:
      - '6379:6379'
    command: redis-server --save 20 1 --loglevel warning --requirepass eYVX7EwVmmxKPCDmwMtyKVge8oLd2t81
    volumes: 
      - cache:/data
volumes:
  cache:
    driver: local
```

## Windows

Redis 官方不建议在 windows 下使用 Redis，所以官网没有 windows 版本可以下载。还好微软团队维护了开源的 windows 版本，地址：[Releases · microsoftarchive/redis (github.com)](https://github.com/MicrosoftArchive/redis/releases)。
![](imgs/Pasted%20image%2020240223151529.png)
下载 msi 版本，下载完成后双击进行安装。


同样，还有开源版本：[Releases · tporadowski/redis (github.com)](https://github.com/tporadowski/redis/releases)。安装完成之后，可以将路径添加到环境变量中，`C:\Program Files\Redis`。


### WSL

此外，可以首先安装 WSL2，然后像 Linux 下面安装 Redis 一样。



## Linux

```bash
curl -fsSL https://packages.redis.io/gpg | sudo gpg --dearmor -o /usr/share/keyrings/redis-archive-keyring.gpg

echo "deb [signed-by=/usr/share/keyrings/redis-archive-keyring.gpg] https://packages.redis.io/deb $(lsb_release -cs) main" | sudo tee /etc/apt/sources.list.d/redis.list

sudo apt-get update
sudo apt-get install redis
```
