Redis 是 key-value 结构的，有五种基础的数据结构：

1. 字符串（`string`）
2. 列表（`list`）
3. 集合（`set`）
4. 有序集合（`zset`，sorted set）
5. 哈希（`hash`）

其中 key 值应该是就是一个名字，指定为字符类型，其中 `list`、`hash`、`set`、`zset` 称为容器型数据结构，容器型数据结构有两条通用规则：
- 如果容器不存在，就创建一个，再进行操作。
- 如果容器里没有数据了，就立即删除，回收内存。

### `string`

`string` 是 Redis 最简单的数据结构，一个 key 对应一个 `string` 类型的 value 。Redis 的 `string` 实际上是使用数组实现的。

基本指令：
- **SET**：设置一个 key-value 对，示例：`SET name lily`
- **GET**：获取一个 key 对应的的 value，示例：`GET name`
- **MSET**：设置一个或多个 key-value 对，示例：`MSET name lily age 18`
- **MGET**：获取一个或多个 key 对应的 value，示例：`MGET name age`
- **SETNX**：设置一个 key-value 对，如果该 key 不存在，设置成功；如果 key 存在，设置失败，示例：`SETNX name lilei`
- **INCR**：如果 value 是整数，还可以进行原子加一操作，示例：`INCR age`
- **DECR**：如果 value 是整数，还可以进行原子减一操作，示例：`DECR age`

### list

​Redis 的 list 是链表实现的，所以其插入删除操作非常快，时间复杂度都是 O(1) ，但是索引定位很慢，时间复杂度是 O(n) 。当 list 中没有元素了，该数据结构会自动删除，内存被回收。

基本指令：
- **LPUSH**：从左边插入元素，可以插入多个。示例：`LPUSH students lily lilei zhangsan`
- **LPOP**：从左边删除元素，默认删除一个元素，可指定需要删除的个数，示例：`LPOP students 5`
- **RPUSH**：从右边插入元素，用法同 LPUSH。
- **RPOP**：从右边删除元素，用法同 LPOP。
- **LRANGE**：列出指定范围里的元素（不会删除元素），示例：`LRANGE students 0 -1`
- **LINDEX**：O(n)，获取指定位置的元素，示例：`LINDEX students 1`
- **LTRIM**：O(n)，删除指定范围的元素，示例：`LTRIM students 1 2`

### hash

Redis 的 hash 的值只能是字符串。

基本指令：
- **HMSET**：写入数据，支持批量。示例： `HMSET 001 name lily age 18`，其中 001 是该条hash的key，name、age 是 hash 里面的 field。
- **HMGET**：获取指定 hash 的某个 field 的 value。示例：`HMGET 001 name`
- **HGETALL**：获取指定 hash 的所有数据。示例：`HGETALL 001`
- **HINCRBY** ：如果 hash 内部的 value 是整型，可以使用 HINCRBY 进行原子加减操作（只需讲操作数设置为负数就是减法操作），示例：`HINCRBY 001 age 1`，`HINCRBY 001 age -1`


### set

Redis 的 set 是无序的。

基本指令：
- **SADD**：加入集合。示例：`SADD students lily lilei`
- **SMEMBERS**：列出集合内成员。示例：`SMEMBERS students`
- **SISMEMBER**：查询某个成员是否存在。示例：`SISMEMBER students lily`
- **SREM**：删除某个成员。示例：`SREM students lily`
- **SCARD**：获取集合长度。示例：`SCARD students`
- **SPOP**：弹出成员，可以指定需要弹出的个数（不知道默认是1）。示例：`SPOP students 5`

### `zset`

Redis 的 `zset` 是一个很有特色的数据结构，一方面它是一个 set，保证了内部 value 的唯一性，另一方面它可以给每个 value 赋予一个 score，代表这个 value 的排序权重。它的内部实现采用的是跳跃列表（skiplist）。

基本指令：
- **ZADD**：增加成员。示例：`ZADD students 95 lily 85 lilei 70 zhangsan 55 lisi`
- **ZRANGE**：正序获取指定个数的成员。示例：`ZRANGE students 0 -1`
- **ZREVRANGE**：倒序获取指定个数的成员。示例：`ZREVRANGE statuents 0 -1`
- **ZRANGEBYSCORE**：根据score范围获取成员，正序排列。示例：`ZRANGEBYSCORE students 0 60`
- **ZREVRANGEBYSCORE**：根据score范围获取成员，倒叙排列。示例：`ZREVRANGEBYSCORE students 100 0`
- **ZREM**：删除指定成员。示例：`ZREM students zhangsan`
- **ZREMRANGEBYSCORE** ：按score范围删除成员。示例：`ZREMRANGEBYSCORE students 0 60`
- **ZSCORE**：获取成员score。示例：`ZSCORE students lilei`
- **ZCARD**：获取zset长度。示例：`ZCARD students`


## 动态字符串

https://mp.weixin.qq.com/s/-2mHYS_xQKWg5XMmrlRx1Q

动态字符串是一种能够动态扩展长度的字符串实现方式。在许多编程语言和数据结构中都有类似的实现，如C语言中的动态数组（dynamic array）。而SDS是Redis中的一种简单动态字符串结构，它是一种动态大小的字节数组，用于存储和操作字符串数据。SDS是Redis内部数据结构的基础，也是字符串数据结构的底层实现。它的结构如下：

```c
/*
 * redis中保存字符串对象的结构
 */
struct sdshdr {
    //用于记录buf数组中使用的字节的数目，和SDS存储的字符串的长度相等 
    int len;
    //用于记录buf数组中没有使用的字节的数目 
    int free;
    //字节数组，用于储存字符串
    char buf[]; //buf的大小等于len+free+1，其中多余的1个字节是用来存储’\0’的
};
```

在C语言中传统字符串是使用长度为N+1的字符数组来表示长度为 的字符串，并且字符串数组的最后一个元素总是空字符 `'\0'`。
