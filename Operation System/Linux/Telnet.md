Telnet 是一种用于远程登录和管理计算机的网络协议及其对应的命令行工具，允许用户通过命令行接口连接到远程主机，并在该主机上执行命令，就像在本地计算机上一样。

**特点**：
1. 远程访问：Telnet 允许用户远程访问和管理计算机系统，这在远程服务器管理和网络设备配置中非常有用。
2. 明文传输：Telnet 使用明文传输数据，这意味着数据（包括用户名和密码）在传输过程中未加密。因此，Telnet 通信很容易受到中间人攻击和窃听。
3. 简单的命令行接口：Telnet 使用一个简单的命令行接口，用户可以通过输入命令来与远程主机交互。
4. 端口号：Telnet 通常在端口 23 上运行。


### 用途

1. 测试端口开放：
```
telnet [目标主机名或IP地址] [端口号]
```
检查响应：
- 如果端口开放，Telnet 会尝试建立连接，你可能会看到一个空白的屏幕或一些响应内容，这表示连接成功。
- 如果端口关闭或被防火墙阻挡，你会看到一个连接失败的消息，例如“连接失败”或“无法打开连接到主机”，这表示目标端口未开放。
