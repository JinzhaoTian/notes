进程（Process）是操作系统中的一个核心概念，指的是**正在执行的程序实例**。它是系统进行资源分配和调度的基本单位，可以理解为程序的一次动态执行过程。

### 关键特性

1. **独立性**  
    - 每个进程拥有独立的地址空间、系统资源（如内存、文件句柄等）和运行状态。
    - 一个进程崩溃通常不会直接影响其他进程（通过进程间通信的除外）。

2. **动态性**  
    - 进程是“活”的，有生命周期（创建、运行、等待、终止等状态变化），而程序是“静态”的代码文件。

3. **并发性**  
    - 多个进程可以并发执行（通过CPU时间片轮转或多核并行），宏观上看似同时运行。

4. **资源分配单位**  
    - 操作系统为每个进程分配内存、CPU时间、I/O设备等资源。

### 进程的组成

一个进程通常包括以下部分：
- **代码段（Text）**：程序的指令（即编译后的机器码）。
- **数据段（Data）**：全局变量、静态变量等。
- **堆（Heap）**：动态分配的内存（如`malloc`申请的空间）。
- **栈（Stack）**：函数调用时的局部变量、返回地址等。
- **进程控制块（PCB，Process Control Block）**：操作系统维护的进程元数据，包括：
    - 进程ID（PID）、状态（运行/就绪/阻塞等）、优先级、寄存器值、打开的文件列表等。

### 进程的状态

进程在其生命周期中会经历多种状态，典型的有：
1. **新建（New）**：进程正在被创建。
2. **就绪（Ready）**：进程已获得所需资源，等待 CPU 调度。
3. **运行（Running）**：进程正在 CPU 上执行。
4. **阻塞（Blocked）**：进程因等待 I/O 等事件而暂停。
5. **终止（Terminated）**：进程执行完毕或被强制结束。

### 进程 vs 线程

- **进程**是资源分配的基本单位，**线程**是CPU调度的基本单位。
- 同一进程的多个线程共享进程的资源（如内存、文件），而进程之间资源隔离。
- 线程切换开销比进程小，但进程的稳定性更高（一个线程崩溃可能导致整个进程终止）。

### 进程的创建与终止

- **创建方式**：  
    - 系统初始化时（如操作系统启动的守护进程）。
    - 通过 `fork()`（Unix/Linux）或 `CreateProcess()`（Windows）由父进程创建子进程。
- **终止原因**：  
    - 正常退出（程序执行完毕）。
    - 错误退出（如 segmentation fault）。
    - 被其他进程或操作系统强制终止（如`kill -9 PID`）。


### 进程间通信

 进程间通信（IPC，Inter-Process Communication）：由于进程间内存隔离，需要通过特定机制通信：
1. **管道（Pipe）**：单向通信，常用于父子进程。
2. **消息队列（Message Queue）**：存储在内核中的消息链表。
3. **共享内存（Shared Memory）**：最高效的方式，但需同步机制（如信号量）。
4. **信号（Signal）**：异步通知（如`SIGKILL`）。
5. **套接字（Socket）**：跨网络通信。


### 示例

在 Linux 中，可以通过 `ps -aux` 命令查看所有运行中的进程。每个进程有唯一的 PID（进程ID），例如：
```bash
$ ps -aux | grep nginx
root      1234  0.0  0.1  ...  /usr/sbin/nginx
```
这里，`1234`是PID，`nginx`是进程对应的程序名称。
