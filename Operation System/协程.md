协程（Coroutine）是一种比线程更轻量级的并发编程模型，允许在**单个线程**中实现多任务的协作式调度，是**可以暂停执行并在稍后恢复的函数**。

与线程的抢占式调度不同，协程需要**主动释放执行权**，通过协作切换任务。

#### 核心特点

1. **协作式调度**：协程需要显式（或隐式）地让出（`yield`）控制权，其他协程才能运行。这避免了线程的锁竞争和上下文切换开销。
2. **轻量级**：协程的上下文切换发生在用户态，无需内核介入，内存占用通常只有线程的几十分之一（例如，Go 的协程约 2KB，而线程通常 MB 级）。
3. **单线程内并发**：多个协程运行在同一个线程中，通过事件循环或调度器管理。适合 I/O 密集型任务（如网络请求、文件读写）。
4. **状态保持**：协程在暂停时会保存局部变量和执行状态，恢复时继续执行，类似生成器（Generator）。


#### 应用场景

- **高并发服务**：如 Web 服务器（Nginx、Tornado）、微服务（Go 的 Goroutine）。
- **异步 I/O**：结合 `async/await` 实现非阻塞操作（Python 的 asyncio、JavaScript 的 Promise）。
- **生成器**：逐步产生数据的流水线（Python 的 `yield`）。

#### 实现方式

1. **语言原生支持**：如 Go（Goroutine）、Kotlin（Coroutine）。
2. **库/框架实现**：如 Python 的 `asyncio`、C++ 的 Boost.Coroutine。
3. **生成器模拟**：通过 `yield` 实现协程切换（早期 Python）。


##### 有栈协程（Stackful Coroutine）

**特点**

- **独立调用栈**：每个协程拥**有独立的栈空间**（类似线程），可以嵌套调用函数并在任意位置挂起。
- **上下文切换**：通过保存/恢复完整的栈（寄存器、栈指针等）实现切换，类似线程切换但更轻量。
- **灵活性**：可在任意函数调用层级中挂起（包括嵌套的深层函数）。

**优点**

- 编程直观：无需显式标记挂起点，适合复杂调用逻辑。
- 兼容性：可与现有代码（如阻塞IO）结合，无需大规模重构。

**缺点**

- 内存开销：每个协程需预分配栈空间（通常几KB~MB），协程数量多时内存消耗大。
- 切换成本：保存完整栈比无栈协程略慢。


##### 无栈协程（Stackless Coroutine）

**特点**

- **无独立栈**：协程共享调用者的栈，通过状态机机制实现挂起/恢复。
- **显式挂起点**：需在代码中显式标记挂起位置（如`await`或`yield`），通常限制在顶层函数。
- **轻量级**：仅保存必要的局部变量（通过闭包或编译器生成的结构体）。

**优点**

- 内存高效：无需预分配栈，协程数量可达百万级。
- 切换极快：仅保存少量状态，性能接近函数调用。

**缺点**

- 编程限制：无法在嵌套函数中随意挂起，需显式管理状态。
- 侵入性：需配合编译器/语言特性（如 `async` / `await` ）。


##### 生成器（Generator）

协程实际上是**通过生成器逐步演化而来的**，生成器是一种特殊的迭代器，通过函数中的 `yield` 关键字实现，可以暂停执行并保留局部状态。

**特点**：
- 使用 `yield` 暂停函数执行，返回一个值。
- 通过 `next()` 或 `for` 循环恢复执行。
- 主要用于生成序列数据（惰性计算）。



#### 优缺点

- **优点**：高并发、低资源消耗、**简化异步代码**（避免回调地狱）。
- **缺点**：不适用 CPU 密集型任务（需配合多进程）、调试复杂。




#### 编程语言支持

##### Go

Go **原生支持**协程（**有栈协程**），通过 `goroutine` 实现，配合 `channel` 进行通信。

```go
package main

import "fmt"

func main() {
    go fmt.Println("Hello from goroutine")
    time.Sleep(1 * time.Second)
}
```

**特点**：
- 有栈协程，轻量级（初始栈仅 2KB），由 Go 运行时调度（GMP 模型）。
- 适用于高并发场景（如微服务、网关）。


##### Python

Python 3.5+ 通过 `async` / `await` 语法支持原生协程，依赖 `asyncio` 库进行事件循环管理。

```python
import asyncio

async def my_coroutine():
    await asyncio.sleep(1)
    print("Coroutine")

asyncio.run(my_coroutine())
```

**特点**：
- 适用于 I/O 密集型任务（如网络请求、文件操作）。
- 协程由事件循环驱动，调度方式为协作式（需显式 `await` ）。


##### C++

C++20 引入协程支持（ `co_await` 、 `co_yield` ）

```c++
#include <coroutine>

auto simple_coroutine() {
    co_await std::suspend_always{};
    std::cout << "Coroutine" << std::endl;
}
```

**特点**：
- 底层控制能力强，适合高性能计算。
- 需要手动管理协程生命周期。


C++ 的 Boost.Coroutine 支持有栈协程。


##### Java

无原生协程，但可通过 **Project Loom**（实验性）的 `Virtual Threads` 或 `CompletableFuture` 模拟。


##### C\#

C# 无原生的协程类型，但是基于 `Task` 模型和异步方法 `async/await`，供了类似的非阻塞执行流程。

```c#
async Task FetchData() {
    var res = await httpClient.GetAsync("https://api.example.com");
    Console.WriteLine(await res.Content.ReadAsStringAsync());
}
```

**特点**：
- 与 Python/JS 类似，集成度高。


##### Rust

Rust 的协程主要通过 `async/await` 、`Future` 和运行时（如 `tokio`、`async-std`）来实现，通常用于异步编程。

```rust
async fn fetch_data() -> Result<String, reqwest::Error> {
    let response = reqwest::get("https://api.example.com").await?;
    response.text().await
}
```

**特点**：
- 无栈协程，无 GC，内存安全，适合系统级并发。


##### Lua

Lua 5.0 开始内置[协程](../Language/Lua/Lua.md#协程)功能（ `coroutine` 库），**单线程**实现，是一种**协作式多任务**机制（非抢占式），允许你在多个任务之间手动切换执行，而无需依赖操作系统线程。

```lua
local co = coroutine.create(function()
    print("Coroutine")
end)
coroutine.resume(co)
```

**特点**：
- 轻量级，常用于游戏脚本或嵌入式系统。


##### JavaScript

JavaScript 在 ES6+ 引入异步函数 `async` / `await` （基于 Promise），通过生成器（Generator）和异步函数来实现协程。

```JavaScript
async function fetchData() {
    const res = await fetch('https://api.example.com');
    console.log(await res.json());
}

fetchData();
```

**特点**：
- 单线程事件循环模型，适合异步 I/O（如 HTTP 请求、数据库操作）。
