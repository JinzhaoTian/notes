tmux 是一个终端复用器（Terminal Multiplexer），其允许你在单个终端窗口中创建、访问和控制多个终端会话。

## 核心功能

1. **会话保持与后台运行**
    - 可以在远程服务器上启动一个 tmux 会话，然后在里面运行一个耗时很长的任务（比如数据备份）。
    - 然后你可以放心地关掉终端窗口，甚至关掉电脑回家。当你回到办公室重新连接上服务器时，那个任务仍然在 tmux 会话里运行着，你可以重新附着（attach）到那个会话，继续查看进度。这大大增强了远程工作的可靠性。
2. **多窗口与窗格**
    - 在一个 tmux 会话中，可以创建多个**窗口**（Window），每个窗口就像终端里的一个标签页。
    - 在每个窗口里，你还可以将屏幕分割成多个**窗格**（Pane），这些窗格可以并排或上下显示，并且可以同时运行不同的命令。比如：一个窗格用 Vim 编辑代码，另一个窗格实时查看日志，第三个窗格执行测试命令，所有操作都在同一个屏幕内完成。
3. **协作**
    - 多个用户可以通过 SSH 连接到同一台服务器，并附着到同一个 tmux 会话。这样，大家就能实时看到同一个终端界面，非常适合结对编程或远程教学。

## 基本概念

1. **会话（Session）**：tmux 的最顶层单元。一个会话可以包含多个窗口。
2. **窗口（Window）**：相当于一个标签页，占据整个终端界面。一个窗口可以包含多个窗格。
3. **窗格（Pane）**：窗口被分割后形成的多个小区域，每个区域都是一个独立的终端。

## 使用流程

1. **启动新会话**：在终端输入 `tmux` 或 `tmux new -s 会话名称`。
2. **操作前缀键**：要执行 tmux 的指令，需要先按一个特殊的组合键来告诉 tmux “接下来我要输入命令了”。默认的前缀键是 **`Ctrl + b`**。
3. **常用命令示例**（所有命令都需要先按前缀键 `Ctrl + b`）：
    - `%`：垂直分割当前窗格。
    - `"`：水平分割当前窗格。
    - 方向键：在窗格之间移动光标。
    - `c`：创建一个新窗口。
    - `n` / `p`：切换到下一个/上一个窗口。
    - `d`：从当前会话中分离（detach），让会话在后台继续运行。
4. **重新连接**：在你重新登录服务器后，输入 `tmux attach` 或 `tmux attach -t 会话名称`，就可以重新回到之前的工作环境。
