线程（Thread）是操作系统能够进行**CPU调度的最小单位**，它是**进程中的一个执行流**，共享进程的资源（如内存、文件等），但拥有独立的执行状态和栈空间。

线程也被称为轻量级进程（Lightweight Process, LWP），因为它的创建、切换和销毁比进程更高效。

## 核心特性

1. **共享进程资源**  
    - 同一进程内的所有线程共享：
        - 代码段、数据段、堆内存、打开的文件描述符等。
    - 每个线程独有：
         - 线程ID（TID）、寄存器状态、栈空间（存储局部变量、函数调用链等）。

2. **轻量级并发**  
    - 线程的创建、切换和销毁比进程更快（无需分配新的内存空间或复制资源）。

3. **并行执行**  
    - 在多核CPU上，多个线程可以真正并行运行（每个核运行一个线程）。

4. **依赖进程存在**  
    - 线程不能独立存在，必须属于某个进程。如果进程终止，其所有线程也会被销毁。


## 线程 vs 进程

| **对比项**       | **进程（Process）**                | **线程（Thread）**                |
|------------------|-----------------------------------|-----------------------------------|
| **资源占用**     | 独立内存空间，资源开销大          | 共享进程资源，开销小              |
| **创建/切换速度**| 慢（需分配独立资源）              | 快（只需分配栈和寄存器）          |
| **通信方式**     | IPC（管道、共享内存、消息队列等） | 直接读写进程的共享变量            |
| **健壮性**       | 一个进程崩溃不影响其他进程        | 一个线程崩溃可能导致整个进程崩溃  |
| **并发性**       | 适合多任务隔离                    | 适合高并发任务（如Web服务器）     |


## 实现方式

### 用户级线程

用户级线程（User-Level Thread）
- 由用户空间的线程库（如POSIX的`pthread`）管理，操作系统不感知。
- **优点**：切换无需内核介入，速度快。
- **缺点**：
    - 一个线程阻塞（如I/O操作）会导致整个进程阻塞。
    - 无法利用多核CPU（内核以为进程只有一个执行流）。

### 内核级线程

内核级线程（Kernel-Level Thread）
- **由操作系统直接管理**，线程调度由内核完成。
- **优点**：
  - 一个线程阻塞不会影响其他线程。
  - 可真正并行执行（多核CPU适用）。
- **缺点**：线程切换需陷入内核，开销较大。

### 混合模型

混合模型（如Java的线程）
- 结合用户级和内核级线程，例如“M:N模型”（M个用户线程映射到N个内核线程）。


## 线程的状态

和进程类似，线程也有生命周期状态：
1. **新建（New）**：线程被创建但未启动。
2. **就绪（Runnable）**：等待CPU调度。
3. **运行（Running）**：正在执行。
4. **阻塞（Blocked）**：等待I/O、锁等事件。
5. **终止（Terminated）**：执行完毕或异常退出。


## 线程同步与通信

由于线程共享进程资源，可能引发**竞态条件（Race Condition）**，需同步机制：
- **互斥锁（Mutex）**：保证同一时间只有一个线程访问共享资源。
- **信号量（Semaphore）**：控制对多个资源的访问。
- **条件变量（Condition Variable）**：线程间的事件通知机制。
- **原子操作（Atomic Operations）**：不可中断的指令（如CAS）。

**示例（C++11线程）**：
```cpp
#include <iostream>
#include <thread>
#include <mutex>

std::mutex mtx; // 互斥锁

void print_hello(int id) {
    mtx.lock();
    std::cout << "Thread " << id << " says: Hello!\n";
    mtx.unlock();
}

int main() {
    std::thread t1(print_hello, 1);
    std::thread t2(print_hello, 2);
    t1.join();
    t2.join();
    return 0;
}
```

## 多线程的应用场景

- **高并发服务器**（如Nginx、Redis）：每个连接一个线程。
- **图形界面程序**：主线程处理UI，后台线程执行计算。
- **科学计算**：并行分解任务（如矩阵运算）。
- **游戏开发**：物理引擎、渲染、AI等分离到不同线程。


## 线程的优缺点

**优点**：
- 提升程序响应速度（如UI线程不被阻塞）。
- 充分利用多核CPU性能。
- 资源共享方便（无需IPC）。

**缺点**：
- 调试困难（竞态条件、死锁）。
- 线程安全问题（需同步机制，可能降低性能）。
- 一个线程崩溃可能影响整个进程。


## 总结

线程是进程内的执行单元，**轻量、高效、共享资源**，适合需要高并发的场景，但需注意同步问题。现代编程语言（如Java、Python、C++）均提供原生线程支持，而协程（Coroutine）等更轻量的技术也在逐渐流行。
