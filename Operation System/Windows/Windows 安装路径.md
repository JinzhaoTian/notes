|          | `C:\Program Files` (及其 `(x86)` 文件夹)   | `C:\Users\用户名\AppData`                  |
| -------- | ------------------------------------- | --------------------------------------- |
| **目的**   | 存放软件运行所需的**核心程序文件**（如 `.exe`, `.dll`） | 存放当前用户的**个性化配置、缓存、存档等数据**               |
| **影响范围** | **所有**登录这台电脑的用户都可以使用这个软件              | 仅对**当前用户**有效，其他用户账户无法访问此文件夹中的软件或数据      |
| **权限要求** | **需要管理员权限**才能安装或修改其中的文件               | **无需管理员权限**，当前用户即可安装和修改                 |
| **典型例子** | 像 Office、Adobe 系列这类大型、被广泛使用的专业软件      | 像 Chrome、Discord 这类可以在当前账户下独立安装和自动更新的应用 |

核心区别在于**影响范围**和**权限要求**，`Program Files` 是给所有用户用的，而 `AppData` 则是个人配置。

## 区别

1. **`Program Files` 体现的是“安全”**：要求管理员权限能有效防止普通用户或恶意软件随意修改核心程序，保证了系统和其他所有用户的稳定与安全。当你安装一个软件并选择“为所有用户安装”时，它通常就会装到这里。
2. **`AppData` 体现的是“便利”**：它让软件可以**绕过管理员权限**，实现静默更新、保存个性化设置，而不会频繁弹出烦人的用户账户控制（UAC）提示。比如，你在 Chrome 里收藏的书签、游戏存档，大多都存放在这里。

## `AppData` 文件夹

`AppData` 文件夹里面还有三个子文件夹，分工各有不同：
- **Roaming**：存放可以随用户账户在不同电脑间同步的数据（比如浏览器书签、应用重要设置）。
- **Local**：存放只适用于当前电脑的数据，通常体积较大或不能迁移（比如浏览器缓存、大型游戏临时文件）。
- **LocalLow**：主要用于存放一些运行在更低安全级别下的应用数据（比如浏览器的无痕模式数据）。

所以下次再看到安装包默认选到 `AppData`，特别是自己电脑权限受限时，就不用感到奇怪了——这是开发者有意选择的路径。如果想调整，多数软件的安装向导里都可以手动更改安装位置（前提是有管理员权限）
