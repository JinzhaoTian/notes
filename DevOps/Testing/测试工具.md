


#### 功能测试工具

- **Selenium** ：开源自动化测试框架，支持多种编程语言（Java、Python、C#等），用于 Web UI 测试，可模拟用户操作浏览器。
- **Cypress** ：基于JavaScript的端到端测试框架，提供实时调试和自动等待机制，适用于现代Web应用测试。
- **Puppeteer** ：由 Google 开发的无头 Chrome 浏览器控制工具，适用于页面截图、爬虫和前端自动化测试。


#### 性能测试工具

- [**JMeter**](../Tools/JMeter.md)：支持多线程并发测试，可模拟HTTP、数据库等协议的高负载场景。通过配置线程组、定时器和监听器，生成压力测试报告，分析响应时间、吞吐量等指标。
- **LoadRunner** ：商业级负载测试工具，适用于复杂场景下的性能分析，支持多种协议和分布式测试
- **kylinPET**：采用 Actor 异步 IO 模型，单机可支持百万级并发，适用于资源有限的测试环境。
- `pt-table-checksum`：分块计算主从库的校验和，避免全表锁对业


#### API测试工具

- **Postman** ：广泛使用的 API 开发和测试工具，支持 REST、GraphQL 等协议，提供请求构建、自动化测试和 Mock 服务。
- **SoapUI** ：开源 API 测试工具，支持 SOAP 和 REST 接口的功能、负载和安全测试。
- **RestAssured** ：基于 Java 的 API 测试库，适用于自动化接口测试，可与测试框架（如 TestNG ）集成。


#### 安全测试工具

- **OWASP ZAP** ：开源 Web 安全测试工具，支持自动化漏洞扫描（如 SQL 注入、XSS ）和渗透测试。
- **Burp Suite** ：专业级Web安全测试平台，用于拦截、修改和分析 HTTP 请求，适用于安全审计。
- **Acunetix** ：商业漏洞扫描工具，可检测 SQL 注入、跨站脚本等常见 Web 安全威胁。


#### 其他实用工具

- **WebPageTest** ：在线网站性能测试工具，提供加载时间、瀑布图分析和优化建议。
- **Grafana + Prometheus** ：监控工具组合，用于实时分析系统性能指标（如 CPU 、内存、响应时间）。
