单元测试（Unit Testing）是软件开发中的一种测试方法，主要特点是对软件中的最小可测试单元进行检查和验证。

**基本概念**

- **定义**：针对程序模块（软件设计的最小单位）进行正确性检验的测试工作
- **范围**：通常测试一个函数、方法或类
- **目的**：验证每个独立单元的行为是否符合预期

**主要特点**

1. **隔离性**：测试单个组件，隔离外部依赖（常用mock/stub技术）
2. **自动化**：可以自动执行和验证结果
3. **快速执行**：单元测试应该运行速度快
4. **可重复**：每次运行结果应该一致
5. **早期发现问题**：在开发周期早期发现缺陷


## 单元测试框架

- **Java** ：
	- [JUnit](../../../Language/Java/JUnit.md) ：JUnit 是 Java 生态中最流行的单元测试框架，也是 xUnit 家族的重要成员
- **Python** ：unittest，pytest
- **JavaScript** ：
	- [Jest](../../../Language/Node/测试/Jest.md) ：JavaScript 测试框架，特别适合 React 应用程序的测试
	- Mocha
- **C#** ：
	- [NUnit](../../Language/CS/测试/NUnit.md) ：成熟稳定的测试框架，源自 Java 的 JUnit。
	- [xUnit](../../Language/CS/测试/xUnit.md)：当前最流行的 C# 测试框架，被 .NET Core 团队选用。
- **C++** ：
	- [gtest](../../Language/C++/测试/Google%20Test.md) ：最流行的 C++ 测试框架，由 Google 开发维护。
	- [Catch2](../../Language/C++/测试/Catch2.md) ：现代、轻量级的 header-only 测试框架。
