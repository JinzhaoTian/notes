BAT 脚本（batch文件）是 Windows 操作系统中的批处理文件，文件扩展名为 `.bat` 或 `.cmd`。这是一种包含一系列命令的文本文件，当执行时，命令会按顺序一一运行。

**主要特点**

1. 简单易用：使用简单的命令语法，容易学习
2. 自动化：可以自动执行一系列命令，无需手动逐一输入
3. Windows原生支持：无需安装额外软件即可运行
4. 批量处理：适合重复性任务和批量文件操作


**常用命令**

```bat
@echo off
:: 这是一个注释
echo 你好，世界！

:: 创建目录
mkdir 新文件夹

:: 复制文件
copy 源文件.txt 目标文件.txt

:: 设置变量
set name=张三
echo 你好，%name%

:: %* 表示脚本调用时的所有命令行参数
Build.exe %*       :: 将调用脚本时传入的命令行参数再全部传给该exe

:: 条件判断
if exist 文件.txt (
    echo 文件存在
) else (
    echo 文件不存在
)

:: 循环
for %%i in (1 2 3) do (
    echo 数字: %%i
)

:: 调用其他程序
start notepad.exe

:: 暂停
pause
```
