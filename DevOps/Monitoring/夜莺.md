夜莺（Nightingale）是一个开源的、专注于监控告警管理的云原生监控分析系统，由滴滴孵化开源。夜莺监控运行在 Linux 系统上，没有提供 Windows 版本的发布包。

## 核心功能

1. **强大的告警引擎**：夜莺的核心是一个强大的告警引擎，负责根据用户配置的规则，周期性地对数据进行分析和判定，一旦触发条件就生成告警事件。
2. **灵活的告警规则**：支持配置复杂的告警规则，包括告警级别、生效时间、告警屏蔽与订阅等。
3. **多样的通知渠道**：内置支持邮件、钉钉、企微、飞书、电话、短信等20多种通知方式，也支持通过 Webhook 自定义扩展。
4. **丰富的告警降噪**：提供告警聚合、抑制、订阅等功能，帮助运维人员过滤告警风暴，专注于真正重要的问题。


## 使用方式

夜莺采用 All-in-One 的设计理念，但在实际使用中，它更侧重于“服务端”的角色：

1. **数据采集**：夜莺自身不负责数据采集。它推荐使用官方配套的采集器 Categraf，也兼容 Prometheus Exporter、Telegraf 等主流采集器。
2. **数据存储**：采集到的数据会存入 Prometheus、VictoriaMetrics、Thanos 等时序数据库（TSDB）中。
3. **分析与告警**：夜莺作为服务端，对接这些数据源，通过 PromQL 等查询语言分析数据，并根据配置的规则触发告警。
4. **可视化与告警管理**：用户通过夜莺提供的 Web UI 统一配置告警规则、查看监控图表和管理告警事件。

这种架构使得夜莺可以无缝融入并增强现有的 Prometheus 生态，因此也被看作是 Prometheus 的一个企业级增强版 WebUI。
