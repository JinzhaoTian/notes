Codeberg 是一个非营利性的开源代码托管平台，致力于为自由和开源软件项目提供一个安全、友好的家园，可以视为社区的开源 Git 服务替代方案。

Codeberg 提供了一系列服务于开源协作的功能：
1. **代码仓库托管**：核心服务，使用 Git 进行版本控制，并集成了问题跟踪、Wiki、Pull Request等协作功能。
2. **Codeberg Pages**：静态网站托管服务，可以直接托管你的项目文档、博客或个人主页。
3. **Codeberg Translate**：基于 Weblate 的本地化（翻译）平台，方便社区协作翻译开源项目的界面和文档。
4. **Woodpecker CI**：一个开源的持续集成/持续部署（CI/CD）引擎，可以自动化测试和部署你的代码。
