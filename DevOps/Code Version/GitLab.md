GitLab 最初是一个基于 Git 的代码仓库管理系统，现在已经发展为集代码管理、项目管理、自动化测试与部署等覆盖整个软件生命周期于一身的 DevOps 平台，官网 [GitLab.com](https://gitlab.com)。

> [!tip] 极狐公司
> 极狐是 GitLab 在中国市场的独立实体，官网 [GitLab.cn](https://gitlab.cn)，成立于 2021 年，是 GitLab Inc. 与红杉宽带跨境数字产业基金、高成资本共同成立的合资公司，二者是技术母公司与本地化合资公司的关系。
> 
> GitLab 提供核心技术、产品和品牌授权，而极狐公司在国内独立运营，拥有产品研发、销售、服务和本地决策权。
> 
> 其中，[JihuLab.com](https://jihulab.com) 是极狐公司推出的中国本土化 SaaS 服务，所有基础设施和数据均位于中国境内，访问速度快，并遵守《网络安全法》等中国法规。因此，它是目前国内用户进行代码托管和DevOps实践的推荐选择。

## 主要版本

GitLab 分为三个主要版本，它们的核心区别如下：

| 特性维度     | **社区版 (CE)**          | **企业版 (EE)**                         | **极狐GitLab 企业版**              |
| -------- | --------------------- | ------------------------------------ | ----------------------------- |
| **核心性质** | **开源免费**              | **商业付费**                             | **商业付费**                      |
| **许可协议** | MIT 许可证               | GitLab 企业许可                          | 极狐GitLab 企业许可                 |
| **核心功能** | 完整的 DevOps 生命周期管理基础功能 | 包含社区版所有功能                            | 基于企业版，增加本地化功能                 |
| **高级功能** | ❌ 不支持                 | ✅ **支持**（如：高级 CI/CD、安全合规、项目管理和洞察分析等） | ✅ **支持**（包含企业版高级功能，并针对中国市场定制） |
| **技术支持** | 社区支持（论坛、Issue）        | GitLab 官方 SLA 技术支持                   | 极狐公司官方 SLA 技术支持               |
| **典型用户** | 个人、学生、中小团队、测试环境       | 中大型企业、对安全和效率有高要求的团队                  | 需要合规、本地化支持及服务的中国境内企业          |
