
## 打包

### node.js 

对于 node.js 项目，可以用 pm2 进行托管，在根目录下新建 pm2.config.js，然后通过传入不同的参数，启动对应的环境，
```js
module.exports = {
  apps : [
      {
        name: "myapp",
        script: "./bin/www",
        watch: true,
        env: {
            "NODE_ENV": "development"
        },
        env_production: {
            "NODE_ENV": "production",
        }
      }
  ]
}
```

- 启动预发环境：pm2 start pm2.config.js --env development
- 启动生产环境：pm2 start pm2.config.js --env production
- 在项目中通过 process.env.NODE_ENV 读取


编写 Dockerfile 并构建新的镜像，
```dockerfile
FROM keymetrics/pm2

RUN mkdir -p /home/backend

WORKDIR /home/backend

COPY ./ /home/backend

RUN yarn install

ENV NPM_CONFIG_LOGLEVEL warn

EXPOSE 9000

CMD ["pm2-runtime", "start", "pm2.config.js", "--env", "production"]
```


```bash
docker build -t backend .
```


编写 docker-compose.yml 配置文件，
```yaml
version: '3'

networks:
  app-web:
   driver: bridge

services:
  mysql:
    image: mariadb
    ports:
     - 3306:3306
    command: --default-authentication-plugin=mysql_native_password
    restart: always
    networks:
     - app-web
    environment:
     - TZ=Asia/Shanghai
     - MYSQL_USER=root
     - MYSQL_ROOT_PASSWORD=123456
    volumes:
     - ./mysql/data:/var/lib/mysql
     - ./mysql/my.cnf:/etc/mysql/my.cnf
     - /etc/localtime:/etc/localtime

  backend:
    image: backend
    ports:
     - 9000:9000
    environment:
     - TZ=Asia/Shanghai
     - MYSQL_USER=root
     - MYSQL_ROOT_PASSWORD=123456
    networks:
     - app-web

  frontend:
    image: frontend
    ports:
     - 80:80
    depends_on:
     - backend
```

然后执行命令运行，
```bash
docker compose up -d
```


### Python

Python 后端服务可以通过多种方式进行托管，下面是几种常见的托管方式：
- WSGI 服务器：常见的有 Gunicorn、uWSGI，适用于 Django、Flask 等框架的同步应用。
- ASGI 服务器： 常见的有 Uvicorn、Daphne、Hypercorn 等，适用于 FastAPI、Django Channels 等现代异步框架。


将 Python 后端服务打包成 Docker 容器可以提高部署的一致性和可移植性，
```dockerfile
# 使用官方 Python 镜像作为基础镜像
FROM python:3.9-slim

# 设置工作目录
WORKDIR /app

# 复制 requirements.txt 文件并安装依赖
COPY requirements.txt .

RUN pip install --no-cache-dir -r requirements.txt

# 复制应用代码到容器中
COPY . .

# 设置环境变量
ENV FLASK_APP=app.py
ENV FLASK_RUN_HOST=0.0.0.0
ENV DB_CONNECTION_STRING=$DB_CONNECTION_STRING

# 启动应用
CMD ["gunicorn", "-w", "4", "-b", "0.0.0.0:8000", "app:app"]
```

然后构建，
```bash
docker build -t my-python-app .
```

最后可以运行，
```bash
docker run -e DB_CONNECTION_STRING='your-connection-string' my-python-app
```

或者使用 `docker-compose.yml` 文件进行配置运行，
```yaml
version: '3.8'
services:
  web:
    image: my-python-app
    environment:
      - DB_CONNECTION_STRING=${DB_CONNECTION_STRING}
```

再或者使用 `.env` 文件，
```env
DB_CONNECTION_STRING=your-connection-string
```
并在 `docker-compose.yml` 中引用，
```yaml
env_file:
  - .env
```


配置好的环境变量可以在 Python 应用中读取环境变量，
```python
import os

db_connection_string = os.getenv('DB_CONNECTION_STRING')
```



## 敏感信息设置

在微服务架构中，后端项目可能会涉及到一些敏感信息，例如数据库连接字符串、API 密钥、访问令牌等。为了安全地处理这些敏感信息，在将后端项目打包成 Docker 时，需要采取一些最佳实践来管理和保护这些数据。

#### 方法一：使用环境变量

通过环境变量来传递敏感信息，使得这些信息不直接包含在代码中或 Docker 镜像中。

首先在 Dockerfile 中，不要硬编码敏感信息，而是使用环境变量占位符，
```dockerfile
FROM node:14
WORKDIR /app
COPY . .
ENV DB_CONNECTION_STRING=$DB_CONNECTION_STRING
CMD ["node", "app.js"]
```


然后通过如下方式进行传递：
1. 在运行 Docker 容器时，通过命令行传递环境变量，
```bash
docker run -e DB_CONNECTION_STRING='your-connection-string' my-backend-service
```

 2. 通过 docker-compose.yml 文件中传递，
```yaml
services:
  backend:
    image: my-backend-service
    environment:
      - DB_CONNECTION_STRING=${DB_CONNECTION_STRING}
```

3. 使用 `.env` 文件来管理环境变量，
```env
DB_CONNECTION_STRING=your-connection-string
```

然后在  docker-compose.yml 中引用，
```yaml
env_file:
  - .env
```


#### 方法二：配置文件外部化

将敏感配置存储在外部配置文件中，而不是硬编码在应用程序中。通过 Docker 挂载配置文件的方式，将配置文件挂载到容器内。

创建一个配置文件（如 config.json），将敏感信息存储在其中，
``` json
{
  "db_connection_string": "your-connection-string"
}
```

在运行容器时，将配置文件挂载到容器内，
```bash
docker run -v /path/to/config.json:/app/config.json my-backend-service
```

这种方式需要在应用程序中进行读取配置文件，
```js
const config = require('./config.json');
const dbConnectionString = config.db_connection_string;
```

#### 方法三：使用配置管理工具

使用配置管理工具（如 Consul、Vault、ConfigMap）来集中管理和分发敏感信息。

使用 HashiCorp Vault 来安全存储敏感信息。Vault 可以与 Kubernetes 或 Docker 集成，提供动态秘密管理。在应用程序中，集成 Vault 客户端，通过 API 或环境变量获取敏感信息。

例如，在初始化时从 Vault 获取数据库连接字符串，
```python
import hvac

client = hvac.Client(url='http://localhost:8200')
client.token = 'your-vault-token'
db_connection_string = client.secrets.kv.v2.read_secret_version(path='database')['data']['data']['connection_string']
```
