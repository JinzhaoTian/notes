### 资源型

#### 01背包

1. 问题描述：有一个容量为 J 的背包，n 种物体，每个物体都有两个属性，即体积 w 和价值 v ，**每种物品只有一个**。如何向背包装物体才能使背包中物体的总价值最大？
2. 解题思路：
    1. 定义变量：vi 表示第 i 个物品的价值，wi 表示第 i 个物品的体积，dp(i, j)：当前背包容量 j，前 i 个物品最佳组合对应的价值。背包问题抽象化（x1，x2，…，xn，其中 xi 取0或1，表示第 i 个物品选或不选）。
    2. 建立模型：求 `max(v1x1 + v2x2 + … + vnxn)`
    3. 约束条件：`w1x1 + w2x2 + … + wnxn < J`
    4. 递推关系式：
        1. 装不下：此时的价值与前i-1个的价值是一样的，即 `dp(i,j) = dp(i-1,j)`
        2. 装得下，选择装或不装：`dp(i,j)=max｛dp(i-1, j-w(i) * x(i)) + v(i) * x(i)｝, x(i) = 0, 1`. 或者 `dp(i,j)=max｛dp(i-1, j)，dp(i-1, j-w(i)) + v(i)｝`.
    5. 代码：

```
// 初始化，价值为0
for(int j = 0; j <= J; ++j) dp[0][j] = 0;
for(int i = 0; i < n; ++i) dp[i][0] = 0;

// 未优化
for(int i = 1; i <= n ; ++i){
    for(int j = J; j >= 0; --j){
        if (j >= w[i]){
            dp[i][j] = max(dp[i - 1][j], dp[i - 1][j - w[i]] + v[i]);
        } else {
            dp[i][j] = dp[i - 1][j];
        }
    }
}
int ans = dp[n][J];

// 优化空间复杂度
for(int i = 1; i <= n ; ++i){
    for(int j = J; j >= 0; --j){
        if (j >= w[i]){
            dp[j] = max(dp[j], dp[j - w[i]] + v[i]);
        } else {
            dp[j] = dp[j];
        }
    }
}

// 最终优化
for(int i = 1; i <= n ; ++i){
    for(int j = J; j >= w[i]; --j){
        dp[j] = max(dp[j], dp[j - w[i]] + v[i]);
    }
}

int ans = dp[J];
```

#### 完全背包

3. 问题描述：有一个容量为 J 的背包，n 种物体，每个物体都有两个属性，即体积 w 和价值 v ，**每种物品有无限多个**。如何向背包装物体才能使背包中物体的总价值最大？
4. 解题思路：
    1. 定义变量：背包问题抽象化（x1，x2，…，xn，其中 xi 取自然数，表示第 i 个物品不选或选择几个）。
    2. 建立模型：求 max(v1x1 + v2x2 + … + vnxn)
    3. 约束条件：w1x1 + w2x2 + … + wnxn < J
    4. 递推关系式
        1. 装不下：此时的价值与前i-1个的价值是一样的，即 dp(i,j) = dp(i-1,j)
        2. 装得下，选择装几个或不装：`dp(i,j)=max｛dp(i-1, j-w(i) * x(i)) + v(i) * x(i)｝, x(i) = 0, 1, 2, ...`
        3. **优化**：对于第i种物品，装两个，可以由前面装一个进行叠加，装n个可以由前面装n-1个进行叠加。那么优化后的转移方程为：`dp(i,j)=max｛dp(i-1, j), dp(i, j - w[i]) + v[i]｝`
    5. 代码：

```
// 初始化，价值为0
for(int j = 0; j <= J; ++j) dp[0][j] = 0;
for(int i = 0; i < n; ++i) dp[i][0] = 0;

// 未优化
for(int i = 1; i <= n ; ++i){
    for(int j = 0; j <= J; ++j){
        if (j < w[i]){
            dp[i][j] = dp[i - 1][j];
        } else {
            dp[i][j] = max(dp[i - 1][j], dp[i][j - w[i]] + v[i]);
        }
    }
}

int ans = dp[n][J];

// 优化
for(int i = 1; i <= n ; ++i){
    for(int j = w[i]; j <= J; ++j){  // 遍历方向不一致
        dp[j] = max(dp[j], dp[j - w[i]] + v[i]);
    }
}

int ans = dp[J];
```

#### 多重背包

5. 问题描述：有一个容量为 J 的背包，n 种物体，每个物体都有两个属性，即体积 w 和价值 v ，**每种物品有数量限制**， 物品最多有 c 件。如何向背包装物体才能使背包中物体的总价值最大？
6. 解题思路
    1. 定义变量：第 i 种物品最多有 ci 件。背包问题抽象化（x1，x2，…，xn，其中 xi 取 0 ... ci ，表示第 i 个物品不选或选择几个）。
    2. 建立模型：求 max(v1x1 + v2x2 + … + vnxn)
    3. 约束条件：w1x1 + w2x2 + … + wnxn < J
    4. 递推关系式
        1. 装不下：此时的价值与前i-1个的价值是一样的，即 dp(i,j) = dp(i-1,j)
        2. 装得下，选择装几个或不装：`dp(i,j)=max｛dp(i-1, j-w(i) * x(i)) + v(i) * x(i)｝, x(i) = 0, 1, ..., c(i)`.
    5. 代码：

```
for(int j = 0; j <= J; ++j) dp[0][j] = 0;
for(int i = 0; i < n; ++i) dp[i][0] = 0;

for(int i = 1; i <= n ; ++i) {
    for(int j = 0; j <= J; ++j) {
        for(int k = 0; k <= c[i] && k * w[i] <= j; ++k){
            dp[i][j] = max(dp[i][j], dp[i - 1][j - w[i] * k] + v[i] * k);
        }
    }
}

int ans = dp[n][J];

// 优化
for(int i = 1; i <= n ; ++i) {
    for(int j = 0; j <= J; ++j) {
        for(int k = 0; k <= c[i] && k * w[i] <= j; ++k){
            dp[j] = max(dp[j], dp[j - w[i] * k] + v[i] * k);
        }
    }
}
```

6. **二进制优化**：多重背包解法一般都是三重循环，复杂度比较高。有一种特别的优化方法可以将多重背包转换为01背包。
    1. 思路：将第 i 种c[i]件物品按二进制的方法分拆成s份“不同”的物品。例如，设第i件物品有20件，每件重量和价值分别为w和p，则可以分拆别5份“物品”如下：
        1. 第1份含有1件物品，重量为w，价值为p；
        2. 第2份含有2件物品，重量为2w，价值为2p；
        3. 第3份含有4件物品，重量为4w，价值为4p；
        4. 第4份含有8件物品，重量为8w，价值为8p；
        5. 第5份含有5件物品，重量为5w，价值为5p。
    2. 代码：

```
for(int k = 1; k <= n ; ++k) {
    int s = c[k];
    for(int i = 1; i <= s; s -= i, i = i * 2) {
        for(int j = V; j >= 0 && j >= w[k] * i; --j){
            dp[j] = max(dp[j], dp[j - w[k] * i] + v[k] * i);
        }
    }
    if(s > 0) {
        for(int j = V; j >= s * w[k]; --j){
            dp[j] = max(dp[j], dp[j - s * w[k]] + s * v[k]);
        }
    }
}
```

### 线性动态规划

线性动态规划，是较常见的一类动态规划问题，其是在线性结构上进行状态转移，这类问题不像背包问题、区间DP等有固定的模板。线性动态规划的目标函数为特定变量的线性函数，约束是这些变量的线性不等式或等式，目的是求目标函数的最大值或最小值。

### 区间动态规划

区间动态规划，其实求的就是一个区间内的最优值。一般这种题目，在设置状态的时候，都可以设 dp(i，j) 为区间 i-j 的最优值，而 dp(i, j)的最优值，是由两个小区间合并而来的，为了划分这两个更小的区间，我们则需用用一个循环变量 k 来枚举，而一般的状态转移方程便是：`dp[i][j] = max/min(dp[i][j], dp[i][k] + dp[k][j] + something), k = i, ..., j`.

#### 模板

```
for (int len = 2; len <= n; len ++){
    for (int i = 1; i + len - 1 <= n; ++i){
        int j = i + len - 1;
        for (int k = i; k <= j; k++)
            dp[i][j] = max/min(dp[i][j], dp[i][k] + dp[k][j] + something);
    }
}
```

### 状态压缩DP

状态压缩DP属于DP问题中比较困难的一类问题，对于状态的压缩模拟和对题目状态的转移需要较强的理解。

状态中所包含的信息过多，该怎么办呢？我们可以**利用二进制**以及**位运算**来实现对于本来应该很大的数组的操作，这就是状态压缩，而使用状态压缩来保存状态的 DP 就叫做状态压缩 DP。
