[ONNX](https://onnx.ai/)（Open Neural Network Exchange）是一种开放的深度学习模型交换格式，旨在促进不同深度学习框架之间的互操作性。它最初由微软和 Facebook 在 2017 年共同发起，旨在让开发者可以在不同的框架之间共享和重用机器学习模型，而不必被锁定在特定的框架或平台中。

ONNX 的关键功能包括：
1. **模型互操作性**：ONNX 支持将模型在不同的深度学习框架之间互相转换。例如，可以使用 PyTorch 训练一个模型并导出为 ONNX 格式，然后在 TensorFlow、MXNet、ONNX Runtime 或其他支持 ONNX 的框架中加载和推理。
2. **标准化表示**：ONNX 通过一个标准的图计算格式（computation graph）来表示模型。这个图描述了模型的各层及其操作，允许在各种硬件和平台上进行一致的解释和执行。
3. **优化推理**：ONNX Runtime 是一个高效的推理引擎，支持优化模型的运行时间，能够在 CPU 和 GPU 上快速执行模型推理任务。
4. **丰富的操作支持**：ONNX 支持许多常见的深度学习操作（如卷积、池化、激活函数等），并通过不断更新来增加对新操作的支持。

ONNX 广泛用于机器学习模型的推理阶段，特别是在模型部署时，因为它允许开发者将模型导出为 ONNX 格式，在轻量级推理引擎中执行，而不依赖于最初的训练框架。
