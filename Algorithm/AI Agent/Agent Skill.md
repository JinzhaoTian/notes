Agent Skill 是指一个智能体（Agent）为了完成特定任务而具备的、可调用的具体能力或功能模块。在传统的 AI 程序中，功能是写死的。但在智能体框架下，Skill 是一种更灵活、更模块化的设计：
1. **原子化**：每个 Skill 通常负责一个非常具体、单一的功能。比如“查询天气”、“发送邮件”、“计算两个数的和”、“调用公司内部 API 获取销售数据”。这样的小功能块易于开发、测试和维护。
2. **工具化**：Skill 被设计成可以被智能体的“大脑”（通常是大型语言模型，LLM）根据当前的需求，动态选择和调用的工具。


## 主要构成

一个标准的 Agent Skill 通常包含以下几个部分：

1. **名称**：一个清晰、唯一的标识符，如 `get_current_weather`。
2. **描述**：一段用自然语言写的文本，精确说明这个技能是做什么的、什么时候该用它、有什么限制。**这对 LLM 来说至关重要**，因为它靠这段描述来决定是否调用这个技能。例如：“当用户想了解某个城市的当前天气情况时调用。需要提供城市名称。”
3. **输入参数**：技能运行需要哪些信息。定义好参数的名字、类型和描述。例如：
    - `location` （string， 必需）： 城市名称，如 “北京” 或 “London”。
    - `unit` （string， 可选）： 温度单位，可选择 “摄氏” 或 “华氏”。
4. **可执行代码**：背后真正干活的那段程序。可以是一个 Python 函数、一个 API 调用、一段 SQL 查询等。当智能体决定调用此 Skill 并用正确的参数触发时，这段代码就会运行。
5. **输出/返回值**：技能执行完毕后返回的结果，通常会送回给智能体的大脑，以便进行下一步处理或生成最终回复。
