ReAct（Reasoning + Acting，推理+行动）范式，一种让 AI 智能体通过“思考”和“行动”协同来解决问题的**提示工程方法**。

## 核心思想

ReAct 范式的核心是思考与行动的循环，让 AI 智能体不再仅仅是“一次性”地输出答案，而是像人类一样，通过一个循环来解决问题：
1. **思考（Thought）**：AI 分析当前问题，规划下一步该做什么。
2. **行动（Action）**：AI 决定并执行一个具体动作，通常是调用一个外部工具，比如搜索引擎、计算器或 API。
3. **观察（Observation）**：AI 获取行动后返回的结果，然后，AI 基于新的观察结果，继续“思考-行动-观察”的循环，直到找到最终答案。


## 工作流程

假设你问 AI：“华为最新的手机是哪一款？它的主要卖点是什么？”  
一个遵循 ReAct 范式的智能体可能会这样工作：

- **Thought（思考）**: 用户问的是最新款华为手机，我的知识可能不是最新的，需要查询实时信息。
- **Action（行动）**: `Search['华为最新款手机 2026']` （调用搜索工具）
- **Observation（观察）**: 获取搜索结果，例如“华为P60系列，主打影像和卫星通信……”
- **Thought（思考）**: 已经找到了最新款是P60系列，接下来需要总结它的卖点。
- **Action（行动）**: `Search['华为P60 卖点']` （再次调用搜索工具进行细化）
- **Observation（观察）**: 获取更多关于影像、屏幕、电池等卖点的细节。
- **Thought（思考）**: 信息已足够，可以生成最终答案了。
- **Final Answer（最终答案）**: “华为最新的手机是P60系列，其主要卖点包括……”


## 主要优点

- **高可解释性**：AI 的整个“心路历程”（Thought）都被记录下来，我们能清晰看到它得出结论的每一步。
- **强大的工具协同能力**：突破了 AI 自身知识库的局限，可以获取实时信息、执行精确计算，大大扩展了应用范围。
- **动态纠错**：如果一次搜索没得到好结果，AI 可以在下一轮思考中调整策略，重新尝试。
