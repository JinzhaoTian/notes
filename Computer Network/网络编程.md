### Overview

	- [多路复用](IO%20多路复用.md)
2. 高层协议实现
	- [HTTP](HTTP.md) 客户端/服务器
	- [WebSocket](WebSocket.md) 实时通信

3. 异步网络编程
	- [非阻塞 IO](非阻塞%20IO.md)

4. 调优
	- [零拷贝技术](零拷贝技术.md)
5. 高性能网络库
	- **C/C++**：
		- **libevent** ：事件驱动，支持 epoll / kqueue 等，轻量级，适合高并发 TCP / UDP。
		- [**libuv**](IO库/libuv.md) ：Node.js 的底层库，跨平台（ Windows IOCP / Linux epoll ），支持异步 I/O。
		- **Boost.Asio** ：C++标准库风格，支持同步/异步操作，跨平台，常用于游戏和金融领域。
		- **muduo**（陈硕开发）：基于 Reactor 模式，专为 Linux 设计，适合多核高并发，国内广泛应用。
		- **DPDK** ：Intel 开发，用户态网络包处理，绕过内核，适用于高速网络（如 NFV、SDN ）。
		- **Seastar** ：异步无锁设计，支持海量连接，ScyllaDB（高性能 NoSQL ）的底层库。
	- **Java**：
		- **Netty** ：异步事件驱动，支持 HTTP / WebSocket / TCP 等，社区生态强大（如 Spark 、  Elasticsearch ）。
		- **Vert.x** ：基于 Netty ，响应式编程模型，适合微服务和高并发。
		- **Grizzly** ：GlassFish 的 NIO 框架，轻量级，适合嵌入式场景。
	- **Go**：
		- **标准库net** ：Go 原生协程（ goroutine ）模型，简单高效，适合大多数网络应用。
		- **gnet** ：类似 Netty 的事件驱动库，性能优于标准库，适合特殊优化场景。
	- **Rust**：
		- **Tokio** ：异步运行时，提供 Future 和 async / await 支持，生态完善（如 Hyper HTTP 库）。
		- **Mio** ：底层非阻塞 I/O 库，Tokio 的基石。
	- **Python**：
		- **asyncio**（标准库）：基于事件循环，适合 HTTP / WebSocket 等异步应用。
		- **uvloop** ：基于 libuv 的 asyncio 替代方案，性能接近 Go 。
		- **gevent** ：协程库，通过猴子补丁简化异步编程。
