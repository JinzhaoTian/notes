非阻塞 I/O （Non-blocking I/O）是一种编程模型，允许程序在等待 I/O 操作（如读取文件、网络通信等）完成时继续执行其他任务，而不是被阻塞（暂停执行）直到操作完成。

非阻塞 I/O 通常与 [IO 多路复用](IO%20多路复用.md)技术（如 select、poll、epoll 或 kqueue）结合使用，以高效地管理多个并发 I/O 操作。

## 核心概念

1. **非阻塞特性**：当发起 I/O 操作时，如果数据未就绪，调用立即返回而不是等待
2. **立即反馈**：无论操作是否完成，函数都会立即返回结果或错误状态
3. **轮询机制**：程序需要主动检查 I/O 操作是否完成（通过返回值或后续检查）


## 实现方式

1. **系统调用标志**：在 Unix/Linux 中，可以通过 `fcntl` 设置文件描述符的 `O_NONBLOCK` 标志：
```c
int flags = fcntl(fd, F_GETFL, 0);
fcntl(fd, F_SETFL, flags | O_NONBLOCK);
```

2. **返回值处理**：
    - 操作成功：返回实际读写的字节数
    - 数据未就绪：返回特定错误（如 EAGAIN 或 EWOULDBLOCK）
