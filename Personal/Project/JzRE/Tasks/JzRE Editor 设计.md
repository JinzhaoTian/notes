编辑器的本质是一个用于创建和操作 ECS Entity 和 Component 的可视化工具。

## 主要组成

### 场景视图（Scene View）

- 这是一个渲染你游戏场景的视口。
- 它需要与你的 `RenderingSystem` 交互，但通常编辑器会有一个**专用的编辑器渲染器**，它可能包含额外的调试绘制（如线框、Gizmo、栅格）。
- 点击场景中的对象，需要将屏幕坐标转换为世界射线，并与场景中的实体进行交互拾取。这通常通过为可点击对象添加一个不可见的碰撞体组件，或者使用 GPU 拾取技术来实现。

### 实体列表/场景层级（Entity List/Scene Hierarchy）

- 这是一个显示所有实体及其父子关系的树状视图。
- **功能：** 创建、删除、重命名实体、拖拽设置父子关系。
- **实现：** 监听该视图的操作，并将其转换为对底层 `Scene` 对象的 `CreateEntity` 、`DestroyEntity` 等调用。

### 属性检查器（Inspector） - **最关键的集成点**

- 当你选中一个实体或组件时，检查器需要**动态地**显示其所有可编辑属性。
- **实现这一点的核心技术是反射（Reflection）**：C++ 原生不支持反射，因此需要[实现反射](../../../../Language/C++/C++%20实现反射.md)。
- **检查器的工作流程**：
    1. 获取选中的实体 `Entity`。
    2. 获取该实体上的所有组件列表（通过反射系统查询）。
    3. 对于每个组件，通过反射系统获取其所有字段的元数据。
    4. 根据字段类型（`float`, `vec3`, `enum`, `asset handle`）**自动生成**对应的 UI 控件（`ImGui::DragFloat3`, `ImGui::ColorEdit4`, 资源选择对话框等）。
    5. 当用户通过 UI 修改值时，通过反射元数据中的**字段偏移量**，直接修改对应组件内存中的数据。

### 资源管理系统集成

- 组件中经常包含对资源的引用（`Mesh`, `Texture`, `Material`）。
- 检查器中的资源字段应该显示为一个可拖拽的框，或者一个“...”按钮，点击后打开资源浏览器。
- 这需要你的**资源管理系统**提供一个接口，让编辑器可以枚举、预览和选择资源。

### Gizmo 操作

- 实现 Translate、Rotate、Scale 等 Gizmo。
- 当用户在场景视图中操作 Gizmo 时，实际上是在修改实体的 `TransformComponent` 中的 `position` 、`rotation` 等值。
- 这需要将 Gizmo 的变换矩阵变化量，转换并应用到当前选中的实体上。
