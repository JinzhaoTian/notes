[CodeMirror](https://codemirror.net/) 是一个开源的、基于 JavaScript 的功能强大的、灵活的网页代码编辑器，用于在网页中实现类似 IDE 的代码编辑功能。CodeMirror 支持多种编程语言、语法高亮、代码折叠等功能，非常适合在浏览器中构建复杂的代码编辑环境。

> [!tip]
[ProseMirror](ProseMirror.md) 和 CodeMirror 的作者是同一个人 Marijn Haverbeke 。

**主要功能**：
1. **语法高亮**：支持超过 100 种编程语言，通过动态加载模式文件扩展对不同语言的支持。
2. **代码折叠**：提供代码块的折叠与展开功能，提升代码阅读体验。
3. **多光标与多选区**：支持同时编辑多个位置，方便大规模代码修改。
4. **自动补全**：提供代码自动补全功能，可以结合自定义逻辑实现智能提示。
5. **代码格式化**：集成代码格式化工具，使代码结构更加清晰。
6. **可扩展性强**：提供插件体系和丰富的 API，可以自定义功能，例如 lint 检查、代码片段、快捷键等。
7. **实时编辑**：支持与后端的实时数据同步，用于多人协作编辑。
8. **主题支持**：提供多种内置主题，支持自定义样式来适配不同项目需求。
9. **响应式设计**：支持在不同分辨率的设备上流畅使用。

**使用场景**：
1. **在线代码编辑器**：如 JSFiddle、CodePen 等。
2. **IDE 集成**：用于浏览器端开发工具，如 Chrome 开发者工具。
3. **学习平台**：提供交互式代码练习环境，如 LeetCode 和 Codecademy。
4. **文档管理**：用于编辑 Markdown、HTML、CSS 等格式的文档。
5. **协作编辑**：用于多人实时协作的代码工具。


**版本**：
- **CodeMirror 5** ：是经典版本，广泛应用于许多项目，基于 DOM 的渲染方式，支持大部分现代浏览器。
- **CodeMirror 6** ：是新一代版本，具有更高的性能和灵活性，使用模块化架构，基于 ProseMirror 的编辑器引擎，提供更好的可扩展性和流畅的用户体验。

# [CodeMirror 5](https://github.com/codemirror/codemirror5)

CodeMirror 5 是基于 **DOM**（文档对象模型）来渲染和管理代码内容。

## 核心组成部分

1. **文本模型**
    - CodeMirror 5 的文本内容由 `Document` 数据结构表示，这是其内部数据模型。
    - 每一行代码都是一个独立的对象，便于单行操作（如插入、删除、修改）。
    - 文本模型与编辑器的渲染是分离的，这使得修改文本内容时不需要立即重新渲染整个视图。
2. **DOM 渲染**
    - CodeMirror 5 依赖 DOM 元素来渲染代码内容，采用分行渲染策略。
    - 每一行代码是一个 `<div>` 或 `<pre>` 元素，通过样式控制每行的显示。
    - 使用 `position: absolute` 对行进行定位，从而支持滚动和行号渲染。
3. **滚动与视图管理**
    - **虚拟视图（Virtual Viewport）：**
        - CodeMirror 并非渲染整个文档，而是仅渲染当前视口内的代码行。
        - 当用户滚动时，动态加载或移除视图外的 DOM 节点以提高性能。
    - **同步滚动：**
        - 编辑器的滚动条与代码内容的滚动位置通过事件绑定实现同步。
4. **语法高亮**
    - CodeMirror 使用 **Tokenization（标记化）** 技术对代码进行解析和高亮。
    - 每个支持的编程语言都有一个“模式（Mode）”文件，其中定义了正则表达式来匹配特定的语言结构（如关键字、注释、字符串等）。
    - 文本被拆分为多个 Token，根据 Token 类型应用不同的 CSS 样式进行渲染。
5. **事件驱动**
    - CodeMirror 通过监听用户的键盘、鼠标事件对编辑器内容进行更新：
        - 按键触发文本插入或删除。
        - 鼠标点击触发光标移动。
        - 光标移动和内容修改会触发重新计算语法高亮或布局。
6. **增量更新**
    - CodeMirror 并不会在每次编辑后重绘整个编辑器，而是采用增量更新的方式：
        - 仅重新渲染被修改的部分行或受影响的区域。
        - 通过对 DOM 操作进行优化，减少不必要的重绘和重排。
7. **光标与选区**
    - 光标和选区通过 DOM 元素模拟。
    - 使用 `<span>` 或 `<div>` 元素作为光标或选区的占位符，通过 `class` 和样式进行渲染。
    - 支持多光标和多选区，底层数据结构管理所有光标位置和选区范围。
8. **插件与扩展**
    - CodeMirror 的插件体系基于事件机制和配置扩展。
    - 通过注册钩子函数，用户可以监听特定事件（如输入、滚动）并添加自定义逻辑。
    - 语法检查（lint）、自动补全、代码折叠等功能均由插件实现。


## 工作流程

1. **初始化**
    - `CodeMirror` 初始化时会将目标 `<textarea>` 替换为一个包含多个子层的 DOM 结构，包括：
        - **编辑层（content）**：负责渲染代码。
        - **滚动层（scrolling element）**：处理滚动条。
        - **背景层（gutter）**：显示行号或代码折叠标记。
2. **用户交互**
    - 用户通过键盘或鼠标操作时，CodeMirror 捕获相关事件并更新文本模型。
    - 更新后的模型触发增量渲染，生成新的 DOM 节点或更新现有节点。
3. **渲染过程**
    - 根据 `Document` 中的文本内容生成语法高亮后的 DOM 元素。
    - 调整 DOM 节点的位置和样式以确保与文本模型一致。
4. **性能优化**
    - **延迟加载：** 对长文本文件分块渲染。
    - **只渲染可见部分：** 减少对视图外行的 DOM 操作。
    - **缓存 Token：** 避免重复计算语法高亮。


## 关键优化点

1. **虚拟视口**
    - 仅渲染用户可见的代码行，大大减少了 DOM 节点的数量。
    - 当用户滚动时，动态加载新行，同时卸载不可见的行。
2. **分行渲染**
    - 每行代码作为独立的 DOM 节点，方便局部更新。
    - 文本更新时仅修改受影响的行，而不是重绘整个视图。
3. **语法高亮缓存**
    - CodeMirror 对每一行的高亮结果进行缓存，仅在行内容发生变化时重新计算。
    - 避免对未修改的行重复解析。
4. **精细化事件处理**
    - 使用 `requestAnimationFrame` 优化滚动事件和内容重绘，避免卡顿。
    - 合并频繁的用户输入事件，减少 DOM 操作次数。

## 优势与限制

**优势**
- **轻量级：** 不需要依赖复杂的渲染引擎，适合大多数浏览器。
- **灵活性：** 支持大量编程语言和自定义扩展。
- **浏览器兼容性：** 能够运行在较旧的浏览器上。

**限制**
- **性能瓶颈：** 基于 DOM 渲染，处理非常大的文档时性能可能下降。
- **复杂功能支持较弱：** 相比 Monaco Editor，CodeMirror 5 在实时协作和丰富的开发工具集成上稍显不足。




# [CodeMirror 6](https://codemirror.net/)

CodeMirror 6 是 CodeMirror 编辑器的新一代版本，完全重新设计，采用模块化和现代化的架构，旨在解决 CodeMirror 5 在性能、可扩展性和灵活性方面的局限性。它构建在 ProseMirror 编辑器引擎的基础上，具有更高的性能和更强的可扩展性，是现代 Web 应用程序理想的代码编辑解决方案。



## 核心特点

1. **模块化架构**
	- CodeMirror 6 完全模块化，所有功能都以独立的包提供（如语法高亮、主题、语言支持等）。
	- 通过按需加载模块，开发者可以仅引入需要的功能，从而减少代码体积。

2. **基于 State 的数据管理**、
	- 采用不可变状态模型，类似于 React 的状态管理。
	- 编辑器状态与视图完全分离，所有编辑操作通过更新状态实现，这使得状态管理更易于跟踪和调试。

3. **高性能**
	- 使用虚拟 DOM 技术渲染代码视图，仅更新发生变化的部分。
	- 支持处理超大文件，渲染时始终保持流畅。

4. **语法高亮**
	- 使用 Lezer 解析器框架提供语法解析，比传统的正则匹配更灵活。
	- 支持增量解析，确保即使在内容变更时也能高效地更新语法高亮。

5. **灵活的可定制性**
	- 开发者可以轻松自定义键盘快捷键、主题、语言模式和插件。
	- 提供强大的 API，用于扩展和增强编辑器功能。

6. **支持现代开发需求**
	- 原生支持 TypeScript，与现代前端工具链高度兼容。
	- 提供实时协作、Markdown 渲染、Lint 检查等插件。

7. **现代 UI 功能**
	- 多光标和多选区。
	- 弹出式工具提示（Tooltips）。
	- 代码折叠和块编辑。
	- 动态的语法提示和自动补全。


## 工作原理

1. **状态驱动**
    - 编辑器核心由一个不可变的状态对象（`EditorState`）驱动。
    - 用户输入、内容变化等事件触发状态的更新，通过状态驱动视图重新渲染。
2. **解析器和语法树**
    - 使用 Lezer 解析器生成语言的语法树（`syntax tree`），通过增量解析更新语法树，而非重新解析整个文档。
    - 语法树支持复杂语言的嵌套，例如 HTML 中的 `<script>` 和 `<style>` 部分。
3. **视图渲染**
    - 编辑器的渲染基于虚拟 DOM，仅更新受影响的部分 DOM 节点。
    - 支持分块渲染长文档，避免一次性加载全部内容导致性能问题。
4. **可扩展性**
    - 通过插件系统（Extensions），用户可以动态配置编辑器功能。
    - 每个插件可独立工作，也可以与其他插件组合使用。
