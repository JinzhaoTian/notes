[Yjs](https://yjs.dev/) 是一个高效的共享编辑框架，专门设计用于在分布式系统中实现实时协作功能，通过 CRDT（Conflict-free Replicated Data Type，无冲突复制数据类型）支持多用户同时编辑的文档，保证了数据的一致性和低延迟。


## 主要功能

1. **实时协作**
    - 允许多个用户同时编辑文档，并自动同步各个用户的更改。
    - 支持离线编辑和随后同步，利用 CRDT 算法来解决冲突。
2. **高效的数据结构**
    - Yjs 的核心是高效的 CRDT 数据结构，支持各种数据类型（文本、数组、Map 等）。
    - 通过细粒度的更新，只传输发生变化的部分，优化了带宽使用。
3. **持久化和离线支持**
    - 可选择将数据存储到本地（如 IndexedDB），从而支持断网操作。
    - 在用户重新连接时自动同步最新的更改。
4. **跨平台和灵活性**
    - 可以与多种网络传输协议（如 WebSocket、WebRTC、HTTP）结合。
    - 易于集成到前端框架（如 React、Vue.js）中，支持 Node.js 后端。
5. **模块化设计**
    - 提供核心库 `yjs`，同时支持扩展功能模块（如编码、网络同步、存储）。
    - 用户可以根据项目需求选择合适的模块。
6. **社区支持和生态系统**
    - Yjs 拥有丰富的插件和工具，例如：
        - `y-webrtc`：基于 WebRTC 的点对点网络同步。
        - `y-websocket`：基于 WebSocket 的网络同步。
        - `y-prosemirror` 和 `y-quill`：与流行的富文本编辑器集成。

## 使用场景

- **协作文本编辑**
    - 适用于构建 Google Docs 或 Notion 类的协作工具。
- **白板应用**
    - 支持多用户协作绘图、图形编辑。
- **在线代码编辑器**
    - 实现类似 VS Code Live Share 的多人实时编程功能。
- **实时数据同步**
    - 可用于多人游戏、实时仪表盘等需要多客户端数据同步的应用。
