That Open Engine 是一套用于快速构建网页端 3D BIM 应用的 JavaScript 工具库，完全免费且开源。 

## 主要组件

| 库名                               | 主要功能                                                |
| -------------------------------- | --------------------------------------------------- |
| **`@thatopen/components`**       | 核心库，提供构建 BIM 应用的基础功能模块，如相机、场景、分类器、剖切工具等。            |
| **`@thatopen/components-front`** | 前端专用工具，包含模型高亮等浏览器环境下的特有功能。                          |
| **`@thatopen/fragments`**        | 几何核心，负责高效处理和显示 3D BIM 数据。                           |
| **`@thatopen/ui`**               | UI 组件库，提供按钮、面板等通用界面元素，方便快速搭建应用界面。                   |
| **`@thatopen/ui-obc`**           | 功能UI组件，为 `components` 库的功能提供“即插即用”的界面，如一键导入 IFC 文件。 |

除了上述核心引擎，That Open 还开发了关键的底层库 `web-ifc`，这是一个用 C++ 编写、编译为 WebAssembly 的高性能 IFC 文件解析和几何处理引擎，能在浏览器中以原生速度读写 IFC 文件。
