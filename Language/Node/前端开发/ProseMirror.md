[ProseMirror](https://prosemirror.xheldon.com/) 是一个强大的 JavaScript 富文本编辑器框架，用于构建高定制化的编辑器，支持复杂文档的编辑和实时协作。它为开发者提供灵活的 API 和丰富的扩展功能，可以用于实现从简单的 WYSIWYG 编辑器到功能齐全的文档处理系统。

## 核心特性

1. **模块化设计**
    - ProseMirror 由多个独立的模块组成，如编辑核心模块、菜单模块、历史记录模块等，开发者可以根据需求自由组合。
2. **文档模型**
    - ProseMirror 使用一个 JSON 表示的文档模型来定义和操作文档内容，提供强大的灵活性，方便与其他系统集成。
3. **实时协作支持**
    - 内置支持实时协作功能，适用于多人同时编辑的场景，类似 Google Docs 的编辑体验。
4. **扩展性**
    - 通过插件机制，开发者可以自定义编辑行为和用户界面，比如添加自定义的菜单、快捷键、甚至特殊的文本处理逻辑。
5. **跨平台支持**
    - 兼容桌面端和移动端，针对不同设备和屏幕大小进行了优化。
6. **精确控制**
    - 提供对用户输入和光标位置的细粒度控制，可以实现一些复杂的编辑交互。


## 核心组件

1. **EditorState**
    - 表示编辑器的当前状态，包含文档内容、选择范围以及插件状态。
2. **EditorView**
    - 负责渲染文档和处理用户交互。
3. **Schema**
    - 定义文档的结构（如节点类型、内容约束），是 ProseMirror 的核心部分之一。
4. **Plugins**
    - 通过插件机制扩展编辑器功能，比如键盘快捷键、输入规则、工具栏功能等。
5. **Transactions**
    - 表示对文档状态的更改，确保文档变更过程的可预测性和一致性。
