
1. 构建生产版本
```bash
npm run build
```

构建完成后，生成的生产版本文件将位于项目的根目录下的 build 目录中，
```
├── build
│   ├── index.html
│   ├── static
│   │   ├── css
│   │   │   └── main.<hash>.css
│   │   └── js
│   │       └── main.<hash>.js
│   └── ...
└── ...
```

生产版本的 build/ 目录下的内容，要根据情况传到服务器上。

2. 创建 Dockerfile
```dockerfile
# 使用一个静态Web服务器作为基础镜像
FROM nginx:alpine

# 将React构建文件复制到Nginx默认的Web目录
COPY . /usr/share/nginx/html

# 暴露Nginx的80端口
EXPOSE 80

# 启动Nginx服务器
CMD ["nginx", "-g", "daemon off;"]
```

然后执行命令构建镜像，
```
docker build -t frontend .
```

或者说，从源代码开始构建：
```dockerfile
#使用官方的Node镜像作为构建环境
FROM node:14 as build

#设置工作目录
WORKDIR /app

#复制源代码到工作目录
COPY . .

#安装依赖并构建生产环境代码
RUN npm install
RUN npm run build

#使用Nginx作为Web服务器
FROM nginx:alpine

#复制构建好的代码到Nginx的默认目录
COPY --from=build /app/build /usr/share/nginx/html

#暴露80端口
EXPOSE 80

#启动Nginx
CMD ["nginx", "-g", "daemon off;"]
```
然后配置 docker-compose.yml 。
