## nvm

nvm（Node Version Manager）是一个独立的工具，需要单独安装。

### 主要功能

1. **安装多版本**：允许你在同一台电脑上安装多个不同版本的 Node.js。
2. **轻松切换**：通过简单的命令行，可以随时在已安装的各个 Node.js 版本之间进行切换，以适应不同项目的需求。
3. **解决兼容性**：避免了因 Node.js 版本不兼容导致的项目运行错误。

### 安装

- Using Homebrew (macOS/Linux)
```
brew install nvm
```

- Windows：使用一个独立的、社区维护的版本 `nvm-windows`



## fnm

fnm（Fast Node Manager）是一款用 Rust 编写的 Node.js 版本管理工具。

### 安装

- Using Homebrew (macOS/Linux)
```
brew install fnm
```

- Using Winget (Windows)
```
winget install Schniz.fnm
```
