
[Markdown Guide](https://www.markdownguide.org/)

## 渲染逻辑

Markdown 渲染逻辑主要包括以下几个步骤：
![](_imgs/Pasted%20image%2020250706205730.png)

1. **解析输入**：首先，读取输入的 Markdown 文本。Markdown 文本是纯文本格式，使用特定的标记来表示格式（例如，`#` 表示标题，`*` 表示无序列表）。
2. **构建语法树**：将输入的 Markdown 文本转换为语法树（Abstract Syntax Tree, AST）。这个过程涉及识别 Markdown 的不同元素（如标题、段落、列表、链接等）并构建相应的树形结构。
3. **生成 HTML**：从语法树生成 HTML。每种 Markdown 元素对应一个或多个 HTML 元素。例如，标题会被转换为 `<h1>`、`<h2>` 等标签，列表项会被转换为 `<ul>` 或 `<ol>` 和 `<li>`。
4. **渲染输出**：将生成的 HTML 输出到页面，通常是通过 DOM 操作将 HTML 插入到网页中。
5. **样式和交互**：在前端，可能会应用 CSS 样式来美化生成的 HTML，还可以添加 JavaScript 交互功能，比如显示/隐藏内容、处理链接等。


## Markdown 格式

### 基础格式

1. **标题**：使用 `#` 表示，支持 6 级标题：
```markdown
# 一级标题
## 二级标题
### 三级标题
```

2. **段落与换行**：直接书写文字形成段落，两个以上的空行或一个空行形成段落分隔；末尾添加两个空格换行。

3. **列表**：
	- **无序列表**：使用 `-`、`*` 或 `+` 开头。
	- **有序列表**：使用数字加 `.`。
```markdown
- 项目1
* 项目2
+ 项目3

1. 第一项
2. 第二项
```

4. **引用**：使用 `>` 表示嵌套引用。
```markdown
> 这是一个引用 
>> 嵌套引用
```

5. **代码**：
	- **行内代码**：使用反引号包裹。
	- **代码块**：使用三个反引号或四个空格缩进。

6. **加粗和斜体**
	- _斜体_：用 `*` 或 `_` 包裹。
	- **加粗**：用 `**` 或 `__` 包裹。
	- _**加粗加斜体**_：用 `***` 包裹。

7. **链接和图片**
	- **链接**：`[链接文字](链接地址)`
	- **图片**：`![图片描述](图片地址)`

8. **分隔线**：使用三个及以上的 `-`、`*` 或 `_` 。

9. **表格**：使用 `|` 和 `-` 来定义表格。
```markdown
| 列1  | 列2  |
| ---- | ---- |
| 数据1 | 数据2 |
```


### 扩展格式

1. **任务列表**
```markdown
- [ ] 未完成任务
- [x] 已完成任务
```

2. **脚注**
```markdown
这是一个脚注[^1]。
[^1]: 脚注内容。
```

3. **表情符号**（GitHub 风格）
```markdown
:smile: :heart:
```

4. **数学公式**：支持 LaTeX 公式。
```markdown
$$E = mc^2$$
```

5. **目录**：通过 `[TOC]` 自动生成目录。

6. **删除线**：使用 `~~` 包裹。

7. **高亮**：使用 `==` 包裹。

8. **自定义注释** / **警告块**
```markdown
:::warning
警告内容
:::
```
