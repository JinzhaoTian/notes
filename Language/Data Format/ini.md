`ini` 文件（Initialization File，初始化文件）是一种简单的文本配置文件格式，广泛用于存储应用程序的配置参数。它的结构清晰、易于读写，适合保存键值对、分组设置等数据。

## 主要特征

1. **轻量级**：纯文本格式，无需复杂解析
2. **可读性强**：内容直观，适合手动编辑
3. **跨平台**：几乎所有编程语言都支持解析
4. **分层结构**：支持分组（Section）和键值对（Key-Value）


## 基本结构

```ini
; 这是注释（以分号或井号开头）
[Section1]       ; 分组1
key1 = value1    ; 键值对
key2 = 123       ; 值可以是数字、字符串等

[Section2]       ; 分组2
path = C:\data   ; 路径或字符串
enabled = true   ; 布尔值
```

**关键组成部分**：
1. **分组（Section）**
    - 用方括号 `[ ]` 包裹，例如 `[Network]`。
    - 用于逻辑上区分不同配置模块。
2. **键值对（Key-Value）**
    - 格式为 `key = value`，等号两侧的空格通常可选。
    - 例如 `username = admin`。
3. **注释**
    - 以 `;` 或 `#` 开头，例如 `; 这是注释`。
4. **数据类型**
    - INI 本身无严格类型，**值均为字符串**，需程序自行转换（如整数、布尔值）。


## 应用场景

1. 保存软件设置（如窗口大小、语言选项）
2. 游戏中的图形/音效配置（如 `settings.ini`）
3. 数据库连接参数（如 `config.ini`）


## 解析

大多数语言提供内置库或第三方库解析 `ini` 文件：
- **C++**：需手动解析或使用库（如 `inih`）
- **C#**：`System.Configuration` 或第三方库 `INI-parser` 
- **Python**：`configparser` 模块
