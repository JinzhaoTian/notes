Protocol Buffers 是一种由 Google 开发的用于序列化结构化数据的跨平台、高效的**二进制数据格式**。

它常用于 [RPC](../../Computer%20Network/RPC.md)（远程过程调用）系统或持久化数据存储，因为它能够快速、紧凑地编码和解码数据，比 XML 或 JSON 更小、更快。

## 主要特点

1. **跨语言支持**：ProtoBuf 支持多种编程语言（如 C++、Java、Python、Go 等），使得在不同平台或系统之间传输数据更加容易。
2. **高效性**：ProtoBuf 采用二进制格式，比文本格式（如 JSON、XML ）更加紧凑和高效，能够在网络传输中节省带宽和加快解析速度。
3. **版本兼容性**：ProtoBuf 支持向前和向后兼容，意味着你可以在数据格式更新的同时保持旧版本的兼容性。这在长期维护的数据协议中非常有用。

## 工作流程

1. **定义数据结构**：使用 `.proto` 文件定义数据的结构。比如定义一个简单的消息：
```ProtoBuf
syntax = "proto3";

message Person {
  string name = 1;
  int32 id = 2;
  string email = 3;
}
```

2. **生成代码**：ProtoBuf 编译器会根据 `.proto` 文件生成相应编程语言的代码，来处理数据的序列化和反序列化。
3. **序列化和反序列化**：使用生成的代码将数据序列化为二进制格式，进行传输或存储，然后在接收端反序列化还原数据。

## 使用场景

- 网络协议：ProtoBuf 经常用于微服务之间的数据交换或 RPC 调用。
- 存储数据：在数据库中高效存储二进制数据，特别是对于大规模数据传输时。
- 移动设备：在移动应用中，由于带宽有限，ProtoBuf 可以帮助减少网络请求的大小。
