智能指针是 C++ 11 中引入的，用于自动管理动态分配内存的类模板，它们帮助防止内存泄漏，并在适当的时候自动释放内存。

在 C++ 中，动态内存的管理是通过一对运算符来完成的：`new` 和 `delete` ，动态内存的使用很容易出问题，因为确保在正确的时间释放内存是很困难的。 


## 主要类型

1. **`std::unique_ptr`**（C++ 11引入）
	- 独占所有权的智能指针
	- 同一时间只能有一个 `unique_ptr` 指向特定对象
	- 当指针被销毁时，它所指向的对象也会被自动删除
	- 不能复制，但可以移动
2. **`std::shared_ptr`**（C++ 11引入）
	- 共享所有权的智能指针
	- 多个 `shared_ptr` 可以指向同一个对象
	- 使用引用计数跟踪有多少指针指向同一对象
	- 当最后一个`shared_ptr`被销毁时，对象被删除
3. **`std::weak_ptr`**（C++ 11引入）
	- 弱引用指针，不增加引用计数
	- 用于解决 `shared_ptr` 的循环引用问题
	- 必须转换为 `shared_ptr` 才能访问所指向的对象
4. **`std::auto_ptr`** (C++ 98 引入，已弃用，C++17移除)
	- 有所有权转移语义
	- 由于设计问题，已被 `unique_ptr` 取代


## 使用建议

1. 优先使用 `unique_ptr` ，除非需要共享所有权
2. 避免使用裸指针（ `new` / `delete` ）
3. 使用 `make_shared` 和 `make_unique` （C++ 14）来创建智能指针，更安全高效
