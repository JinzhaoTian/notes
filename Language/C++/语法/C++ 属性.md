在 C++ 中，属性（Attributes）是一种用于向编译器提供额外信息的语法机制，允许开发者在代码中添加特定的注解，以控制编译、优化或代码生成行为。

属性是 C++ 11 标准引入的特性，后续标准（如 C++ 14、C++ 17、C++ 20）进一步扩展了其功能。

## 基本语法

属性通过 `[[...]]` 双括号语法表示，可以应用于以下位置：
- 函数、变量、类、枚举、代码块等。
- 某些属性支持参数，如 `[[deprecated("理由")]]`

```cpp
[[nodiscard]] int calculate(); // 函数属性
[[maybe_unused]] int x;       // 变量属性
```

## 对比装饰器

C++ 的属性和其他语言（如 Python、Java、JavaScript）中的装饰器（Decorators）在功能上有一定的相似性（都是为代码添加额外信息或行为），但它们在设计目标、语法和实现机制上有显著区别。

### 核心区别

| 特性       | C++ 属性 (Attributes)       | 其他语言的装饰器 (Decorators)             |
| -------- | ------------------------- | --------------------------------- |
| **目的**   | 提供编译期元数据，指导编译器行为（优化、警告等）。 | 动态或静态地修改类/函数的行为（如注入逻辑、扩展功能）。      |
| **执行时机** | 编译时处理，不改变运行时行为。           | 可能在编译时或运行时生效（依赖语言实现）。             |
| **语法**   | 双括号 `[[...]]`，标准化语法。      | 通常为 `@decorator` 或类似符号（如 Python）。 |
| **可扩展性** | 标准属性固定，编译器可扩展非标准属性。       | 通常允许用户自定义装饰器（如 Python 的函数装饰器）。    |
| **典型用例** | 抑制警告、标记废弃代码、优化内存布局等。      | 日志记录、权限检查、依赖注入、AOP 编程等。           |


## 对比 C# Attribute

C# 的特性（Attribute）类似于 C++ 的属性，但功能更强大，用于在运行时提供元数据。 C++ 的更偏向编译优化，而 C# 的 Attribute 更灵活，支持运行时反射。

### 核心区别

| **特性**     | **C++ Attributes** | **C# Attribute**   |
| ---------- | ------------------ | ------------------ |
| **作用**     | 编译期元数据（优化/警告）      | 运行时元数据（反射/AOP）     |
| **语法**     | `[[...]]`          | `[...]`            |
| **是否影响逻辑** | 否                  | 否（但可被反射读取）         |
| **自定义支持**  | 有限（依赖编译器）          | 是（可继承 `Attribute`） |
