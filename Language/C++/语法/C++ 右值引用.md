在 C++ 中，右值（Rvalue，Right-hand-side value）是表达式的一种属性，它表示一个临时的、无法被取地址的值，通常出现在赋值操作的右侧，因此得名右值。

理解右值是掌握移动语义和完美转发的基础。

## 右值分类

C++ 11 将右值进一步细分，
1. **纯右值（Pure Rvalue, prvalue）**：没有名字，不能被赋值
	- 字面量（`42`、`"hello"`）
	- 临时对象（`a + b`）
	- 返回非引用的函数调用（`func()`）
```c++
int a = 10;     // 10 是纯右值
int b = a + 2;  // a + 2 是纯右值
```

2. **将亡值（eXpiring Value, xvalue）**：
	- 即将被移动（`std::move`）的对象，或者通过右值引用返回的对象。
	- 有名字，但即将被销毁，可以安全窃取其资源。
```c++
std::string s1 = "hello";
std::string s2 = std::move(s1);  // s1 变成将亡值（xvalue）
```

## 右值引用

C++ 11 引入右值引用（Rvalue Reference， `&&`）用于绑定到右值，
```c++
int x = 10;     // x 是左值（可以取地址 &x）
int y = x + 5;  // x + 5 是右值（临时计算结果）
int&& z = 10;   // 10 是右值，z 是右值引用
```








## 左值分类

左值（Lvalue，Left-hand-side value）通常表示一个**有名字的**、**持久的**、**可以取地址**的对象，而右值则表示**临时的**、**无法取地址**的值。

左值是指：
- **可以出现在赋值表达式左侧**（即可以被赋值）
- **有明确的存储位置（内存地址）**（可以使用 `&` 取地址）
- **生命周期通常超出当前表达式**，不会在当前语句结束后立即销毁。

左值可以细分为，
1. **变量名**：
	- `int x;` ：`x` 是左值
2. **引用变量**：
	- `int& ref = x;`：`ref` 是左值
3. **数组元素**
	- `arr[0]`： 是左值
4. **返回左值引用的函数调用**
	- `std::cout << "Hi"` 返回 `std::ostream&`
5. **类成员变量**
	- `obj.member`： 是左值


## 左值引用

C++ 的左值引用（Lvalue Reference, `&`）只能绑定到左值，
```c++
int x = 10;
int& ref = x;   // 正确，x 是左值
int* p1 = &x;   // 正确，x 是左值，可以取地址

int& bad = 10;  // 错误！10 是右值，不能绑定到左值引用
int* p2 = &(x + 5); // 错误！x + 5 是右值，不能取地址
```

**例外**：**const 左值引用可以绑定到右值**
```c++
const int& cref = 10;  // 合法，const 左值引用可以绑定到右值
```


## 通用引用

通用引用（`T&&`）可以绑定左值和右值，
```c++
template <typename T>
void foo(T&& arg) {}  // arg 可以是左值或右值

int a = 10;
foo(a);   // arg 是左值引用
foo(10);  // arg 是右值引用
```
