
## Keyword

### `decltype(auto)`

`decltype(auto)` 是 C++ 14 引入的一个特性，它结合了 `auto` 的类型推导和 `decltype` 的精确类型推导规则。

#### 基本原理

1. **`auto` 的类型推导**
	- 会忽略引用和顶层 `const`
	- 对于 `const int& y = 10; auto x = y;`，`x` 的类型是 `int`，不是 `const int&`
```cpp
auto x = expr;  // 类型推导遵循模板参数推导规则
```

2. **`decltype` 的类型推导**
	- 保留所有类型信息（引用、const、volatile）
	- 对于 `const int& y = 10; decltype(y) x = y;`，`x` 的类型是 `const int&`
```cpp
decltype(expr) x = expr;  // 精确推导表达式的类型
```

3. **`decltype(auto)` 的类型推导**：结合了两者的优点：语法像 `auto`，推导规则像 `decltype`
```cpp
decltype(auto) x = expr;  // 使用 decltype 规则推导 auto 的类型
```

#### 使用示例

 1. **返回类型推导**
```cpp
// 传统方式：需要明确指定返回类型
template<typename T, typename U>
auto add1(T t, U u) -> decltype(t + u) {
    return t + u;
}

// C++14：使用 decltype(auto)
template<typename T, typename U>
decltype(auto) add2(T t, U u) {
    return t + u;  // 自动推导返回类型
}
```

```cpp
// 空值推导
template <typename T, typename... Args>
decltype(auto) JzWorld::AddComponent(JzEntity entity, Args &&...args)
{
    if constexpr (std::is_same_v<decltype(m_registry.emplace<T>(entity, std::forward<Args>(args)...)), void>) {
        m_registry.emplace<T>(entity, std::forward<Args>(args)...);
        return m_registry.get<T>(entity);
    } else {
        return m_registry.emplace<T>(entity, std::forward<Args>(args)...);
    }
}
```

2. **完美转发返回值**
```cpp
// 返回引用
int x = 10;
int& get_ref() {
    return x;
}

// 正确的方法：返回引用
decltype(auto) foo1() {
    return get_ref();  // 返回类型是 int&
}

// 错误的方法：失去引用
auto foo2() {
    return get_ref();  // 返回类型是 int（值拷贝）
}

// 测试
foo1() = 20;  // 正确：修改了 x 的值
foo2() = 20;  // 错误：返回值是临时对象
```


## Operator

### `[[...]]`

在 C++ 14 中定义的常见属性有：
1. **`[[deprecated]]`**：标记代码为已废弃，编译器会在使用时发出警告
```cpp
[[deprecated]] void oldFunction();
```



## `std::make_unique`

`std::make_unique` 是 C++14 引入的用于创建 `std::unique_ptr` 的工厂函数
### 优点

1. **异常安全**：防止内存泄漏
2. **更简洁**：不需要直接使用 `new`
3. **更高效**：避免了额外的内存分配
