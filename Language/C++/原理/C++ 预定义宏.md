
1. `__LINE__`：代表当前代码所在的行号
	- 类型：`int`
2. `__FILE__`：当前源文件的文件名
	- 类型：字符串
3. `__DATE__`：编译日期
	- 类型：字符串
	- 格式：`Mmm dd yyyy`（`Nov 19 2024`）
4. `__TIME__`：编译时间
	- 类型：字符串
	- 格式：`hh:mm:ss`（`14:30:25`）
5. `__func__`：当前函数名
	- 类型：字符串
	- 示例：`void test() { printf("当前函数：%s\n", __func__);}`，输出 `test`
6. `__FUNCTION__`：类似 `__func__`，某些编译器的扩展
