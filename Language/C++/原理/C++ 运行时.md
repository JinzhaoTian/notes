C 运行时库在编译和运行 C/C++ 程序时提供了基础的库函数实现和程序初始化、资源管理等支持，确保程序能够正常运行并管理其资源和环境。

# Runtime 原理

### 编译阶段

1. **编译源代码**：
    - 编译器（如 GCC 或 MSVC）将 C/C++ 源代码转换为目标代码（object code）。
    - 编译过程中，所有对标准库函数的调用（如 `printf`、`malloc`）都将被替换为对 CRT 中相应函数的调用。
2. **链接目标文件**：
    - 链接器将所有目标文件（.o 或 .obj 文件）和库文件链接在一起，生成最终的可执行文件。
    - 链接器会将 CRT 库（静态库或动态库）中的必要代码包含在可执行文件中。

### 链接 CRT

- **静态链接**：
    - CRT 的所有代码在编译时就被包含到最终的可执行文件中。
    - 优点：独立性强，不需要外部的运行时库。
    - 缺点：增加可执行文件的大小，每个应用程序有自己独立的 CRT 代码。
- **动态链接**：
    - CRT 的代码在运行时通过共享库（如 DLL 文件）加载。
    - 优点：可执行文件较小，多个应用程序可以共享同一个 CRT 实例。
    - 缺点：需要确保运行环境中存在所需的共享库。

### 运行时阶段

1. **程序启动**：
    - 当操作系统加载可执行文件时，会首先加载 CRT（如果是动态链接，则加载相应的 DLL）。
    - CRT 初始化环境，包括堆栈、全局变量、静态变量等。
2. **调用入口点**：
    - CRT 通常定义一个入口点（如 `_start` 或 `mainCRTStartup`），操作系统会先调用这个入口点。
    - 入口点会进行进一步的初始化，包括：
        - 设置命令行参数。
        - 初始化标准输入、输出和错误流。
        - 调用全局和静态对象的构造函数（对于 C++ 程序）。
3. **调用 `main` 函数**：
    - 初始化完成后，CRT 调用程序的 `main` 函数，开始执行用户代码。
4. **管理运行时行为**：
    - 在程序运行期间，CRT 提供各种运行时支持，包括内存管理、输入输出、字符串处理、数学运算等。
    - 这些功能通过 CRT 中的标准库函数实现，如 `malloc`、`free`、`printf`、`scanf` 等。
5. **程序终止和清理**：
    - 当 `main` 函数返回或调用 `exit` 函数时，CRT 开始终止过程。
    - 进行清理工作，包括：
        - 调用通过 `atexit` 注册的清理函数。
        - 释放动态分配的内存。
        - 关闭打开的文件和其他资源。
    - 最终，CRT 调用操作系统的系统调用，返回退出码并终止程序。

# Windows

## MSVCRT

MSVCRT（Microsoft Visual C++ Runtime），是 Windows 操作系统自带的 C 运行时库，提供了标准的 C 库函数以及一些 Windows 特有的扩展函数，包含了一些与现代标准**不完全兼容**的实现，例如对 C99 和 C11 标准的支持较差。

适用于老旧应用程序和需要与 Windows 原生 API 高度兼容的程序，早期版本随 Windows 95 和 Windows NT 一起发布。

## UCRT

UCRT（Universal C Runtime）是微软在 2015 年发布的一种新的 C 运行时库，旨在取代 MSVCRT ，提供了更符合现代标准的实现，全面支持 C99 和部分 C11 标准，设计更现代化，性能更高，并且在兼容性方面进行了改进。

UCRT 是 Windows 10 的一部分，并通过 Windows Update 提供给早期版本的 Windows。


# Linux

## glibc

glibc（GNU C Library）是 GNU 项目的 C 运行时库，广泛应用于 Linux 系统中，提供全面的标准 C 库实现以及 POSIX 兼容性。

几乎所有的 Linux 发行版都自带 glibc，因此无需额外安装。
## musl

musl 轻量级、快速、符合标准的 C 运行时库，旨在替代 glibc，常用于嵌入式系统和容器化应用。一些 Linux 发行版（如 Alpine Linux）默认使用 musl 而不是 glibc。安装这些发行版时，musl 会自动集成。

## dietlibc

dietlibc 是超小型 C 运行时库，旨在最小化代码大小和资源占用，如果使用该 runtime 需要手动集成。


# BSD

## libc

libc（BSD libc）BSD 系统的标准 C 运行时库，提供与 glibc 类似的功能，但在某些实现细节和特性上有所不同。


# 嵌入式

## newlib

newlib 适用于嵌入式系统的轻量级 C 运行时库，提供基本的 C 标准库函数实现。
