
## Keyword


### `if constexpr`

假设编写一个模板函数 `length`，对于具有 `.lenght()` 的成员函数的类型，返回调用；对于数值型的类型就返回数值。但是下面的写法不通过编译：

```C++
template<typename T>
auto length(const T& value) noexcept {
    if (std::is_integral<T>::value) { // is number
        return value;
       }
    else{
        return value.length();
    }
}

int main() noexcept {
    int a = 5;
    std::string b = "foo";

    std::cout << length(a) << ' ' << length(b) << '\n'; // doesn't compile
}
```

这是因为在实例化这个模板函数时，对于 int 类型，其形式就像：
```C++
auto length(const int& value) noexcept {
    if (std::is_integral<int>::value) { // is number
        return value;
    else
        return value.length();
}
```
但是 int 类型没有 `.lenght()` 成员函数，因为编译器不通过编译。

如果使用 `if constexpr` 代替 `if`，就意味着在编译期间就可以判断 `std::is_integral<T>::value` ，如果为 `true`，那么其他分支（ `else if` 或者 `else`）就会直接丢弃掉。

即，对于下面形式，
```C++
template<typename T>
auto length(const T& value) noexcept {
    if constexpr (std::integral<T>::value) { // is number
        return value;
    else
        return value.length();
}
```
在实例化期间，
```C++
int length(const int& value) noexcept {
    //if constexpr (std::is_integral<int>::value) { this branch is taken
        return value;
    //else                           discarded
    //    return value.length();     discarded
}

std::size_t length(const std::string& value) noexcept {
    //if constexpr (std::is_integral<int>::value) { discarded
    //    return value;                   discarded
    //else                           this branch is taken
        return value.length();
}
```

这样的话就可以通过编译。



## Operator

### `[[...]]`

在 C++ 17 中定义的常见属性有：
1. **`[[maybe_unused]]`**：抑制未使用变量/实体的编译器警告。
```cpp
[[maybe_unused]] int debugLog; // 避免未使用警告
```

2. **`[[fallthrough]]`**：在 `switch` 语句中显式标记故意的 `case` 穿透（避免警告）。
```cpp
switch (x) {
    case 1: doSomething(); [[fallthrough]];
    case 2: doMore(); // 无警告
}
```


## Expression


### Fold Expressions

折叠表达式（Fold Expressions）是 C++ 17 中引入的一项特性，旨在简化可变参数模板的处理。它允许开发者对模板参数包中的所有元素执行一个给定的操作符，从而将它们折叠成单一的值。

```cpp
template<typename... Args>
auto sum(Args... args) {
    return (args + ...); // 折叠表达式
}
```





## `std::optional`

`std::optional` 是 C++17 引入的一个模板类，用于表示一个可能包含值也可能不包含值的容器。它提供了一种类型安全的方式来表示可选值，避免了使用特殊值（如 nullptr、-1 等）或额外的布尔标志来表示值不存在的情况。

C++ 17 之前的版本可以通过 `boost::optional` 实现几乎相同的功能，`std::optional` 是处理可选值的现代 C++ 方式，比传统方法更安全、更清晰。

### 头文件

```c++
#include <optional>
```

### 使用示例

```c++
#include <optional>
#include <iostream>

std::optional<int> divide(int a, int b) {
    if (b == 0) {
        return std::nullopt; // 表示无值
    }
    return a / b;
}

int main() {
    auto result = divide(10, 2);
    if (result) {
        std::cout << "Result: " << *result << "\n"; // 解引用访问值
    } else {
        std::cout << "Division by zero!\n";
    }
    
    // 或者使用 value_or 提供默认值
    std::cout << "Result: " << result.value_or(0) << "\n";
}
```

### 常用操作

1. `has_value()`
	- 检查是否包含值
2. `value()`
	- 获取值，如果无值则抛出 `std::bad_optional_access`
3. `value_or(default)`
	- 获取值或返回默认值
4. `operator*` 和 `operator->`
	- 直接访问存储的值
5. `reset()` 或 `= std::nullopt`
	- 清除存储的值





## `std::filesystem`

`std::filesystem` 是 C++17 标准引入的文件系统库，提供了一套跨平台的接口，用于操作文件系统路径、目录、文件及权限等。它封装了底层操作系统的文件操作功能（如 Windows、Linux、macOS），使开发者能编写可移植的代码。

### 头文件

```c++
#include <filesystem>
```

### 核心组件

1. **`std::filesystem::path`**
	- 表示文件系统路径，自动处理不同操作系统的路径格式（如 Windows 的 `\` 和 Linux 的 `/`）
2. **目录操作函数**
	- `create_directory()`
	- `create_directories()`：创建目录
	- `remove()`
	- `remove_all()`：删除
	- `directory_iterator`
	- `recursive_directory_iterator` ：遍历目录
3. **文件操作函数**
	- `copy()`：复制
	- `copy_file()`
	- `rename()`：重命名/移动
	- `file_size()`：查询文件属性
	- `last_write_time()`
	- `exists()`：状态检查
	- `is_regular_file()`
	- `is_directory()`
4. **文件状态与权限**
	- `file_status`
	-  `perms`


### 使用示例

```c++
#include <iostream>
#include <filesystem>

int main() {
	std::filesystem::path dir = "my_folder";
    std::filesystem::create_directories(dir); // 创建目录

    std::filesystem::path file = dir / "data.txt"; // 路径拼接
    std::ofstream(file).put('a');    // 创建文件

    // 检查文件属性
    if (std::filesystem::exists(file) && std::filesystem::is_regular_file(file)) {
        std::cout << "文件大小: " << std::filesystem::file_size(file) << " 字节\n";
    }
    
    std::filesystem::remove_all(dir); // 递归删除目录
    return 0;
}
```

## `std::string_view`

`std::string_view` 是 C++ 17 标准库中引入的一个重要特性，它提供了一种非所有权的、轻量级的字符串视图。

`std::string_view` 的**核心目标**解决在处理字符串时，特别是 `std::string` 和 C-style 字符串（`const char*`）在函数传参和子串操作中，因不必要的内存分配和数据拷贝所导致的性能开销。

`std::string_view` 的**核心优势**在于其**零拷贝**特性，它允许我们像操作 `std::string` 一样操作一个字符串，但几乎没有额外的性能成本，实现了对底层字符序列的高效只读访问。
