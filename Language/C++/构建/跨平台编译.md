
## 线程库

在 C/C++ 中，多线程编程不是语言本身的一部分，而是通过操作系统提供的 API 实现的。

- **Linux/macOS**：使用 `pthread` 库。你需要编译时加 `-pthread` 标志（它既是一个编译标志，也是一个链接标志）。
- **Windows**：使用 `windows.h` 中的 `CreateThread` 等 API，通常不需要链接单独的库，但需要一些特定的宏定义（如 `_WIN32_WINNT`）。

`FindThreads.cmake` 脚本的神奇之处就在于它自动为你处理了所有这些平台差异。你只需要简单地链接 `Threads::Threads`，CMake 就会在 Linux 上为你添加 `-pthread`，在 Windows 上设置正确的定义，而在 macOS 上也会进行相应的配置。

```cmake
cmake_minimum_required(VERSION 3.16) # 确保版本足够新
project(MyProject)

# 查找系统线程库，必须找到
find_package(Threads REQUIRED)

# 添加你的可执行文件
add_executable(my_app main.cpp)

# 将可执行文件与线程库进行链接。
# 推荐使用现代的目标属性方法：
target_link_libraries(my_app PRIVATE Threads::Threads)

# 旧式的变量方法（不推荐，但需要了解）：
# target_link_libraries(my_app PRIVATE ${CMAKE_THREAD_LIBS_INIT})
```
