`__attribute__` 是 GCC 和 Clang 等编译器提供的一种编译器扩展，**核心作用**是允许开发者向编译器提供关于代码（变量、函数、类型等）的额外信息，从而指导编译器进行更特定的优化、更严格的检查或生成更特殊的代码。

简单来说，它是一种给编译器“提要求”或“给提示”的机制。

```cpp
__attribute__((attribute_name))

__attribute__((annotate(__VA_ARGS__)))
```

### 关键要点

1. **非标准 C++**：`__attribute__` 不是 C++ 标准的一部分，这意味着使用了它的代码在其它编译器（如 MSVC）上可能无法编译。
	- 在 MSVC 中，可以用 `__declspec(annotate(__VA_ARGS__))` 替代
2. **可移植性问题**：如果你希望代码能在不同编译器上编译，你需要使用预处理器指令（如 `#ifdef __GNUC__`）来包装 `__attribute__` 语句。
