
## Keyword 

### `concept`

 `concept` 是 C++ 20 引入的关键字，主要用于改进模板编程，是一种**对模板参数进行约束**的机制，允许在编译时指定模板参数必须满足的要求。

#### 基本语法

```c++
template <typename T>
concept MyConcept = requires(T t) {
    // 要求列表
    t.some_method();  // 类型T必须有some_method成员函数
    typename T::value_type;  // 类型T必须有value_type成员类型
};
```

#### 使用示例

```c++
#include <concepts>
#include <iostream>

// 定义一个概念
template <typename T>
concept Addable = requires(T a, T b) {
    { a + b } -> std::same_as<T>;  // 要求a+b返回类型也是T
};

// 使用概念约束模板
template <Addable T>
T add(T a, T b) {
    return a + b;
}

// 另一种使用概念的语法
template <typename T>
requires Addable<T>
T subtract(T a, T b) {
    return a - b;
}

int main() {
    std::cout << add(1, 2) << std::endl;  // 正确，int满足Addable
    // std::cout << add("a", "b") << std::endl;  // 错误，字符串不满足Addable
}
```

#### 主要概念

C++ 20 标准库头文件 `<concepts>` 提供了许多预定义的 `concepts`，例如：
1. `std::integral`：
	- 要求类型是整数类型
2. `std::floating_point`
	- 要求类型是浮点类型
3. `std::same_as`
	- 要求类型与指定类型相同
4. `std::derived_from`
	- 要求类型派生自指定类型
5. `std::convertible_to`
	- 要求类型可转换为指定类型




### `requires`

`requires` 是 C++20 引入的关键字，极大地改善了模板编程的体验，提供了更好的类型安全和更清晰的错误信息。

#### 主要用途

- **定义 `concepts` 中的约束条件**：指定类型必须满足的要求
```c++
template <typename T>
concept Addable = requires(T a, T b) {
    a + b;  // 要求类型T必须支持+操作
    { a + b } -> std::same_as<T>;  // 要求a+b的结果类型也是T
};
```

- **对模板施加约束**：在模板声明中直接添加约束
```c++
// 方法1: 在模板参数列表后
template <typename T>
requires Addable<T>
T add(T a, T b) 
{
	return a + b;
}

// 方法2: 作为函数声明的一部分
template <typename T>
T multiply(T a, T b) requires Multipliable<T> 
{
	return a * b;
}

// 方法3: 直接使用requires表达式
template <typename T>
requires requires(T x) { x / 2; }  // 第一个requires开始约束，第二个开始requires表达式
T half(T x)
{
	return x / 2;
}
```

#### `requires` 表达式

`requires` 表达式是一种**编译时布尔表达式**，用于检查类型是否满足特定要求：
```c++
template <typename T>
constexpr bool is_serializable = requires(T t, std::ostream& os) {
    os << t;  // 要求T类型支持<<操作符
};
```

`requires` 表达式可以包含四种类型的子句：
1. **简单要求**：检查表达式是否有效
2. **类型要求**：检查类型是否存在
3. **复合要求**：检查表达式属性（如返回类型）
4. **嵌套要求**：检查布尔常量表达式



#### 使用示例

```c++
#include <concepts>
#include <iostream>

template <typename T>
concept Printable = requires(T t) {
    { std::cout << t } -> std::same_as<std::ostream&>;
};

void print(const Printable auto& value) {
    std::cout << value << std::endl;
}

int main() {
    print(42);      // 正确，int是可打印的
    // print(std::vector<int>{});  // 错误，vector不可打印
}
```


## Operator

### `[[...]]`

在 C++ 20 中新增或改进的常用属性有：
1. **`[[likely]]`** 和 **`[[unlikely]]`**：提示编译器某个条件分支更可能（`likely`）或不太可能（`unlikely`）被执行，以优化分支预测。
```cpp
if (condition) [[likely]] {
    // 更可能执行的代码
} else [[unlikely]] {
    // 不太可能执行的代码
}
```

2. **`[[nodiscard]]` 增强**：用来标记函数或类型的返回值不应被忽略，否则编译器会发出警告，C++ 20 允许附加原因字符串。
```cpp
[[nodiscard("必须处理返回值")]] int compute();
```

3. **`[[no_unique_address]]`**：允许非静态数据成员与其他成员共享内存地址，优化空类（如无状态分配器）的内存占用。
```cpp
struct Empty {};
struct S {
    int x;
    [[no_unique_address]] Empty e;  // 可能不占用额外内存
};
```

4. **`[[deprecated]]` 增强**：标记已弃用的代码，C++ 20 允许提供弃用原因。
```cpp
[[deprecated("改用新API")]] void old_func();
```
