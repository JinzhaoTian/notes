

## Keyword

### `auto`

`auto`是 C++ 11 引入的关键字，让编译器在编译器就推导出变量的类型，可以通过=右边的类型推导出变量的类型。

```C++
auto a = 10; // 10是int型，可以自动推导出a是int

string str("hello world");
for (auto c : str) {
    cout << c;
}
```


### `decltype`

`decltype` 是 C++ 11 引入的关键字，用于**查询表达式的类型**，但不实际计算表达式的值。


#### 推导规则

1. **表达式是标识符或类成员访问**
```cpp
int x;
decltype(x)     // int

const int cx = 10;
decltype(cx)    // const int

int arr[10];
decltype(arr)   // int[10]（数组类型）
```

2. **表达式是左值**（非纯右值）
```cpp
int x = 10;
decltype((x))   // int&（额外的括号使x成为左值表达式）

int arr[10];
decltype(arr[0]) // int&（下标操作返回左值）

int* p = &x;
decltype(*p)    // int&（解引用返回左值）
```

3. **表达式是纯右值**
```cpp
int x = 10;
decltype(x + 5)   // int（x+5是纯右值）
decltype(42)      // int
```

#### 实用示例

1. **模板编程中的类型推导**
```cpp
template<typename T, typename U>
auto add(T t, U u) -> decltype(t + u) {
    return t + u;
}
// C++14 后可以简化为：
template<typename T, typename U>
decltype(auto) add(T t, U u) {
    return t + u;
}
```

2. **完美转发返回值**
```cpp
template<typename Container, typename Index>
decltype(auto) access(Container& c, Index i) {
    return c[i];  // 保持返回类型（可能是引用）
}
```

3. **在变量声明中使用**
```cpp
std::vector<int> vec = {1, 2, 3};
decltype(vec)::value_type x = 10;  // x 的类型是 int

// 用于 lambda 参数
auto lambda = [](decltype(vec) v) {
    return v.size();
};
```


#### 常见陷阱

```cpp
int x = 10;

decltype(x)   a = x;    // int
decltype((x)) b = x;    // int&（注意括号的差异！）

// 错误示例：decltype 需要编译时可确定的表达式
int y = 20;
decltype(x + y) z;      // OK：编译时可确定
// decltype(std::cin >> x) w;  // 可能有问题：涉及运行时
```



### `noexcept`

`noexcept` 是 C++ 11 引入的关键字，用于指定函数是否会抛出异常，是异常规范（exception specification）的一种现代形式，比旧的 `throw()` 更高效且更易于使用。

#### 主要特性

- **性能优势**：编译器可以对 `noexcept` 函数进行更好的优化
- **移动语义**：标准库容器在重新分配时会优先使用 `noexcept` 移动构造函数
- **终止程序**：如果 `noexcept` 函数确实抛出了异常，程序会调用 `std::terminate()`
- **比 `throw()` 更好**：`noexcept` 不会带来运行时开销，而 `throw()` 可能有


#### 常用操作

1. **作为说明符**：表示函数不会抛出任何异常
```c++
void myFunction() noexcept {
	// 这个函数保证不会抛出异常
}
```

2. **作为运算符**：检查表达式是否可能抛出异常
```c++
bool willThrow = noexcept(myFunction()); // 返回true，因为myFunction是noexcept的
```

#### 主要形式

1. **无条件 `noexcept`**
```c++
void func() noexcept; // 保证不抛出异常
```

2. **条件 `noexcept`**
```c++
void func() noexcept(noexcept(expression)); // 根据表达式结果决定是否noexcept
```


#### 使用建议

- 对于明确不会抛出异常的函数，使用 `noexcept`
- 移动构造函数和移动赋值运算符通常应该标记为 `noexcept`
- 析构函数默认就是 `noexcept` 的，通常不需要显式声明
- 标准库算法和容器会利用 `noexcept` 信息进行优化

#### 使用示例

```c++
class MyClass {
public:
    // 移动构造函数标记为noexcept
    MyClass(MyClass&& other) noexcept {
        // 移动资源
    }
    
    // 条件noexcept
    void swap(MyClass& other) noexcept(noexcept(std::swap(data, other.data))) {
        std::swap(data, other.data);
    }
    
private:
    int* data;
};
```


### `constexpr`

`constexpr` 是 C++ 11 引入的关键字，用于指定表达式、函数或对象在编译时求值（compile-time evaluation）。

它的主要目的是允许更多的计算在编译期间完成，而不是在运行时完成，从而提高性能并支持更多的编译时检查。

然而，在 C++ 11 中 `constexpr` 函数有诸多的严格限制（例如：每个 `constexpr` 函数的定义本质上都只能有一个 return 语句），但是这些限制在 C++ 14 中大多数都被取消了。当然，成功计算 `constexpr` 函数仍然需要所有的计算步骤在编译期都是可行且有效的：当前，在堆上内存分配和异常抛出都是不被支持的。

C++ 11 允许将变量声明为 `constexpr` 类型以便由编译器来验证变量的值是否是一个常量表达式。

```C++
constexpr int m = 20;        // 20是一个常量表达式
constexpr int s = size();    // 只有当size()是一个constexpr函数时才正确
```

### `using`

`using` 关键字在 C++ 98 / C++ 03 已经引入，其功能为：引入命名空间、命名空间别名等。在 C++ 11 中新增功能为： 

1. **类型别名（替代 `typedef`）**
```c++
using MyInt = int;  // C++11 新增
```

2. **模板别名**：
```c++
template<typename T>
using Vec = std::vector<T>;  // C++11 新增
```

3. **继承构造函数**：
```c++
class Base {
public:
    Base(int) {}
};

class Derived : public Base {
public:
    using Base::Base;  // C++11 新增，继承构造函数
};
```

#### 后续标准中的增强

- C++ 17 对 `using` 的继承构造函数进行了改进
- C++ 20 引入了 `using enum` 语法



## Operator

### `&&`

在 C++ 中，`&&` 有两种含义：

#### 逻辑与

当 `&&` 用作二元运算符时，它是**逻辑与**（Logical AND）操作符，它要求两个操作数都是 `true`（非零），结果才为 `true`，否则为 `false`：
```c++
if (a > 0 && b < 10) {
    // 只有当 a > 0 且 b < 10 都为真时，才会执行
}
```

> [!info]- 短路求值
> **短路求值（Short-Circuit Evaluation）**：如果第一个操作数为 `false`，则不会计算第二个操作数。

#### [右值引用](语法/C++%20右值引用.md)

右值引用（Rvalue Reference）是 C++ 11 引入的含义，用于支持[移动语义](语法/C++%20移动语义.md)和[完美转发](语法/C++%20完美转发.md)。

> [!info]- 右值
> **右值（Rvalue）** 是表达式的一种属性，它表示一个**临时的**、**无法被取地址**的值，通常出现在赋值操作的右侧，因此得名右值。

> [!info]- 左值
> **左值（Lvalue）** 通常表示一个有名字的、持久的、可以取地址的对象，
> - 可以出现在赋值表达式左侧（即可以被赋值）
> - 有明确的存储位置（内存地址）（可以使用 `&` 取地址）
> - 生命周期通常超出当前表达式，不会在当前语句结束后立即销毁。

> [!info]- 移动语义
> **移动语义（Move Semantics）** 允许资源（如动态内存、文件句柄等）的所有权从一个对象转移到另一个对象，而不是进行昂贵的复制操作

> [!info]- 完美转发
> **完美转发（Perfect Forwarding）** 允许函数模板将其参数无损地转发给其他函数，保持参数的原始类型，避免额外的拷贝。

右值引用可以绑定到右值（临时对象），允许高效地**移动**资源而非复制。

```c++
void foo(int&& x); // x 是右值引用，只能绑定到右值（如临时变量）

int a = 5;
foo(10);     // 合法，10 是右值
foo(a);      // 非法，a 是左值
foo(std::move(a)); // 合法，std::move 将 a 转为右值
```

##### 用途

- `MyClass(MyClass&& other)`：移动构造函数
- `MyClass& operator=(MyClass&& other)`：移动赋值运算符
- `std::forward<T>(arg)`：完美转发


### `[[...]]`

 C++ 11 中引入双中括号 `[[...]]` 语法，用来表示属性（Attributes），并在后续标准中不断扩展。

属性可以应用于以下位置：
1. 函数、变量、类、枚举、代码块等
2. 某些属性支持参数，如 `[[deprecated("理由")]]` 

在 C++ 11 中定义的常见属性有：
1. **`[[nodiscard]]`**：要求调用者必须处理函数的返回值，如用于避免忽略错误码。
	- 如果返回值未被使用，编译器会发出警告。
```cpp
[[nodiscard]] int openFile();
```

2. **`[[noreturn]]`**：表示函数不会返回，如终止程序或无限循环。
```cpp
[[noreturn]] void fatalError() { exit(1); }
```

#### 后续标准中的增强

1. C++ 14：
	- `[[deprecated]]`
2. C++ 17：
	- `[[fallthrough]]` 
	- `[[maybe_unused]]`
3. C++ 20：
	- `[[likely]]` 
	- `[[unlikely]]` 
	- `[[nodiscard]]` 增强
	- `[[no_unique_address]]` 
	- `[[deprecated]]` 增强


#### 编译器特定属性

不同编译器可能支持额外的非标准属性（需查阅文档）：
- **GCC/Clang**：`[[gnu::always_inline]]`、`[[gnu::visibility("hidden")]]`
- **MSVC**：`[[msvc::noop]]`

### Variadic Templates

可变参数模板（Variadic Templates）是 C++ 11 引入的一个重要特性，允许模板接受任意数量和类型的参数。

可变参数模板使用省略号（`...`）语法来表示可以接受任意数量的参数：
```cpp
template<typename... Args>
class MyClass {};

template<typename... Args>
void myFunction(Args... args) {}
```

- `Args` 是模板参数包（template parameter pack）
- `args` 是函数参数包（function parameter pack）

#### 使用场景

1. **递归展开**：最常见的用法是通过递归方式处理参数包：
```c++
// 基础情况
void print() {
    std::cout << std::endl;
}

// 递归情况
template<typename T, typename... Args>
void print(T first, Args... args) {
    std::cout << first << " ";
    print(args...); // 递归调用
}
```

2. **折叠表达式**：C++ 17引入了折叠表达式，简化了可变参数模板的使用：
```c++
template<typename... Args>
auto sum(Args... args) {
    return (args + ...); // 折叠表达式
}
```

3. **完美转发**：可变参数模板常用于实现完美转发：
```c++
template<typename... Args>
void wrapper(Args&&... args) {
    some_function(std::forward<Args>(args)...);
}
```



## `std::move`

`std::move` 是 C++ 11 引入的一个标准库函数，用于将对象标记为可移动（转换为右值引用），从而启用[移动语义](语法/C++%20移动语义.md)而非复制语义。

### 头文件

```c++
#include <utility>
```

### 函数原型

```c++
template <typename T>
typename std::remove_reference<T>::type&& move(T&& arg) noexcept;
```

### 使用示例

```c++
std::vector<int> v1 = {1, 2, 3};
std::vector<int> v2 = std::move(v1);  // 调用移动构造函数

// v1现在处于有效但未指定状态（通常为空）
```

### 主要特性

1. **不实际移动数据**：只是将对象标记为可移动
```c++
int x = 10;
int&& y = std::move(x);  // 只是类型转换，x的值仍是10
```

2. **移动后的源对象**：
	- 处于有效但未指定的状态
	- 通常应该不再使用或重新赋值
	- 标准库类型通常会被置为空状态

3. **与移动构造函数/赋值的关系**：
```c++
// 以下两行等价
T b = std::move(a);
T b(static_cast<T&&>(a));
```

### 应用场景

1. **转移资源所有权**：
```c++
std::unique_ptr<int> p1(new int(42));
std::unique_ptr<int> p2 = std::move(p1);  // p1 现在为nullptr
```

2. **优化返回值**：
```c++
std::vector<int> createVector() {
    std::vector<int> tmp;
    // ...填充数据...
    return std::move(tmp);  // C++ 17 起不需要，NRVO 会优化
}
```

> [!info]- NRVO
> NRVO（Named Return Value Optimization，命名返回值优化）是 C++ 编译器中的一种优化技术，用于消除函数返回局部对象时的额外拷贝或移动操作。
> 
> NRVO 允许编译器跳过中间的拷贝/移动步骤，直接在调用方准备的内存位置上构造返回的对象。

> [!info]- RVO
> RVO（Return Value Optimization，返回值优化）适用于返回匿名临时对象，NRVO 适用于返回命名局部对象（Named Return Value Optimization）。

```c++
std::string createString() {
    std::string s = "Hello, NRVO!";
    return s;                              // 通常这里会触发 NRVO
}

std::string createString() {
    return std::string("Hello, RVO!");     // 触发 RVO
}
```

3. **在容器中插入可移动对象**：
```c++
std::vector<std::string> v;
std::string s = "data";
v.push_back(std::move(s));  // s 现在可能为空
```


### 注意事项

1. **不要移动局部变量后继续使用**：
```c++
std::string s = "hello";
std::string s2 = std::move(s);
// s的内容现在不确定，使用它是未定义行为
```

2. **基本类型无移动优势**：
```c++
int a = 5;
int b = std::move(a);  // 仍然会复制，无性能提升
```

3. **不是所有类型都支持移动**：如果没有移动构造函数，会回退到复制操作





## `std::forward`

`std::forward` 是 C++ 11 引入的一个标准库函数，用于实现[完美转发](语法/C++%20完美转发.md)，是与**通用引用**（`T&&`）配合使用的关键组件，用于在模板函数中保持参数的原始值类别（左值或右值）。

### 头文件

```c++
#include <utility>
```

### 函数原型

```c++
template <class T>
constexpr T&& forward(typename std::remove_reference<T>::type& t) noexcept;

template <class T>
constexpr T&& forward(typename std::remove_reference<T>::type&& t) noexcept;
```


### 使用示例

```c++
#include <utility>
#include <iostream>

void process(int& x) { std::cout << "处理左值: " << x << std::endl; }
void process(int&& x) { std::cout << "处理右值: " << x << std::endl; }

template <typename T>
void wrapper(T&& arg) {
    process(std::forward<T>(arg));  // 完美转发
}

int main() {
    int x = 10;
    wrapper(x);      // 调用左值版本
    wrapper(20);     // 调用右值版本
}
```


### 应用场景

1. **工厂函数**：创建对象并转发构造参数
```c++
template <typename T, typename... Args>
std::unique_ptr<T> make_unique(Args&&... args) {
    return std::unique_ptr<T>(new T(std::forward<Args>(args)...));
}
```
2. **包装器函数**：将参数无损地传递给下层函数
3. **通用容器操作**：如 `emplace_back` 实现


### 注意事项

1. **只应在模板函数中使用 `std::forward`**
2. 通常只转发每个参数一次
3. 不要对函数局部变量使用 `std::forward`（除非明确知道其生命周期）
4. 过度使用可能降低代码可读性

## `std::enable_shared_from_this`

`std::enable_shared_from_this` 是 C++ 11 引入的一个类模板，允许一个对象安全地生成指向自身的 `std::shared_ptr`，而不会意外地创建出一个新的、独立的 `shared_ptr`（这会导致重复析构等问题）。

当对象已经被 `std::shared_ptr` 管理时，如果需要在对象内部获取指向自身的 `std::shared_ptr`，就应该使用 `enable_shared_from_this`。

### 头文件

```cpp
#include <memory>
```

### 使用示例

```cpp
class Foo : public std::enable_shared_from_this<Foo> {
public:
    void process() {
        // 正确：shared_from_this 返回一个与现有 shared_ptr 共享所有权的 shared_ptr
        std::shared_ptr<Foo> local_ptr = shared_from_this();
        // 使用 local_ptr...
    } // 不会导致双重删除
};
```

## `std::reference_wrapper`

`std::reference_wrapper` 是 C++ 11 引入的一个类模板，它将一个引用包装成一个可拷贝、可赋值的对象，主要用于解决标准容器（如 `vector`, `list`, `map` 等）**不能直接存储引用**的问题。

> [!tip] 为什么需要它？
> 直接的问题是**容器不能直接存储引用**：
> ```cpp
> std::vector<int&> vec;  // 错误！不能创建引用的容器
> ```
> 解决方案：使用 `std::reference_wrapper`，
> ```cpp
> std::vector<std::reference_wrapper<int>> vec;
> ```

> [!caution]- 为什么容器不能直接存储引用?
> 容器不能直接存储引用有多个根本原因，涉及到 C++ 语言设计、类型系统和内存模型等多个层面。
> 1. **引用不是对象，而是别名**：引用在 C++ 中不是一个独立的对象，而是一个已存在对象的别名。它没有自己的存储空间，只是在编译时的一个符号。
> ```cpp
> int x = 10;
> int& ref = x;  // ref只是x的另一个名字，没有独立的内存地址
> ```
> 2. **引用必须在初始化时绑定，且不能重新绑定**：
> ```cpp
> int a = 1, b = 2;
> int& ref = a;   // OK
> ref = b;        // 这是赋值给a，不是重新绑定！a现在等于2
> int& ref2;      // 错误！引用必须初始化
> ```
> 3. **引用的地址不可获取**：引用没有自己的地址，对引用取地址得到的是它所引用的对象的地址
> ```cpp
> int x = 10;
> int& ref = x;
> cout << &ref;  // 输出的是x的地址，不是"ref的地址"
> ```
> 4. **引用的默认构造问题**：所有标准容器类型 `T` 都必须满足 `T` 是**可默认构造的**，但**引用不能默认构造**：
> ```cpp
> template<class T>
> class vector {
>     // ...
>     T* data;  // 需要分配T类型的数组
>     data = new T[size];  // 每个元素需要默认构造
> };
> ```
> 5. **引用的赋值语义问题**：容器的很多操作（`resize`，`insert`，`erase`等）需要赋值元素
> ```cpp
> // 如果T是引用
> T a = x;  // 初始化
> T b;      // 错误！不能默认构造
> b = a;    // 引用赋值是给引用的对象赋值，不是复制引用本身
> ```


### 头文件

```cpp
#include <functional>
```

### 主要特性

1. **可复制和可赋值**
```cpp
int x = 10, y = 20;
std::reference_wrapper<int> ref1 = x;       // 包装引用
std::reference_wrapper<int> ref2 = ref1;    // 可以复制
ref2 = y;                                   // 可以重新赋值
```

2. **隐式转换为原始引用**
```cpp
int value = ref1;  // 隐式转换为 int&
func(ref1);        // 如果 func 接受 int&，可以隐式转换
```

3. **支持 `get()` 方法获取引用**
```cpp
int& raw_ref = ref1.get();  // 获取底层引用
```





## `std::function`

`std::function` 是 C++ 11 引入的一个通用的函数包装器，它可以存储、复制和调用任何可调用对象（函数、lambda 表达式、绑定表达式或其他函数对象）。

### 头文件

```c++
#include <functional>
```

### 主要特性

1. **多态函数包装器**：可以保存多种不同类型的可调用对象
```cpp
#include <functional>
#include <iostream>

void print_num(int i) {
    std::cout << i << '\n';
}

int main() {
    // 包装自由函数
    std::function<void(int)> f1 = print_num;
    f1(42);
    
    // 包装lambda表达式
    std::function<void()> f2 = []() { print_num(123); };
    f2();
    
    // 包装函数对象
    struct Print {
        void operator()(int i) const {
            std::cout << i << '\n';
        }
    };
    std::function<void(int)> f3 = Print();
    f3(456);
}
```

2. **类型擦除**：隐藏了具体可调用对象的实际类型

3. **安全调用**：可以检查是否包含有效函数，默认构造的 `std::function` 不包含可调用对象
```cpp
std::function<void()> f;
if (!f) { // 检查是否为空
    std::cout << "f is empty\n";
}
```

4. **与bind配合使用**：
```cpp
void print_sum(int a, int b) {
    std::cout << a + b << '\n';
}

std::function<void(int)> f = std::bind(print_sum, 10, std::placeholders::_1);

f(20); // 输出30
```

5. **作为回调函数**：
```cpp
class Button {
public:
    std::function<void()> onClick;
    void click() {
        if (onClick) onClick();
    }
};

Button btn;
btn.onClick = []() { std::cout << "Button clicked!\n"; };
btn.click();
```


## `std::bind`

`std::bind` 是 C++ 11 标准库中的一个函数模板，用于创建函数对象的绑定版本，作用：
1. 将函数的参数绑定到特定值
2. 重新排列参数顺序
3. 将成员函数绑定到对象实例

### 主要特性

1. **参数绑定**：可以将某些参数固定为特定值
```cpp
auto bound_func = std::bind(func, arg1, arg2);
```

2. **占位符**：使用 `std::placeholders::_1`, `_2`, ..., `_N` 表示未绑定的参数
```cpp
auto bound_func = std::bind(func, _1, 42); // 第一个参数由调用时指定
```

**`##__VA_ARGS__`**
- 这是可变参数宏的扩展，会将调用时传入的所有额外参数原样插入到这里
- `##` 的作用是当 `__VA_ARGS__` 为空时，消除前面的逗号
```cpp
auto bound_func = std::bind(&func, &Class::method, ##__VA_ARGS__)
```


3. **成员函数绑定**：可以绑定成员函数和对象
```cpp
auto bound_member = std::bind(&Class::method, &obj, _1);
```

4. **参数重排序**：可以改变参数顺序
```cpp
auto reversed = std::bind(func, _2, _1); // 交换参数顺序
```


> [!tip] 
> 在 C++ 14 之后，通常可以用 lambda 替代这种复杂的 `std::bind` 表达式，代码会更清晰



## `std::atomic`

`std::atomic` 是 C++ 11 引入的模板类，用于提供线程安全的原子操作。它是多线程编程中重要的同步机制，可以避免数据竞争和保证内存顺序。`std::atomic` 包装的类型可以保证对该变量的所有操作都是原子的。

> [!info]- 原子操作
> 原子操作是指不可被中断的操作，要么完全执行，要么完全不执行，不会出现部分执行的状态。

### 头文件

```c++
#include <atomic>
```

### 使用示例

```cpp
#include <atomic>
#include <iostream>
#include <thread>

std::atomic<int> counter(0);  // 原子整型变量

void increment() {
    for (int i = 0; i < 100000; ++i) {
        counter.fetch_add(1, std::memory_order_relaxed);
    }
}

int main() {
    std::thread t1(increment);
    std::thread t2(increment);
    
    t1.join();
    t2.join();
    
    std::cout << "Counter value: " << counter << std::endl;
    return 0;
}
```

### 常用操作

- `load()` - 原子地读取值
- `store()` - 原子地写入值
- `fetch_add()` - 原子加法
- `fetch_sub()` - 原子减法
- `fetch_and()`, `fetch_or()`, `fetch_xor()` - 位运算
- `compare_exchange_weak()` - 比较交换
- `compare_exchange_strong()` - 比较交换

### 内存顺序

`std::atomic` 提供多种内存顺序选项：
- `memory_order_relaxed` - 最宽松，只保证原子性
- `memory_order_consume` - 依赖加载
- `memory_order_acquire` - 加载操作
- `memory_order_release` - 存储操作
- `memory_order_acq_rel` - 加载+存储
- `memory_order_seq_cst` - 顺序一致性（默认）



## `std::mutex`

`std::mutex` 是 C++ 11 标准库中提供的一个同步原语，全称为互斥锁（mutual exclusion），用于保护共享数据免受多线程同时访问，防止数据竞争的发生。

### 头文件

```c++
#include <mutex>
```

### 主要特性

- 不可复制，不可移动
- 提供基本的互斥功能
- 通常与 `std::lock_guard` 或 `std::unique_lock` 一起使用

### 使用示例

```cpp
#include <iostream>
#include <thread>
#include <mutex>

std::mutex mtx; // 全局互斥量

void print_block(int n, char c) {
    mtx.lock(); // 手动锁定
    for(int i=0; i<n; ++i) { std::cout << c; }
    std::cout << '\n';
    mtx.unlock(); // 手动解锁
}

int main() {
    std::thread th1(print_block, 50, '*');
    std::thread th2(print_block, 50, '$');
    
    th1.join();
    th2.join();
    
    return 0;
}
```

### 常用操作

- `lock()` - 锁定互斥量
```cpp
void lock();
```
- `try_lock()` - 尝试锁定互斥量
```cpp
bool try_lock(); // 成功返回 true，失败返回 false(不阻塞)
```
- `unlock()` - 解锁互斥量
```cpp
void unlock();
```


## `std::condition_variable`

`std::condition_variable` 是 C++ 11 标准库中提供的一个同步原语，用于线程间的条件同步。它允许线程在某个条件不满足时进入等待状态，直到其他线程通知条件可能已改变。

### 头文件

```c++
#include <condition_variable>
```

### 主要特性

- 不可复制，不可移动
- 需要与 `std::mutex` 配合使用
- 通常与 `std::unique_lock<std::mutex>` 一起使用


### 使用示例

```cpp
#include <iostream>
#include <thread>
#include <mutex>
#include <condition_variable>

std::mutex mtx;
std::condition_variable cv;
bool ready = false;

void worker_thread() {
    std::unique_lock<std::mutex> lock(mtx);
    cv.wait(lock, []{ return ready; }); // 等待ready变为true
    
    std::cout << "Worker thread is processing data\n";
}

int main() {
    std::thread worker(worker_thread);
    
    {
        std::lock_guard<std::mutex> lock(mtx);
        ready = true;
        std::cout << "Main thread signals data ready\n";
    }
    cv.notify_one(); // 通知等待的线程
    
    worker.join();
    return 0;
}
```

### 常用操作

- `wait()` - 无条件等待
```cpp
void wait(std::unique_lock<std::mutex>& lock);
```
- `wait()` with predicate - 带条件的等待（推荐用法）
```cpp
template <class Predicate>
void wait(std::unique_lock<std::mutex>& lock, Predicate pred);
```
- `notify_one()` - 唤醒一个等待线程
```cpp
void notify_one() noexcept;
```
- `notify_all()` - 唤醒所有等待线程
```cpp
void notify_all() noexcept;
```


## `std::thread`

`std::thread` 是 C++ 11 标准库中引入的线程类，用于表示和管理单个执行线程。

```cpp
#include <iostream>
#include <thread>

void thread_function() {
    std::cout << "Hello from thread!\n";
}

int main() {
    // 创建并启动线程
    std::thread t(thread_function);
    
    // 主线程继续执行
    std::cout << "Hello from main!\n";
    
    // 等待线程结束
    t.join();
    
    return 0;
}
```

```c++
#include <thread>
```
