# Matplotlib

> 参考：[官方API](https://matplotlib.org/stable/api/index.html)

matplotlib是python的一个绘图库，与numpy、pandas共享数据科学三剑客的美誉，也是很多高级可视化库的基础。matplotlib不是python内置库，调用前需手动安装，且需依赖numpy库。matplotlib，是matrix + plot + library的缩写。

调用matplotlib库绘图一般是用pyplot子模块，其集成了绝大部分常用方法接口：

* Figure：面板(图)，matplotlib中的所有图像都是位于figure对象中，一个图像只能有一个figure对象。
* Subplot：子图，figure对象下创建一个或多个subplot对象(即axes)用于绘制图像。



## 基本图像

1. scatter：散点图

2. hist：直方图

3. bar：柱状图
