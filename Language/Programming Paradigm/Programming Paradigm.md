编程范式（Programming Paradigm）是指编写程序的基本风格或模式，它决定了程序员如何组织代码、解决问题以及表达逻辑。不同的编程范式提供了不同的抽象层次和思维方式，适用于不同类型的项目或问题。

### 主要分类

1. **命令式编程（Imperative Programming）**
    - **核心思想**：通过明确的“步骤”告诉计算机“如何做”（How to do）。  
    - **特点**：依赖语句改变程序状态（如变量赋值、循环等）。  
    - **子类**：  
        - [**过程式编程**](过程式编程.md)：以函数/过程为单位组织代码（如 C）。  
        - [**面向对象编程**](面向对象编程.md)：以对象为核心，封装数据和行为（如 Java、Python ）。  

2. **声明式编程（Declarative Programming）**  
    - **核心思想**：描述“做什么”（What to do），而非具体步骤。  
    - **特点**：更关注结果而非过程。  
    - **子类**：  
        - [**函数式编程**](函数式编程.md)：用纯函数、不可变数据避免副作用（如 Haskell 、Scala ）
        - [**逻辑式编程**](逻辑式编程.md)：通过规则和事实推导结果（如 Prolog ）
        - [**响应式编程**](响应式编程.md)：处理数据流和变化传播（如 RxJS ）

3. **其他重要范式**  
    - [**面向切面编程**](面向切面编程.md)：分离横切关注点（如日志、事务）。  
    - [**元编程**](元编程.md)：编写能操作代码的代码（如 Ruby 的 `method_missing` ）。  
    - [**并发编程**](../../Operation%20System/并发编程.md)：处理多任务并行（如 Go 的协程）。  


### 代码示例

1. **命令式（C语言）**  
   ```c
   int sum = 0;
   for (int i = 1; i <= 10; i++) {
       sum += i;  // 显式控制循环和变量
   }
   ```

2. **函数式（Haskell）**  
   ```haskell
   sum [1..10]  // 描述“求和”，无需指定如何迭代
   ```

3. **面向对象（Python）**  
   ```python
   class Calculator:
       def sum(self, a, b):
           return a + b  # 通过对象封装行为
   ```


### 如何选择编程范式？

1. **问题类型**：  
    - 数据处理？考虑函数式
    - 复杂系统建模？考虑 OOP
2. **语言支持**：如 JavaScript 支持多范式，而 Haskell 专注函数式。  
3. **团队习惯**：一致性比范式本身更重要。  

编程范式本质是解决问题的工具，现代语言（如 Python、Scala ）常支持多范式混合使用。理解不同范式的优缺点，能帮助你写出更高效、可维护的代码。
