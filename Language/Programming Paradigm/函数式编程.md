函数式编程（Functional Programming）是一种编程范式，它将电脑运算视为函数运算，并且避免使用程序状态以及易变对象。其中，λ 演算是该语言最重要的基础，且 λ 演算的函数可以接受函数作为输入的参数和输出的返回值。函数式编程起源于范畴论（Category Theory），其认为世界上所有的概念体系，都可以抽象成一个个的范畴（category）。

函数式编程是与面向对象编程和过程式编程并列的编程范式，其典型例子是 MapReduce 算法。

**核心思想**是**用纯函数、不可变数据和表达式**来构建程序。


## 核心原则

1. **纯函数（Pure Functions）**
    - 相同的输入**永远**得到相同的输出（无随机性、依赖外部状态等）。
    - **无副作用**（不修改全局变量、不改变输入参数、不执行I/O操作等）。
    - 例如：`const add = (a, b) => a + b` 是纯函数；`let count = 0; const increment = () => count++` 不是。
2. **不可变性（Immutability）**
    - 数据一旦创建就不可修改，任何“修改”操作都会返回一个新对象。
    - 例如：在 JavaScript 中，使用 `map` 生成新数组而非直接修改原数组。
3. **函数是一等公民（First-Class Functions）**
    - 函数可以像变量一样被传递、赋值或作为返回值。
    - 例如：高阶函数（接收或返回函数的函数）。
4. **声明式而非命令式**
    - 关注“做什么”（What）而非“如何做”（How）。
    - 例如：用 `filter` 、 `map` 代替 `for` 循环。


## 关键特性

- **高阶函数（Higher-Order Functions）**：操作其他函数的函数（如 `map`、`filter`、`reduce` ）。
```javascript
const numbers = [1, 2, 3];
const doubled = numbers.map(x => x * 2); // [2, 4, 6]
```

- **递归（Recursion）**：替代循环，通过函数自我调用实现迭代（如计算阶乘）。
```haskell
factorial 0 = 1
factorial n = n * factorial (n - 1)  -- Haskell示例
```

- **引用透明性（Referential Transparency）**：表达式可替换为其值而不影响程序行为（如数学公式）。

- **惰性求值（Lazy Evaluation）**：只在需要时计算表达式（如 Haskell 中的无限列表）。


## 示例对比

- **命令式（Imperative）**：
```javascript
let sum = 0;
for (let i = 0; i < 10; i++) {
    sum += i;
}
```

- **函数式（Functional）**：
```javascript
const sum = [...Array(10).keys()].reduce((acc, x) => acc + x, 0);
```


## 常见语言

- **纯函数式**：Haskell、Elm
- **支持函数式**：JavaScript（Lodash/Ramda）、Python（itertools）、Scala、F#
- **多范式**：Java（Stream API）、C#（LINQ）



## Monad

Monad 是函数式编程中的一个核心概念，最初来自范畴论，后来被引入到编程语言中作为管理副作用和复杂计算的一种方式。

Monad 可以看作是一种设计模式，它允许你将操作序列化，同时处理副作用（如 IO 、状态、异常等），主要有三个组成部分：
1. **类型构造器**：将类型包装在另一个上下文中（如 `Maybe<T>`）
2. **unit/return 操作**：将一个普通值放入 monad 中（如 `Just 5`）
3. **bind/flatMap 操作**：允许将 monadic 值串联起来（如 `>>=` 操作符）

> [!tip] 为什么需要 Monad
> 在纯函数式语言（如 Haskell）中，函数不能有副作用，但实际编程需要处理IO、异常等。Monad 提供了一种结构化的方式来处理这些副作用，同时保持代码的纯粹性。
