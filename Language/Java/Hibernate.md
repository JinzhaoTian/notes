Hibernate 是一个开源的对象关系映射（ORM）框架，用于在 Java 应用程序中将面向对象的领域模型与关系数据库之间建立映射关系。

## 主要特点

1. **ORM功能**：将 Java 类映射到数据库表，Java 数据类型映射到 SQL 数据类型
2. **数据库无关性**：支持多种数据库，通过简单的配置切换数据库
3. **HQL查询语言**：提供面向对象的查询语言（Hibernate Query Language）
4. **缓存机制**：提供一级缓存和二级缓存提高性能
5. **事务管理**：支持声明式和编程式事务


## 核心组件

- **SessionFactory**：线程安全的工厂类，创建 Session 实例
- **Session**：单线程对象，代表与数据库的一次会话
- **Transaction**：管理操作的事务
- **Query**：执行查询的接口
- **Criteria**：面向对象的条件查询 API
