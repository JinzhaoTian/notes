
Java 自 1995 年发布以来，经历了多个版本的迭代，每个版本都引入了重要的特性和改进。

1. **Java 1.0 (1995)**
    - 首个正式版本，包含核心 API 和基本特性（如 `Applet`、AWT）。
2. **Java 1.1 (1997)**
    - 引入内部类、JDBC、RMI、反射等。
3. **Java 1.2 (1998)**
    - 更名为 "Java 2"，推出 Swing 图形库、集合框架（`Collections`）、JIT 编译器。
4. **Java 1.4 (2002)**
    - 重要更新：正则表达式、NIO、日志 API（`java.util.logging`）、XML 处理。
5. **Java 5 (2004)**
    - 里程碑版本，更名为 "Java SE 5.0"，引入：
        - **泛型**（Generics）
        - **注解**（Annotations）
        - **枚举**（Enums）
        - **自动装箱/拆箱**
        - `java.util.concurrent` 并发库。
6. **Java 6 (2006)**
    - 改进 JVM 性能（脚本引擎支持、JDBC 4.0），但无重大语法特性。
7. **Java 7 (2011)**
    - 引入 `try-with-resources`、`NIO 2.0`（文件操作 API）、`Switch` 支持字符串、钻石操作符（`<>`）。
8. **Java 8 (2014)**
    - **最广泛使用的版本**，重大更新：
        - **Lambda 表达式**
        - **Stream API**
        - **默认方法**（Default Methods）
        - 新的日期时间 API（`java.time`）
        - `Optional` 类。
9. **Java 9 (2017)**
    - 模块化系统（JPMS）、JShell（REPL 工具）。
10. **Java 11 (2018, LTS)**
    - 第二个长期支持版本（LTS），移除 Java EE 模块，引入 `var`（局部变量类型推断）、HTTP Client API。
11. **Java 17 (2021, LTS)**
    - 引入密封类（`sealed classes`）、模式匹配（`switch` 增强）、文本块（多行字符串）。
12. **Java 21 (2023, LTS)**
	- 正式引入虚拟线程（Project Loom）、结构化并发等。


### 最多使用

1. **Java 8 (仍占主导地位)**
    - 据 2023 年统计（如 JetBrains、New Relic 等报告），约 **60%~70%** 的生产环境仍在使用 Java 8。
    - 原因：稳定性、LTS 支持、企业级应用迁移成本高，且许多旧框架（如 Spring Boot 2.x）默认兼容 Java 8。
2. **Java 11 (增长迅速)**
    - 第二大使用版本（约 **20%~30%**），作为 Java 8 后的首个 LTS 版本，被越来越多企业采用。
    - 云原生和现代框架（如 Spring Boot 3.0+）开始要求 Java 11+。
3. **Java 17 及更新版本**
    - 因性能优化和新特性（如虚拟线程），Java 17 的采用率正在上升，但尚未成为主流。
    - 预计未来几年会逐步替代 Java 11。
