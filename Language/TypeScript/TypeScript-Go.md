TypeScript-Go（TS-Go，[typescript-go](https://github.com/microsoft/typescript-go)）是微软 TypeScript 团队推出的一个项目，目的是将 TypeScript **编译器**和**工具链**从基于 JavaScript / Node.js 的实现迁移到 Go 语言，以显著提升性能。

TypeScript-Go 的核心目标是通过用 Go 语言重写 TypeScript 编译器来大幅提升编译性能，但**最终输出仍然是标准的 JavaScript**，与现有的 TypeScript 编译器（`tsc`）保持兼容。
