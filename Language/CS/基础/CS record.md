`record` 是 C# 9.0 引入的一种**专为存储数据而设计的类型**。它像是 `class` 的“数据特化版”，能用更简洁的代码帮你实现一个**不可变的、基于值相等**的数据模型。

简单来说，`record` 帮你自动生成了大量样板代码，让你能更专注于数据本身。

## 核心特性

* **基于值的相等性 (Value-based Equality)**：这是 `record` 最核心的特性。两个 `record` 对象比较时，比较的是它们**内部存储的所有数据**是否都相同。如果相同，它们就被视为相等，而不是像普通 `class` 那样默认比较对象引用（即内存地址）。
	* 例如，两个都叫 "Alice"、年龄 30 的 `Person` 记录，它们就是相等的。
* **不可变性 (Immutability)**：`record` 默认是只读的。对象一旦被创建，其属性值就不能再被修改。这带来了线程安全、可预测性强等好处。
* **非破坏性修改 (Non-destructive Mutation)**：虽然不能直接修改，但你可以通过 `with` 表达式，基于现有对象**创建一个修改了部分属性的新副本**。
```csharp
var person1 = new Person("Alice", "Smith");
// 创建一个新对象，修改了姓氏
var person2 = person1 with { LastName = "Johnson" };
```
* **简洁的语法**：`record` 提供了“位置语法”（Positional Syntax），让你能用一行代码就定义好一个包含属性、构造函数和解构方法的类型。
```csharp
// 一行代码，搞定！
public record Person(string FirstName, string LastName);
```
* **内置的字符串表示**：自动生成有意义的 `ToString()` 方法，方便调试和日志输出。

## Record 与 Class 的核心区别

| 特性 | Record | Class |
| :--- | :--- | :--- |
| **相等性比较** | **基于值** (所有属性值相同即相等) | **基于引用** (默认比较内存地址) |
| **默认可变性** | **不可变** (`init` 属性) | **可变** (可随时修改属性) |
| **语法简洁性** | **极高**，支持位置语法，代码量少 | 较复杂，需手动定义属性、构造函数等 |
| **继承** | 只能继承自另一个 `record` | 支持完整的面向对象继承体系 |

## `record class` 与 `record struct`

从 C# 10 开始，`record` 可以更明确地声明为引用类型或值类型。

* **`record class`** (或简写为 `record`)：**引用类型**，存储在堆上。适用于大多数数据模型，尤其是较大的对象。
* **`record struct`**：**值类型**，通常存储在栈上。适用于小型、轻量级的数据，在追求性能的场景下很有优势。默认属性是**可读写**的，但你可以用 `readonly record struct` 来使其不可变。

## 适用场景

* **数据传输对象 (DTO)**：如 API 的请求和响应模型。
* **不可变配置对象**：系统启动后不再更改的配置信息。
* **值对象 (Value Object)**：在领域驱动设计（DDD）中，用于表示没有唯一标识，只由其属性值决定的对象。
* **需要值相等性的场景**：例如，在集合或字典中，你希望根据内容而非引用来查找或比较对象。

## 注意事项

`record` 并非万能。在依赖**引用相等性**的框架（如 Entity Framework Core）中，将实体类定义为 `record` 可能会引发问题。

总而言之，当你需要定义一个以**承载数据**为主要目的、且需要**值相等性**和**不可变性**的类型时，`record` 会是比传统 `class` 更现代、更高效的选择。
