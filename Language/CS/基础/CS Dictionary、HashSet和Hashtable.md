
在 C# 中的高效检索数据结构。

# Dictionary< TKey, TValue >

`Dictionary<TKey, TValue>` 是一个泛型集合，它在 `System.Collections.Generic` 命名空间中定义。它的主要特点包括：

1. **键值对存储**：每个元素都是一个键值对，键和值的类型在定义时指定。
2. **键唯一**：每个键在集合中必须是唯一的。如果尝试添加一个已经存在的键，会抛出异常。
3. **泛型**：`Dictionary<TKey, TValue>` 是一个泛型集合，提供了类型安全性。键和值的类型必须在定义字典时指定。
4. **高效的查找**：由于底层实现基于哈希表，`Dictionary` 提供高效的查找、添加和删除操作。
5. **非线程安全**：`Dictionary` 不是线程安全的。如果需要在多线程环境中使用，可以使用同步包装的 `ConcurrentDictionary` 或者其他线程安全的集合。

## 底层原理

1. **数据结构**：基于哈希表
2. **哈希值**：使用键元素的 `.GetHashCode()` 方法来计算。
3. **冲突处理**：使用链地址法来处理哈希冲突。也就是说，每个数组槽位存储一个链表，当不同的键（或元素）哈希到相同的索引时，这些键（或元素）会被存储在该索引处的链表中。
4. **平均时间复杂度**：由于使用了哈希表，两者都提供常数时间复杂度O(1)的查找、添加和删除操作（在没有大量冲突的理想情况下）。



# HashSet< T >

`HashSet<T>`是一个不包含重复元素的集合，它在`System.Collections.Generic`命名空间中定义。它的主要特点包括：

1. **唯一元素**：集合中的每个元素都是唯一的，不能有重复的元素。
2. **泛型集合**：`HashSet<T>`是一个泛型集合，意味着你可以指定集合中元素的类型。例如，`HashSet<int>`表示一个只包含整数的集合。
3. **高效的查找**：由于底层实现基于哈希表，`HashSet`提供高效的查找、添加和删除操作。
4. **非线程安全**：`HashSet`不是线程安全的。如果需要在多线程环境中使用，必须自己实现同步。


## 底层原理

1. **数据结构**：基于哈希表
2. **哈希值**：使用集合中元素的 `.GetHashCode()` 方法来计算。
3. **冲突处理**：使用链地址法来处理哈希冲突。也就是说，每个数组槽位存储一个链表，当不同的键（或元素）哈希到相同的索引时，这些键（或元素）会被存储在该索引处的链表中。
4. **平均时间复杂度**：由于使用了哈希表，两者都提供常数时间复杂度O(1)的查找、添加和删除操作（在没有大量冲突的理想情况下）。



# Hashtable

`Hashtable`是一个键值对集合，它在`System.Collections`命名空间中定义。它的主要特点包括：

1. **键值对存储**：每个元素都是一个键值对，键和值可以是任何类型的对象。
2. **键唯一**：每个键在集合中必须是唯一的。如果尝试添加一个已经存在的键，会抛出异常。
3. **非泛型**：`Hashtable`是非泛型集合，存储的对象都是作为`object`类型处理的。这意味着在取出元素时需要进行类型转换。
4. **非线程安全**：`Hashtable`不是线程安全的。如果需要在多线程环境中使用，可以使用同步包装的`Hashtable`或者其他线程安全的集合。


## 底层原理

1. **数据结构**：基于哈希表
2. **哈希函数**：`Hashtable` 使用键的 `.GetHashCode()` 方法来计算哈希值，并使用内部算法将哈希值转换为数组索引。
3. **冲突处理**：早期版本的 `Hashtable` 使用开放地址法（Open Addressing）处理冲突，但现代实现通常也采用链地址法。
4. **动态扩展**：当负载因子达到一定阈值时（通常是0.72），`Hashtable` 会扩展数组大小并重新分配现有元素的位置。
