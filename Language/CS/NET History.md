
### 历史

2001 年，.NET Framework v1.0 发布。

2003 年，.NET Framework v1.1 发布，完善了桌面应用开发和 Web 开发，推出了 ASP.NET。

2006 年，.NET Framework v2.0 、.NET Framework v3.0 发布。在 3.0 版本中，微软推出了 WPC、WCF、WF 等框架。

2009 年， ASP.NET MVC v1.0 发布。

2010 年，.NET Framework v4.0 发布。

2014 年，.NET Framework 升级到 v4.5。

2015 年，.NET Framework 升级到 v4.6。.NET Core 决定开发，并完全开源。

2016 年，.NET Core v1.0 发布。ASP.NET Core 推出，UWP 框架推出。

2017 年，.NET Framework 升级到 v4.7。.NET Core 2.0 发布。

2019 年，.NET Framework 升级到 v4.8，这是 .NET Framework 的最后一个版本。.NET Core 3.0 发布，这个版本代表着 .NET Core 已经彻底稳定下来。

2020 年，.NET Framework 产品线关闭，并将 .NET Core 产品线更名为 .NET，.NET 5 发布。

2021 年，.NET 6 发布，长期支持版本。

2022 年，.NET 7 发布。

2023 年，.Net 8 发布。
