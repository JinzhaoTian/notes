## .NET SDK

.NET SDK 在开发环境使用，用于构建 .NET 应用程序，主要包含内容：
1. .NET Runtime
2. CLI 工具（dotnet 命令）
3. 编译器（将代码编译为 IL）
4. NuGet 包管理器
5. 调试器
6. 模板（创建新项目的模板）
7. 文档
8. 其他开发工具


## .NET Runtime

.NET Runtime 在生产环境使用，运行已编译的 .NET 应用程序，主要包含内容：
1. CLR（Common Language Runtime）
2. 基类库（BCL）
3. JIT 编译器
4. 垃圾回收器


## .NET Hosting Bundle

.NET Hosting Bundle 在 IIS 上运行 ASP.NET Core 应用程序，主要包含内容：
1. .NET Runtime
2. ASP.NET Core Runtime
3. IIS 本机支持模块（ANCM - ASP.NET Core Module）
4. 其他 IIS 集成组件
