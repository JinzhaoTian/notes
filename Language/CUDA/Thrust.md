[Thrust](https://github.com/NVIDIA/thrust) 是一个 C++ 模板库，用于在 NVIDIA CUDA 设备上进行并行计算。它提供了高级的抽象接口，允许开发者在 GPU 上高效地执行并行算法，而不需要直接编写 CUDA 代码。Thrust 库的设计灵感来自于 C++ 标准模板库（STL），它提供了一组通用的算法和数据结构，如排序、扫描、变换和过滤操作。

Thrust 的主要特点包括：
1. **高效的并行算法**：Thrust 提供了一系列用于并行计算的算法，如排序、归约、扫描等，这些算法在 GPU 上具有很高的性能。
2. **抽象化的接口**：它将并行计算的复杂性抽象化，使开发者能够使用类似于 STL 的接口进行编程，而不需要关注底层的 CUDA 细节。
3. **与 CUDA 的集成**：Thrust 可以与 CUDA 无缝集成，利用 GPU 的并行计算能力来加速应用程序。
4. **可移植性**：尽管 Thrust 的主要目标是 CUDA，Thrust 也可以与其他并行计算平台兼容，通过适配器模式支持其他计算后端。
