Wails 是一个用 Go 语言和现代 Web 技术构建轻量级、跨平台桌面应用的开源框架。

## 核心设计

Wails 的核心设计是将高性能的 Go 后端与现代 Web 前端无缝结合，这套架构带来了更小的体积、更快的启动速度、更低的内存占用，同时避免了重复打包浏览器，且能利用 WebView 的自动安全更新。


1. **高效的前后端通信**：Wails 自动生成前后端绑定的代码，让 JavaScript / TypeScript 可以像调用本地函数一样直接调用 Go 方法，反之亦然，无需处理 HTTP 或 IPC 。
2. **统一的开发体验**：框架集成了实时热重载功能，开发时修改前端或 Go 代码，应用窗口会自动刷新，几乎瞬间就能看到变化。
3. **完善的生产支持**：框架提供命令行工具，只需一条 `wails build` 命令，就能将应用、前端资源和图标打包成一个可分发、支持应用商店上架的单文件程序。
4. **强大的原生集成**：它不仅仅是一个 Web 窗口容器，还支持创建原生菜单、系统托盘、打开原生文件对话框、发送系统通知，并能够方便地调用剪贴板等功能，从而实现与操作系统的深度集成。

## 对比

Wails 与传统方案的关键区别在于：

| **对比维度** | **Wails**                                             | **Electron (传统方案)**         |
| -------- | ----------------------------------------------------- | --------------------------- |
| **运行方式** | 编译为单一原生二进制文件                                          | 捆绑独立的 Chromium 与 Node.js 环境 |
| **渲染引擎** | 调用**操作系统原生 WebView**（如 Win 的 WebView2，macOS 的 WebKit） | 内嵌完整的 Chromium 浏览器          |
| **打包体积** | **约15 MB**                                            | **约150 MB**                 |
| **内存占用** | **约10 MB**                                            | **100 MB以上**                |
| **启动时间** | **< 0.5秒**                                            | **2-3秒**                    |


## 调用示例

下面是一个在 Wails 中，前端调用 Go 方法的极简流程：

1. **Go 后端**：在 Go 结构体中定义一个方法。
```go
// 在 app.go 中
type App struct{}
func (a *App) Greet(name string) string {
	return "Hello, " + name + "!"
}
```
 
2. **前端调用**：Wails 会自动生成 TypeScript 绑定，前端可直接调用。
```javascript
// 在前端（如 Vue 组件中）
import { Greet } from '../wailsjs/go/main/App';
const sayHello = async () => {
	let message = await Greet("World");
	console.log(message); // 输出: Hello, World!
};
```
