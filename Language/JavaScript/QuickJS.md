QuickJS 是由 Fabrice Bellard 开发的一个小巧、可嵌入的 JavaScript 引擎，它专注于在资源有限的环境中执行 JavaScript 代码。

> [!tip] Fabrice Bellard
> Fabrice Bellard 是一位著名的程序员，创造了许多令人惊叹的项目，例如：
> - **[FFmpeg](../../Algorithm/Video/FFmpeg.md)**：强大的音视频处理库和工具。
> - **QEMU**：著名的硬件虚拟化和仿真平台，支持多架构 CPU 及硬件模拟。
> - **TinyCC**：一个非常小巧且快速的 C 编译器。
> 
> Bellard 的作品一贯以高效、精巧和高质量著称，QuickJS 也继承了他的这些风格。

## 核心特性

1. **轻量且快速**
    - **体积小**：整个引擎的源代码只有几百 KB，编译后的可执行文件也非常小。这使得它非常适合嵌入到其他应用程序中，而不会显著增加最终产品的体积。
    - **低内存占用**：在启动和运行时消耗的内存非常少，这对于嵌入式设备和物联网应用至关重要。

2. **符合 ECMAScript 标准**
    - 它支持最新的 ECMAScript 规范，兼容性非常好。它几乎完整支持 **ES2020** 特性，包括模块、异步编程（Promise, async/await）、类、生成器、箭头函数等。这意味着很多现代的 JavaScript 代码无需修改或只需少量修改就可以在 QuickJS 中运行。

3. **可编译为独立的可执行文件**    
    - QuickJS 提供了一个编译器（`qjsc`），可以将 JavaScript 代码预先编译成可执行文件或 C 语言源文件。这带来了两个好处：
        - **保护源码**：可以将你的 JS 程序编译成一个二进制的可执行文件，分发时无需附带源码。
        - **提升启动速度**：预编译可以减少解析和编译字节码的时间，从而加快程序的启动速度。

4. **垃圾回收**
    - 使用引用计数（为主）和循环引用来消除的垃圾回收机制，内存管理高效。

5. **数学计算能力**
    - 它内置了对扩展精度整数的支持，可以进行高精度的数学计算。
