字体就是一套具有相同风格和样式的文字、字母、数字和符号的集合，指的是一整套字符集，包括不同的粗细（如细体、常规、粗体）、不同的样式（如正体、斜体）和不同的大小（如10号、12号）。

字型通常指的是字体家族中的一个特定成员，比如“思源黑体 Regular”、“Times New Roman Bold Italic”。在日常口语中，我们常常混用“字体”和“字型”，但了解其中的细微差别有助于更专业地交流。

#### 衬线体

1. **特征：** 在字母笔画的开始和末端有额外的装饰性笔画，这些“小脚”就是衬线。
2. **视觉感受：** 传统、经典、优雅、正式、可信。
3. **设计目的：** 衬线有助于引导视线沿着水平线移动，被认为在长段落印刷品（如书籍、报纸）中能提高阅读的流畅性和易读性。
4. **常见例子：**
    - **中文：** 宋体（Song / SimSun）就是最典型的中文衬线字体。你可以看到它的横笔画末端也有三角形的小装饰。
    - **英文：** Times New Roman, Georgia, Garamond, 宋体 (SimSun)。


#### 无衬线体

1. **特征：** “Sans”在法语中意为“无”，所以无衬线体就是没有这些额外装饰脚的字体。笔画粗细通常比较均匀。
2. **视觉感受：** 现代、简约、干净、友好、直接。
3. **设计目的：** 在屏幕显示和小字号下通常更清晰易读，因此广泛应用于网页、UI界面、标题和海报中。
4. **常见例子：**
    - **中文：** 黑体（Hei / Heiti）是最典型的中文无衬线字体。
    - **英文：** Arial, Helvetica, Calibri, 微软雅黑 (Microsoft YaHei)。


> [!tip] 简单总结
> 有脚（衬线）显得古典，没脚（无衬线）显得现代。


#### 等宽字体
1. **特征：** 每个字母、数字和符号都占据完全相同的水平空间。一个大写的`W`（很宽）和一个点号`.`（很窄）的宽度是一样的。
2. **视觉感受：** 像打字机打出来的效果，整齐划一，有时会显得有些呆板。
3. **主要用途：**
    - **编程写代码：** 这是等宽字体最重要的用途。代码对齐至关重要，等宽字体能保证代码结构清晰，便于阅读和调试。
    - **终端/命令行界面：** 同样为了对齐和格式。 
    - **制作表格：** 容易让文字栏位上下对齐。
4. **常见例子：**
    - **中文：** 中易等宽（SimSun）、等距更纱黑体（Sarasa Mono SC）
    - **英文：** Consolas, Courier New, Monaco, Source Code Pro.

#### 不等宽字体

1. **特征：** 每个字符的宽度根据其形状自然变化。`i`和`l`比较窄，`w`和`m`比较宽。这样排版更紧凑、更高效，也更符合阅读习惯。
2. **视觉感受：** 就是我们日常见到和使用的绝大多数字体，看起来自然、流畅。
3. **主要用途：** 几乎所有的日常应用，包括书籍、杂志、网页、广告、文档正文等。
4. **常见例子：** 除了上面提到的等宽字体，你见过的几乎所有字体都是不等宽的，比如 Arial, Times New Roman, 微软雅黑, 思源黑体 等等。


**简单总结：每个字一样宽（等宽）用于代码和表格；每个字宽度不同（不等宽）用于日常阅读。**
