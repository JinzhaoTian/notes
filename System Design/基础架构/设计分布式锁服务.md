
分布式锁（Distributed Lock）是在分布式系统中协调多个进程/服务对共享资源访问的重要机制。

## 适用场景

1. **共享资源互斥访问**：当多个服务/进程需要**互斥访问共享资源**时：
	- **数据库行记录修改**：防止多个服务同时修改同一条记录导致数据不一致
	- **文件系统操作**：防止多个节点同时写入同一个文件
	- **外部API调用限制**：当外部API有调用频率限制时

2. **避免重复处理**
	- **定时任务防重**：确保集群中只有一个节点执行定时任务
	- **消息队列消费幂等**：防止消息被多个消费者重复处理
	- **支付防重**：防止用户重复提交支付请求导致多次扣款

3. **顺序性保证**
	- **订单号生成**：确保订单号连续不重复
	- **流水号生成**：保证业务流水号的唯一性和顺序性

4. **分布式系统协调**
	- **主节点选举**：在集群中选择主节点
	- **配置更新同步**：确保配置变更在所有节点上一致执行
	- **状态机同步**：保证分布式状态机的一致性


## 设计实现


### 基于数据库

- **唯一索引/主键约束**
```sql
CREATE TABLE distributed_lock (
    lock_name VARCHAR(64) PRIMARY KEY,
    owner VARCHAR(64),
    expire_time TIMESTAMP
);
```

- **获取锁**
```sql
INSERT INTO distributed_lock(lock_name, owner, expire_time) 
VALUES ('order_lock', 'service1', NOW() + INTERVAL 30 SECOND);
```


- **释放锁**
```sql
DELETE FROM distributed_lock WHERE lock_name = 'order_lock' AND owner = 'service1';
```

#### 优缺点

- **优点**：简单易实现  
- **缺点**：性能较差，数据库单点问题


### 基于 Redis

#### SETNX + EXPIRE

##### Java 实现

```java
import redis.clients.jedis.Jedis;
import redis.clients.jedis.params.SetParams;

public class SimpleRedisLock {
    private Jedis jedis;
    private String lockKey;
    private String lockValue;
    private int expireTime; // 毫秒

    public SimpleRedisLock(Jedis jedis, String lockKey, int expireTime) {
        this.jedis = jedis;
        this.lockKey = lockKey;
        this.expireTime = expireTime;
        this.lockValue = UUID.randomUUID().toString();
    }

    public boolean tryLock(long waitTime) throws InterruptedException {
        long start = System.currentTimeMillis();
        
        while (true) {
            // SET lockKey lockValue NX PX expireTime
            String result = jedis.set(lockKey, lockValue, 
                SetParams.setParams().nx().px(expireTime));
            
            if ("OK".equals(result)) {
                return true;
            }
            
            if (System.currentTimeMillis() - start >= waitTime) {
                return false;
            }
            
            Thread.sleep(100); // 等待重试
        }
    }

    public void unlock() {
        // 使用Lua脚本保证原子性
        String luaScript = "if redis.call('get', KEYS[1]) == ARGV[1] then " +
                           "return redis.call('del', KEYS[1]) " +
                           "else " +
                           "return 0 " +
                           "end";
        
        jedis.eval(luaScript, 1, lockKey, lockValue);
    }
}
```

使用，
```java
public class OrderService {
    private Jedis jedis = new Jedis("localhost");
    
    public void createOrder(String orderId) {
        SimpleRedisLock lock = new SimpleRedisLock(jedis, "order_lock:" + orderId, 30000);
        
        try {
            if (lock.tryLock(5000)) { // 等待5秒获取锁
                // 执行业务逻辑
                System.out.println("成功获取锁，处理订单: " + orderId);
            } else {
                System.out.println("获取锁失败");
            }
        } finally {
            lock.unlock();
        }
    }
}
```


##### Spring Boot 实现

```java
import org.springframework.data.redis.core.StringRedisTemplate;
import org.springframework.data.redis.core.script.DefaultRedisScript;
import org.springframework.stereotype.Component;

import java.util.Collections;
import java.util.UUID;
import java.util.concurrent.TimeUnit;

@Component
public class RedisDistributedLock {
    private final StringRedisTemplate redisTemplate;
    private static final String LOCK_PREFIX = "lock:";
    private static final long DEFAULT_EXPIRE = 30000; // 30秒
    
    // Lua解锁脚本
    private static final String UNLOCK_LUA =
        "if redis.call('get', KEYS[1]) == ARGV[1] then " +
        "   return redis.call('del', KEYS[1]) " +
        "else " +
        "   return 0 " +
        "end";

    public RedisDistributedLock(StringRedisTemplate redisTemplate) {
        this.redisTemplate = redisTemplate;
    }

    /**
     * 尝试获取锁
     * @param lockName 锁名称
     * @param waitTime 最大等待时间(毫秒)
     * @param leaseTime 锁持有时间(毫秒)
     * @return 锁标识（解锁时需要使用），获取失败返回null
     */
    public String tryLock(String lockName, long waitTime, long leaseTime) {
        String lockKey = LOCK_PREFIX + lockName;
        String lockValue = UUID.randomUUID().toString();
        
        long endTime = System.currentTimeMillis() + waitTime;
        
        while (System.currentTimeMillis() < endTime) {
            if (redisTemplate.opsForValue().setIfAbsent(
                lockKey, lockValue, leaseTime, TimeUnit.MILLISECONDS)) {
                return lockValue; // 获取锁成功
            }
            
            try {
                Thread.sleep(100); // 等待重试
            } catch (InterruptedException e) {
                Thread.currentThread().interrupt();
                break;
            }
        }
        
        return null;
    }

    /**
     * 释放锁
     * @param lockName 锁名称
     * @param lockValue 锁标识
     * @return 是否释放成功
     */
    public boolean unlock(String lockName, String lockValue) {
        String lockKey = LOCK_PREFIX + lockName;
        
        DefaultRedisScript<Long> redisScript = new DefaultRedisScript<>(UNLOCK_LUA, Long.class);
        Long result = redisTemplate.execute(redisScript, 
            Collections.singletonList(lockKey), lockValue);
        
        return result != null && result == 1;
    }

    /**
     * 简易加锁方法（默认参数）
     */
    public String lock(String lockName) {
        return tryLock(lockName, 5000, DEFAULT_EXPIRE);
    }
}
```

使用，
```java
@Service
public class PaymentService {
    private final RedisDistributedLock redisLock;
    
    public PaymentService(RedisDistributedLock redisLock) {
        this.redisLock = redisLock;
    }
    
    public boolean processPayment(String orderId, BigDecimal amount) {
        String lockValue = redisLock.tryLock("payment:" + orderId, 3000, 10000);
        
        if (lockValue == null) {
            throw new RuntimeException("系统繁忙，请稍后再试");
        }
        
        try {
            // 处理支付核心逻辑
            // 检查订单状态
            // 扣减余额
            // 记录交易流水
            return true;
        } finally {
            redisLock.unlock("payment:" + orderId, lockValue);
        }
    }
}
```


#### RedLock 算法

Redis 官方推荐的分布式锁算法，使用多个独立的 Redis 实例：
- 获取当前时间
- 依次尝试从 N 个 Redis 实例获取锁
- 计算获取锁总耗时，小于锁超时时间且获得多数实例认可则成功
- 锁的实际有效时间 = 初始有效时间 - 获取锁耗时

##### 实现

- **Maven 依赖**
```xml
<dependency>
    <groupId>org.redisson</groupId>
    <artifactId>redisson-spring-boot-starter</artifactId>
    <version>3.17.0</version>
</dependency>
```

- **配置类**
```java
@Configuration
public class RedissonConfig {
    @Value("${spring.redis.host}")
    private String host;
    
    @Value("${spring.redis.port}")
    private String port;
    
    @Bean
    public RedissonClient redissonClient() {
        Config config = new Config();
        config.useSingleServer()
              .setAddress("redis://" + host + ":" + port);
        return Redisson.create(config);
    }
}
```

- **使用示例**

```java
@Service
public class InventoryService {
    private final RedissonClient redissonClient;
    
    public InventoryService(RedissonClient redissonClient) {
        this.redissonClient = redissonClient;
    }
    
    public void reduceStock(Long productId, int quantity) {
        RLock lock = redissonClient.getLock("product_stock:" + productId);
        
        try {
            // 尝试加锁，最多等待100秒，上锁后30秒自动解锁
            boolean locked = lock.tryLock(100, 30, TimeUnit.SECONDS);
            
            if (locked) {
                // 执行业务逻辑
                // 查询库存
                // 检查是否充足
                // 扣减库存
            } else {
                throw new RuntimeException("获取锁失败");
            }
        } catch (InterruptedException e) {
            Thread.currentThread().interrupt();
            throw new RuntimeException("锁等待被中断");
        } finally {
            if (lock.isLocked() && lock.isHeldByCurrentThread()) {
                lock.unlock();
            }
        }
    }
}
```



### 基于 ZooKeeper

1. 在锁节点下创建临时顺序节点
2. 检查自己是否是最小序号节点
3. 如果是则获取锁，否则监听前一个节点
4. 完成操作后删除节点

```java
public void lock() throws Exception {
    String path = zk.create("/locks/lock-", 
                          null, 
                          ZooDefs.Ids.OPEN_ACL_UNSAFE,
                          CreateMode.EPHEMERAL_SEQUENTIAL);
    
    while (true) {
        List<String> children = zk.getChildren("/locks", false);
        Collections.sort(children);
        
        if (path.endsWith(children.get(0))) {
            return; // 获取锁
        } else {
            waitForLock(children.get(0)); // 等待前一个节点释放
        }
    }
}
```


### 基于 etcd

etcd 的租约（lease）机制非常适合实现分布式锁：

```go
func (m *Mutex) Lock() error {
    resp, err := m.client.Grant(context.Background(), 60) // 60秒租约
    if err != nil {
        return err
    }
    
    // 尝试获取锁
    txn := m.client.Txn(context.Background()).
        If(clientv3.Compare(clientv3.CreateRevision(m.key), "=", 0)).
        Then(clientv3.OpPut(m.key, m.id, clientv3.WithLease(resp.ID))).
        Else(clientv3.OpGet(m.key))
    
    txnResp, err := txn.Commit()
    if err != nil {
        return err
    }
    
    if !txnResp.Succeeded {
        return ErrLockAcquired
    }
    
    m.leaseID = resp.ID
    return nil
}
```


## 最佳实践

1. **设置合理的超时时间**：防止死锁，确保锁最终能被释放
2. **实现可重入性**：同一线程/进程可多次获取锁
3. **避免惊群效应**：大量客户端同时竞争锁时的高负载问题
4. **故障恢复**：处理锁服务节点故障的情况
5. **公平性**：按照请求顺序获取锁
6. **监控与告警**：监控锁的使用情况和异常



## 选择建议

- 简单场景：Redis SETNX
- 高一致性要求：ZooKeeper 或 etcd
- 大规模部署：考虑 RedLock 或专业的分布式锁服务
