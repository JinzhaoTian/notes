Wine 是一个能在 Linux、macOS 等非 Windows 系统上，直接运行 Windows 的应用程序和游戏的软件，而且完全免费。

| 特性       | Wine (兼容层)                           | 传统虚拟机 (如 VirtualBox)                                      |
| -------- | ------------------------------------ | --------------------------------------------------------- |
| **工作方式** | 将 Windows 程序的指令实时翻译成 Linux 系统能理解的语言。 | 在现有系统上完整地模拟出一台包括 CPU、内存、硬盘在内的虚拟电脑，然后再在这台虚拟电脑里安装Windows系统。 |
| **性能**   | 很高，几乎是原生应用的性能，因为它没有模拟硬件的开销。          | 有一定性能损耗，因为指令需要经过多层转换。                                     |
| **集成度**  | Windows 程序可以像原生程序一样直接运行在桌面上。         | Windows 程序被“关”在一个独立的窗口里运行，与主系统隔离。                         |

Wine 项目始于 1993 年，初衷只是为了在 Linux 上运行 Windows 3.1 的程序。经过30多年的发展，它已经成长为一个庞大而成熟的软件。它由全球的志愿者和商业公司（如 CodeWeavers）共同维护，采用 LGPL 开源协议发布，确保了它的自由和免费。

如今，Wine 已经非常强大：

- **广泛应用**：它不仅能在 Linux 上运行大量 Windows 软件，也是 Valve 公司让 **Steam Deck** 掌机流畅运行 Windows 游戏的核心技术 **Proton** 的基础。
- **持续更新**：Wine 的开发非常活跃，不断支持新的 Windows 应用程序和游戏。例如，它一直在改进对 Direct3D 12 的支持，并引入了对现代显示协议 Wayland 的支持。
- **并非完美**：虽然已有数千款软件能完美运行，但仍有部分程序（特别是依赖复杂驱动的游戏）存在兼容性问题。此外，由于 Wine 与你的系统共享文件权限，**它本身不是一个安全的沙盒环境，运行未知的 Windows 程序同样有感染恶意软件的风险**。
