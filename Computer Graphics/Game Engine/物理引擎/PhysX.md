[PhysX](https://gameworksdocs.nvidia.com/PhysX/4.1/documentation/physxguide/Index.html) 是由 NVIDIA 开发的一款强大的物理引擎，广泛应用于视频游戏、仿真、虚拟现实和其他需要物理模拟的应用程序中。它的主要功能是模拟逼真的物理现象，例如刚体动力学、流体动力学、布料模拟、柔体模拟、车辆动力学等。PhysX 支持 GPU 加速，通过利用 NVIDIA 的图形处理器来提高物理计算的效率和性能。

PhysX 被集成在许多游戏引擎中，如 Unity 和 Unreal Engine，允许开发者轻松地为游戏或仿真项目加入真实的物理效果。
