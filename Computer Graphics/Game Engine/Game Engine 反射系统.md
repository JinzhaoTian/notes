>[!tip] 为何游戏引擎需要反射？
> 
> 在现代游戏引擎的架构中，反射（Reflection）系统扮演着至关重要的角色。尽管 C++ 等编译型语言本身不直接提供运行时反射，但几乎所有商业级或自研引擎都会构建一套自己的反射机制。这套机制是引擎诸多核心功能得以实现的基础，主要包括：
>
> - **编辑器支持**：在编辑器中动态地显示和编辑对象的属性（如在属性面板中调整组件参数）。
> - **序列化与反序列化**：将游戏对象（GameObject）、组件（Component）等的状态保存到磁盘（如场景文件、存档）或从磁盘加载，无需为每个类手写存取代码。
> - **脚本/蓝图系统**：允许脚本语言（如Lua、Python）或可视化脚本（如蓝图）在运行时访问和调用C++对象的属性和方法。
> - **网络同步**：自动地将需要同步的属性在网络间传输，实现多人游戏中的状态同步。
