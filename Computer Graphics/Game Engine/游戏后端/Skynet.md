Skynet 是一个轻量级、高性能的开源服务端并发框架，主要用于游戏服务器开发，基于C和Lua，采用单进程多线程 Actor 模型，旨在提供高并发、低延迟的消息处理能力，适用于大规模在线游戏服务器架构。

## 核心特点

1. **Actor 模型**
    - 每个服务（Actor）独立运行，通过消息传递进行通信，避免多线程锁竞争问题，简化并发编程。
    - 服务之间完全隔离，每个 Lua 服务运行在独立的 Lua 虚拟机（LuaState）中，确保安全性和稳定性。

2. **混合编程（C + Lua）**
    - C 负责底层消息调度、网络通信和性能关键模块。
    - Lua 用于业务逻辑开发，降低开发门槛，支持热更新。

3. **高效的消息队列**
    - 采用无锁队列优化消息传递，减少数据复制，提升性能。
    - 支持异步消息处理，Lua 协程（coroutine）机制让逻辑代码以同步方式编写，但实际运行是异步的，避免阻塞。

4. **轻量级架构**
    - 核心代码仅约 8K 行 C + 2K 行 Lua，结构紧凑，易于定制。
    - 支持 10K+ 并发连接，适用于高负载游戏服务器。

5. **内置基础组件**
    - 提供定时器、命名服务、数据库访问、集群通信等基础功能。
    - 支持跨节点通信（通过 Harbor ID 实现集群）

## 优点

- **高性能**：多线程 + 协程机制，适合 IO 密集型任务。
- **低耦合**：服务独立，便于模块化开发。
- **开发友好**：Lua 脚本简化逻辑开发，C 语言优化关键性能。

## 缺点

- **单点故障风险**：默认采用单点 World 服务管理集群，容灾能力较弱。
- **学习曲线较陡**：需熟悉 Actor 模型和消息驱动架构。
- **官方仅支持 Linux**，Windows 支持有限。

## 应用场景

- **MMORPG、实时对战游戏**（如《风之大陆》《三国志》手游）。
- **微服务架构**：结合 Redis、MySQL 实现数据存储，Go 语言辅助扩展
