UnrealScript（常简称为 UScript）是早期版本的 Unreal Engine（特别是 Unreal Engine 3 及更早版本）所使用的一种脚本语言。它是由 Epic Games 专门为 Unreal Engine 开发的，主要用于编写游戏逻辑和行为。

UnrealScript 的语法和特性与 Java 或 C++ 类似，但针对游戏开发进行了优化，使得它更适合于处理实时交互、事件响应等任务。

UnrealScript 在 Unreal Engine 3 中是核心脚本语言，用于游戏逻辑的开发。Unreal Engine 4 推出后，UnrealScript 被弃用，Epic Games 将开发重心转移到了 C++ 和 Blueprints（蓝图）上。这个决定是为了提升性能，并提供更灵活和高效的开发方式。
