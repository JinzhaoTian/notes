UE 的工具链相当庞大，涵盖了从代码编译、资源编辑到性能分析的各个方面，其开发语言主要涉及 C++、C# 以及一些特定的脚本语言（如 Python ）。

>[!tip] 
>在 UE 中，真正的**游戏运行时代码**和**核心引擎功能**几乎完全由 C++ 实现，C# 等仅用来完成一些开发工具链，特别是编译工具方面，并不直接参与游戏逻辑的编写或运行时。

## Unreal Build Tool

Unreal Build Tool（UBT，虚幻编译工具）这是 UE 的核心编译管理和组织工具，用 C# 编写。UBT 本身不参与最终游戏的运行，只是一个**构建时**的工具。

### 主要职责

- **解析和配置**：读取项目的 `.Target.cs` 和 `.Build.cs` 文件，确定编译目标（如游戏、编辑器、客户端、服务器）、模块依赖关系、编译选项等。
- **驱动整个构建流程**：UBT 会调用 UHT 来处理所有包含反射宏的 C++ 头文件，生成必要的反射代码（`*.generated.h` 和 `*.gen.cpp`）。之后，UBT 再调用底层的 C++ 编译器（如 MSVC）来编译最终的二进制文件。
- **依赖管理和条件编译**：确保所有模块按照正确的顺序编译，处理不同平台（Windows、Mac、Linux、主机动平台等）的差异化编译。


## Unreal Header Tool

Unreal Header Tool（UHT，虚幻头工具）是一个用 C++ 编写的代码生成工具，负责解析你在 C++ 代码中使用的那些特殊的反射宏（如 `UCLASS()`，`UFUNCTION()`，`UPROPERTY()`），并生成实现虚幻引擎反射系统所必需的代码文件（`*.generated.h` 和 `*.gen.cpp`）。

[UE 反射系统](UE%20反射系统.md)是虚幻引擎实现蓝图与 C++ 通信、序列化、网络复制等关键功能的基石。

## Unreal Editor

Unreal Editor（虚幻编辑器）是引擎的核心集成开发环境，其本身主要是用 C++ 开发的，并使用了虚幻自家的 Slate UI 框架来构建界面。

关卡编辑器、材质编辑器、蓝图编辑器等都是内置于 Unreal Editor 中的组件。


## IDE

对于 C++ 代码的编写和调试，Visual Studio 是 Windows 平台上最常用和最官方支持的选择，通常会配合 Visual Assist 或 ReSharper C++ 等插件来提高效率。

JetBrains Rider for Unreal Engine 也是一个越来越受欢迎的跨平台选择，它对虚幻引擎的 C++ 和蓝图提供了良好的支持。



## 资源编辑器

Unreal Editor 内置了一系列专业的资源编辑器，例如材质编辑器、静态网格体编辑器、骨骼网格体编辑器、Sequencer（用于过场动画）、行为树编辑器（用于AI）等等。这些编辑器的核心功能通常由 C++ 实现，但它们往往会提供**扩展接口**：
- 许多编辑器功能可以通过 Python 脚本进行访问和自动化操作。
- 也可以使用 Editor Utility Widgets（EUW）或 Editor Utility Blueprints（EUB），即通过蓝图可视化脚本的方式，在编辑器内创建自定义的工具面板和功能，而无需编写 C++ 代码

## 脚本与自动化

为了让开发更高效，虚幻引擎提供了多种自动化途径：
- **Python**：在虚幻引擎中，Python 被广泛用于编辑器脚本编写和自动化任务，比如批量导入资源、重命名资产、自动化关卡布置等。引擎提供了丰富的 Python API 来操作编辑器内的对象。
- **Blueprint Editor Utilities (编辑器工具蓝图)**：可以使用**蓝图**来创建**仅在编辑器内部运行的工具和脚本**。这对于快速原型制作、为设计团队构建定制化工具或者自动化一些重复性的内容创建任务非常有用，**无需等待程序员用 C++ 实现**。


## Unreal Insights

这是一个功能强大的性能分析工具，可以捕获和可视化游戏运行时的详细数据，包括 CPU 性能、 GPU 渲染、内存使用、网络状态等。它本身是引擎的一部分，用 C++ 开发。

引擎内嵌的各种统计命令（如 `stat unit`，`stat game`，`stat scenerendering` 等）也提供了实时查看性能指标的能力。
