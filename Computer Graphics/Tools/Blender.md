Blender 是一款免费、开源的 3D 创作套件，可以理解为一种“数字艺术家的瑞士军刀”。它支持整个 3D 制作流程，被广泛应用于独立开发、艺术创作甚至影视行业。

## 核心能力

- **建模**：从零塑造物体、角色或场景的 3D 形状。
- **渲染**：使用 Cycles（光线追踪）或 Eevee（实时渲染）引擎生成逼真图像。
- **动画与绑定**：为角色设置骨骼和控制器，制作运动效果。
- **雕刻**：像捏泥巴一样高精度塑造模型，适合生物和细节。
- **视觉特效（VFX）**：合成、抠像、摄像机追踪等。
- **视频编辑**：内置剪辑、转场和基础调色功能。
- **2D 动画（Grease Pencil）**：在 3D 空间里绘制 2D 动画。


## 技术栈

Blender 主要使用 C++、Python 和 GLSL 三种语言开发，三者分工明确。
1. **C++**：核心引擎与性能关键模块
	- 负责软件底层架构、渲染引擎（Cycles、Eevee）、几何处理、物理模拟等计算密集型任务。这是 Blender 的主体语言，历史代码中曾有较多 C，但现在绝大部分已转为 C++。
2. **Python**：界面布局、工具逻辑与扩展系统
	- 用于搭建用户界面、定义快捷键、实现简单工具，并作为脚本和插件的开发语言。Blender 内置的 Python API 允许用户深度定制和扩展功能。
3. **GLSL**：着色器程序
	- 用于编写在 GPU（显卡）上运行的着色器代码，控制 Eevee 渲染器等场景中的材质外观和视觉效果。
