# 模型加载库

## Assimp

[Assimp](https://github.com/assimp/assimp) （Open Asset Import Library，开放的资产导入库）是一个非常流行的模型导入库，能够导入导出很多种不同的模型文件格式，会将所有的模型数据加载至 Assimp 的通用数据结构中。![](imgs/Pasted%20image%2020240731165539.png)
当使用 Assimp 导入一个模型的时候，它通常会将整个模型加载进一个场景（Scene）对象，它会包含导入的模型/场景中的所有数据。Assimp 会将场景载入为一系列的节点（Node），每个节点包含了场景对象中所储存数据的索引，每个节点都可以有任意数量的子节点。

[支持的三维模型数据](https://github.com/assimp/assimp/blob/master/doc/Fileformats.md) 有：OBJ、glTF、STL、DXF等等很多。

# 三维数据文件


三维场景数据文件格式，常见的有几种 "`*.3ds`"，"`*.max`"，"`*.mb`"，"`*.dxf`"，"`*.obj`"，每种格式都有其特定的用途和优势：
- **"`*.obj`"**：OBJ 格式，**基于纯文本编码存储**，用于存储三维模型的几何信息，包括顶点、法线、纹理坐标等，可以直接用记事本打开进行查看和编辑修改。
  支持多边形（Polygon），直线（Lines），表面（Surfaces），和自由形态曲线（Free-form Curves），通过它们的点来描述，曲线和表面则根据于它们的控制点和依附于曲线类型的额外信息来定义。不包含动画、材质特性、贴图路径、动力学、粒子等信息，**支持三个点以上的面**，很多其它的模型文件格式只支持三个点的面，支持法线和贴图坐标。
```C#
# A 2 x 2 square mapped with a 1 x 1 square  
# texture stretched to fit the square exactly.  
mtllib master.mtl  
v 0.000000 2.000000 0.000000  
v 0.000000 0.000000 0.000000  
v 2.000000 0.000000 0.000000  
v 2.000000 2.000000 0.000000  
vt 0.000000 1.000000 0.000000  
vt 0.000000 0.000000 0.000000  
vt 1.000000 0.000000 0.000000  
vt 1.000000 1.000000 0.000000  
# 4 vertices  
usemtl wood  
# The first number is the point,  
# then the slash,  
# and the second is the texture point  
f 1/1 2/2 3/3 4/4  
# 1 element
```

- **"`*.dxf`"**：D.X.F.直译为绘图交换格式（Drawing Exchange Format），简单来说它是一种高度兼容的CAD文件类型，实际上适配多种文件设计类型以及多种CAD软件。最初是在1982年作为 `.dwg` 的开源替代品而创建的，**基于纯文本编码存储**。

- **"`*.mb`"**：MB 文件大多属于 Autodesk 的 Maya，具有 "`*.mb`" 文件扩展名。包含 3D 数据，例如场景、世界、纹理、动画、地形、设置以及雾和照明等效果，**基于二进制存储**。

- **"`*.3ds`"和"`*.max`"**：这两种文件格式都是 Autodesk 3ds Max中的，其中 `*.3ds` 历史悠久，仅保留必要的几何体、纹理和照明数据，**基于二进制存储**。
  `*.max` 文件包含一个或多个 3D 模型，包括线框、纹理、灯光效果、阴影、动画和其他 3D 设计元素，主要用来取代 `*.3ds` 。Autodesk 3ds Max 可以将 `*.max` 文件转换为各种格式，如 `*.fbx`、`*.ai`、`*.dwg`、`*.dxf`、`*.igs`、`*.sat`、`*.stl` 等。

- **"`*.fbx`"**：Autodesk FBX 文件格式是一种流行的 3D 数据交换格式，用于 3D 编辑器和游戏引擎之间，支持 3D 模型、场景层次、材质照明、动画、骨骼、蒙皮和混合形状，**基于二进制存储**。FBX 作为一种较旧的格式，还支持目前尚未广泛使用的数据，例如 NURBS 曲面和曲线，它也可以存储具有不同拓扑的位置、UV 和法线数据。FBX 文件快速又高效，具有良好的兼容性，可用于在Maya 、3DS Max、Unity 3D 和 Unreal Engine 之间轻松传输复杂的 3D 场景数据。
  FBX 最大缺点是**封闭格式**，访问 FBX 文件中数据的唯一官方方法是使用官方 SDK。

- ~~**"`*.ai`"**：`*.ai` 文件是在Adobe Illustrator中创建，包括由点连接的线，而不是光栅图像数据，通常用于创建横幅和logo，非3D文件。~~

- **"`*.stl`"**：由3D Systems于1987年创建，并且已被广泛用作全行业3D打印机模型的标准文件。从原生CAD文件导出的，并使用三维笛卡尔坐标系描述三角形单位法线和顶点的原始非结构化三角形曲面格式。




1. 点：三维坐标
2. 线：直线段的两点表示，直线方程，向量，参数方程，Bezier曲线的线段扩展，NURBS曲线的线段扩展，体素。
3. 面：三角形网格（mesh），四边形（Quad），点云，体素（Voxel），贝塞尔曲面（Bezier），非均匀有理B样条曲面（Non-Uniform Rational B-Spline，NURBS），Bezier曲线的三维扩展（B-Spline曲面），细分曲面（Subdivision Surfaces），隐式曲面（等式或不等式）。
4. 体：点线面的组合

其中，在三维空间中B-Spline曲面是NURBS曲面的一个特例，NURBS曲面在其基础上引入了有理性，使得它在形状控制和精确性上更为灵活和精确，又可以把NURBS曲线理解成四维空间的B样条曲线在三维空间的投影。


几何图形的表示，隐式的表示有：
- Algebraic Surface：代数曲面，
- Level Sets：水平集
- Distance Functions：距离函数，强大

显示的表示有：
- Point Cloud：点云
- Polygon Mesh：多边形面，任何面都可以拆成小的三角形。
- NURBS：非均匀有理B样条曲线
