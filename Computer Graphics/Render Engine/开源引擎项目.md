## 图形引擎

- OGRE（Object-Oriented Graphics Rendering Engine），即面向对象图形渲染引擎，是一个面向场景管理的 3D 图形引擎，它基于 C++ 开发，帮助开发人员更容易的开发带硬件加速的 3D 图形程序。它的类库封装了底层图形库（Direct3D 和 OpenGL）的所有细节，提供了基于世界对象的接口和类。
	- [项目地址](https://github.com/OGRECave/ogre) 

- Irrlicht Engine，鬼火：
	- [地址](https://irrlicht.sourceforge.io/?page_id=10) 

- WebGL引擎项目：[地址](https://github.com/gavinyork/zephyr3d) 

- MiniEngine：微软开源的 DX12 教学，比较偏图形引擎，严格来说可能不算游戏引擎。
	- [项目地址](https://github.com/microsoft/DirectX-Graphics-Samples) 

- Filament：谷歌开源渲染引擎，跨平台，多线程渲染。
	- [项目地址](https://github.com/google/filament) 
	- 支持 OpenGL 、Vulkan、Metal、WebGL 2.0

## 游戏引擎

- Piccolo：Games104系列课程的配套项目
	- [项目地址](https://github.com/BoomingTech/Piccolo)

- FlaxEngine：开源的游戏引擎，支持 DirectX 12、Vulkan，专门为开发高性能的 3D 游戏和实时应用而设计。它提供了一套现代化的工具和功能，支持从小型独立游戏到大型商业项目的开发。
	- [项目地址](https://github.com/FlaxEngine/FlaxEngine)
	- 编辑器 UI ：使用 C# 和 WPF 。
	- 脚本系统：
		- 支持 C# 脚本，使用 Mono 作为 C# 脚本引擎。
		- 支持蓝图，图形化脚本。
![](_imgs/Pasted%20image%2020250122101312.png)


- LumixEngine：开源的游戏引擎，主要用于开发跨平台的 3D 游戏。它是一个基于 C++ 的引擎，使用 DirectX 12，设计上具有模块化、轻量级和高效性，适用于从小型到中型的游戏项目。
	- [项目地址](https://github.com/nem0/LumixEngine)
	- 编辑器 UI ：主要是使用 ImGui 实现的。
	- 脚本系统：通过集成的 Lua 脚本语言实现。
![](_imgs/Pasted%20image%2020250122101147.png)


- SpartanEngine： 开源的跨平台 C++ 渲染引擎，旨在提供一个高效且易于扩展的图形渲染平台。它支持现代图形技术，如 OpenGL、 Vulkan 和 DirectX 12，并且专注于简化渲染管线的实现，使开发人员能够更轻松地创建和渲染复杂的 3D 场景。
	- [项目地址](https://github.com/PanosK92/SpartanEngine)
![](_imgs/Pasted%20image%2020250122101120.png)



- 虚幻引擎：
	- [主页](https://www.unrealengine.com/zh-CN/unreal-engine-5)
	- [项目地址](https://github.com/EpicGames/UnrealEngine)
	- 脚本系统：
		- Blueprints，蓝图：虚幻引擎提供的一种可视化脚本系统，使得开发者可以通过拖拽节点的方式编写游戏逻辑，而不需要写一行代码。
		- C++ 脚本：虚幻引擎本身是使用 C++ 编写的，因此开发者也可以直接在 C++ 中编写脚本来实现更底层、性能要求更高的功能。
		- Python 脚本：虚幻引擎从 4.19 版本开始支持 Python 脚本，主要用于编辑器工具的自动化、数据处理、和批量操作等。
		- 外部脚本：可以通过第三方插件扩展，支持其他脚本语言，如 Lua 和 JavaScript。
![](_imgs/Pasted%20image%2020240126105643.png)
