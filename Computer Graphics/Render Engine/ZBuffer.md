Z-Buffer（深度缓冲）是计算机图形学中用于解决可见性判断（Visible Surface Determination）问题的一种核心技术。简单来说，它的作用是确保在渲染3D场景时，离相机近的物体遮挡住离相机远的物体，从而产生正确的视觉遮挡效果。

## 核心思想

为屏幕上（或渲染目标上）的**每一个像素**（Pixel）额外存储一个值，这个值代表当前渲染到该像素位置的所有物体中，**距离相机（观察点）最近的物体表面点的深度值（Z值）**。这个存储深度值的内存区域就是 Z-Buffer（也叫 Depth Buffer ）


## 工作原理

1. **初始化**：
    - 为每个像素创建一个 Z-Buffer 值
    - 通常将所有像素的初始深度值设置为一个**非常大的数**（例如，远裁剪平面的距离，表示“无穷远”或“没有物体”）
2. **遍历图元**：
    - 对场景中需要渲染的所有物体（通常分解为三角形等基本图元）进行遍历。这些图元可以按**任意顺序**提交给渲染管线（不需要进行从后到前的排序）
3. **光栅化**：
    - 对于当前正在处理的图元（比如一个三角形），GPU会将其投影到屏幕上，确定它覆盖了哪些像素（这个过程称为光栅化）
4. **深度测试**：
    - 对于图元覆盖到的**每一个像素**：
        - **计算深度**：计算该图元在当前像素位置处的**深度值**（Z值）。这个值通常在0.0（近裁剪面）到1.0（远裁剪面）之间（经过透视除法后的归一化设备坐标NDC中的深度），或者在视图空间中的实际距离
        - **比较：** 将该计算出的深度值（`Z_new`）与该像素在Z-Buffer中当前存储的深度值（`Z_stored`）进行比较
        - **判断**：
            - **如果 `Z_new < Z_stored`**：说明当前图元在这个像素位置上比之前渲染的任何图元都**更靠近相机**（更浅/更小）
                - **更新**：将Z-Buffer中该像素的深度值更新为`Z_new`
                - **绘制**：计算该图元在该像素的颜色值，并更新该像素在**颜色缓冲**（Frame Buffer）中的颜色
            - **如果 `Z_new >= Z_stored`**：说明当前图元在这个像素位置上被之前渲染的某个图元**遮挡住了**（更深/更大）
                - **丢弃**：该图元在这个像素上的信息（颜色）被**丢弃**，不更新颜色缓冲
5. **重复**：
    - 对所有需要渲染的图元重复步骤3和4
6. **显示**：
    - 当所有图元都处理完毕后，颜色缓冲中存储的就是最终渲染好的、具有正确遮挡关系的2D图像，将其显示到屏幕上

## 关键优势

1. **简单高效**：算法逻辑直接，易于硬件并行化实现。现代GPU都有高度优化的Z-Buffer硬件单元
2. **处理复杂场景**：能够正确处理任意复杂的物体交叠和深度关系（如网格交叉、孔洞等），无需对物体进行全局排序（画家算法需要严格的从后到前排序，这在复杂场景中难以实现且效率低下）
3. **按像素精度**：深度测试发生在每个像素级别，精度非常高
4. **独立处理**：图元可以按任意顺序渲染（虽然顺序会影响效率，但不影响最终结果的正确性），这对流水线处理非常友好


## 局限性

1. **透明物体**：Z-Buffer本身**无法正确处理半透明物体**。因为透明物体需要混合（Blending）被它遮挡的物体的颜色，而标准的Z-Buffer测试会直接丢弃被遮挡的片元。渲染透明物体通常需要：
    - 先渲染所有不透明物体（使用Z-Buffer）
    - 对透明物体按**从后到前**的顺序排序（手动或使用OIT技术）
    - 关闭深度写入（避免遮挡后面的透明物体），开启混合模式进行渲染
2. **深度冲突**：当两个表面非常接近时，由于数值精度限制，可能出现闪烁的伪影。可以通过**深度偏移**（Depth Bias/Polygon Offset）等技术缓解
3. **内存消耗**：Z-Buffer需要额外的显存空间（通常每个像素16位、24位或32位）。现代图形API（如Vulkan, DX12）和GPU支持**深度预通道**（Depth Pre-Pass）或**Early-Z**等技术，先快速渲染一遍深度信息，避免后续为被遮挡的像素计算着色（提升性能）
4. **过度绘制**：即使一个像素最终被前面的物体完全挡住，所有覆盖到该像素的图元片元仍然会被光栅化并执行深度测试（虽然颜色计算可能被跳过）。这浪费了计算资源。**Early-Z/Early Depth Test**技术旨在光栅化后、片元着色器执行前进行深度测试，丢弃被遮挡的片元，避免不必要的着色计算。但片元着色器修改深度值会禁用此优化
5. **精度分布**：在透视投影下，Z-Buffer的精度分布不是线性的，离相机越近精度越高，越远精度越低。这有时会导致远处物体深度测试不准确
