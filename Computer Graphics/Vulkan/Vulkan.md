Vulkan 是一个跨平台的、开放的、现代化的低开销（Low-Overhead）图形和计算 API。

> [!info] 类比：更形象的比喻
> 为了更好地理解，将 Vulkan 和 OpenGL 对比：
> - **OpenGL 像是自动挡汽车**：你（开发者）告诉它“加速到100公里/小时”（绘制一个带纹理的三角形），它帮你处理所有细节（换挡、供油等）。这很容易上手，但你不知道引擎盖下具体发生了什么，也无法进行精细的微调，效率可能不是最优的。 
> - **Vulkan 像是手动挡赛车**：它给了你方向盘、离合器、换挡杆等所有控制权。你需要自己决定何时换挡、油门踩多深。**上手非常难**，需要学习很多知识，但一旦你精通了，就能把赛车的性能压榨到极致，跑出最快的速度。同时，因为中间环节少（没有自动变速箱的“翻译”损耗），动力传递更直接，这就是所谓的 **“低开销”**。

## 主要特点

1. **高性能与低开销**
	- Vulkan 极大地减少了 CPU 的负担，在 OpenGL 中，CPU 需要花费大量时间在驱动层进行状态检查和错误处理，而 Vulkan 将这部分责任交给了开发者。开发者可以预先设置好所有状态（“预编译”），运行时直接高效执行，使得 CPU 能更专注于其他游戏逻辑，从而释放 GPU 的全部潜力。
2. **跨平台**：它可以在多种操作系统上运行，包括：
	- **Windows**
	- **Linux**
	- **Android**（对移动端游戏和高端图形应用至关重要）
	- 其他平台，如：
		- **macOS**：通过 MoltenVK 转换层
		- 任天堂 Switch
3. **显式控制（Explicit Control）**：
	- 开发者几乎需要手动管理一切，包括：
        - 内存分配
        - 线程同步
        - 命令缓冲区的创建和提交
        - 渲染管线状态
    - 这带来了巨大的灵活性和优化空间，但同时也大大增加了开发的复杂度和工作量。
4. **多线程友好**：
    - OpenGL 在多线程方面非常弱，通常只有一个上下文线程能与 GPU 通信。
    - Vulkan 从设计之初就支持多线程，允许开发者并行地创建命令缓冲区，然后由主线程统一提交，能更好地利用现代多核 CPU 的优势。
5. **统一的图形和计算 API**：
    - Vulkan 不仅用于绘制图形，还将通用计算（GPGPU）作为一等公民。这意味着你可以用同一套 API 来做机器学习、物理模拟、图像处理等非图形任务，与图形渲染无缝结合。
6. **更现代的特性**：直接支持现代 GPU 的架构特性，如：
	- **并行渲染**（Multi-GPU）：可以更高效地同时使用独立显卡和集成显卡，甚至多块独立显卡。
	- **光线追踪**：Vulkan 是首个原生支持硬件光线追踪的跨平台 API（通过 `VK_KHR_ray_tracing` 扩展），这对于实现电影级的逼真光照效果至关重要。
