SetPass Call 是 Unity 游戏引擎中用于衡量渲染性能的一个关键指标。它指的是 CPU 通知 GPU 准备并使用一组新的渲染状态（特别是着色器和其属性）进行下一次绘制调用的过程。

>[!info] 渲染一个物体的基本流程
> 1. **设置渲染状态**：CPU 告诉 GPU：“嘿，接下来要画的物体，请使用这个特定的着色器、这些纹理、这些颜色和这些混合模式。” 
> 2. **发出绘制调用**：CPU 命令 GPU：“好了，状态都设置好了，现在开始画这个网格吧！”
 
这个过程在 Unity 中由一个叫做 **SetPass Call** 的指令完成，它结合了上述两个步骤，**SetPass Call 是一个非常耗费 CPU 资源的操作**，如果在一帧内发生了太多的 SetPass Call，CPU 就会忙于为 GPU 做准备工作和发送指令，而无法处理游戏逻辑（如物理、AI、脚本等），从而导致 CPU 瓶颈，最终表现为游戏帧率下降和卡顿。
