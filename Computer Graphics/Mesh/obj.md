OBJ 格式（扩展名 `.obj`）是一种通用的 **3D 模型文件格式**，最初由 Wavefront Technologies 开发，用于存储和交换 3D 几何数据。它被广泛用于 3D 建模、动画和游戏开发，支持顶点、面、纹理坐标、法线等基本几何信息。

**主要特点**

1. **纯文本格式**：可读性强，可以用文本编辑器直接查看或修改。
2. **支持多边形网格**：存储顶点（vertices）、面（faces）、边（edges）等数据。
3. **可包含附加信息**：
    - **纹理坐标（UV 映射）**：用于贴图。
    - **法线（Normals）**：定义光照和阴影。
    - **材质引用**：通过 `.mtl` 文件关联材质和贴图。
4. **不支持动画或骨骼**：仅存储静态几何体。


**文件示例**

```obj
# 注释行（以 # 开头）
v 1.0 0.0 0.0   # 顶点坐标 (x, y, z)
v 0.0 1.0 0.0
v 0.0 0.0 1.0

vt 0.5 0.5      # 纹理坐标 (u, v)
vn 0.0 0.0 1.0  # 法线向量 (x, y, z)

f 1/1/1 2/1/1 3/1/1  # 面（顶点索引/纹理索引/法线索引）
```
**术语**：
- **`v`**：顶点坐标（Vertex）。
- **`vt`**：纹理坐标（Texture Coordinate）。
- **`vn`**：顶点法线（Vertex Normal）。
- **`f`**：面（Face），定义多边形（通常为三角形或四边形）。
    - 格式示例：`f 顶点索引/纹理索引/法线索引`（索引从 1 开始）。
