如果你想更改可执行文件本身的图标（如在 Windows 桌面或 Linux 文件管理器中所见），需要使用平台特定的方法。

## Windows

1. 准备一个 `ICO`格式的图标文件。
2. 在你的项目中添加一个资源文件（例如 `app.rc`），内容如下：
```rc
IDI_ICON1 ICON "path/to/your/icon.ico"
```
3. 将该资源文件添加到项目中，编译时它会自动链接到可执行文件。
```bash
windres app.rc -o app.res
g++ main.cpp app.res -o app.exe -lglfw3 -lopengl32
```


## macOS

在 macOS 中添加应用程序图标（在 Dock 和 Finder 中显示）需要借助 macOS 的应用程序捆绑包（App Bundle）结构。

1. 准备一个 `.icns` 格式的图标文件并创建特定的应用程序目录结构。
	- 准备一个高分辨率（如 1024x1024 像素）的 PNG 图像。
	- 使用 macOS 自带的脚本创建多尺寸图标集。打开 Terminal，将你的 PNG 图标文件（例如 `my_icon.png`）拖放到 `icon.iconset` 文件夹，并执行以下命令来生成 `.icns` 文件：
```cpp
mkdir icon.iconset
sips -z 16 16   my_icon.png --out icon.iconset/icon_16x16.png
sips -z 32 32   my_icon.png --out icon.iconset/icon_16x16@2x.png
sips -z 32 32   my_icon.png --out icon.iconset/icon_32x32.png
sips -z 64 64   my_icon.png --out icon.iconset/icon_32x32@2x.png
sips -z 128 128 my_icon.png --out icon.iconset/icon_128x128.png
sips -z 256 256 my_icon.png --out icon.iconset/icon_128x128@2x.png
sips -z 256 256 my_icon.png --out icon.iconset/icon_256x256.png
sips -z 512 512 my_icon.png --out icon.iconset/icon_256x256@2x.png
sips -z 512 512 my_icon.png --out icon.iconset/icon_512x512.png
sips -z 1024 1024 my_icon.png --out icon.iconset/icon_512x512@2x.png
iconutil -c icns icon.iconset
```


2. 创建应用程序捆绑包（App Bundle）：
```
MyApp.app/
└── Contents/
    ├── Info.plist
    ├── MacOS/
    │   └── my_app_executable  # 你的编译后的可执行文件
    └── Resources/
        └── icon.icns  # 你的图标文件
```

3. 配置 `Info.plist` 文件：
```xml
<?xml version="1.0" encoding="UTF-8"?>
<!DOCTYPE plist PUBLIC "-//Apple//DTD PLIST 1.0//EN" "http://www.apple.com/DTDs/PropertyList-1.0.dtd">
<plist version="1.0">
<dict>
    <key>CFBundleName</key>
    <string>My GLFW App</string>
    <key>CFBundleIdentifier</key>
    <string>com.yourcompany.yourapp</string>
    <key>CFBundleVersion</key>
    <string>1.0.0</string>
    <key>CFBundleExecutable</key>
    <string>my_app_executable</string>
    <key>CFBundleIconFile</key>
    <string>icon.icns</string>
</dict>
</plist>
```

4. 构建步骤
```bash
# 1. 创建必要的目录
mkdir -p MyApp.app/Contents/MacOS
mkdir -p MyApp.app/Contents/Resources

# 2. 编译你的GLFW程序（确保链接了必要的库，如-lglfw）
g++ -std=c++17 main.cpp -o my_glfw_app -lglfw -framework OpenGL -framework Cocoa -framework IOKit

# 3. 将可执行文件、Info.plist和icon.icns移动到正确位置
cp my_glfw_app MyApp.app/Contents/MacOS/
cp Info.plist MyApp.app/Contents/
cp icon.icns MyApp.app/Contents/Resources/
```


## Linux

1. 通过 `.desktop` 文件定义应用程序
```ini
# 示例 .desktop 文件
[Desktop Entry]
Version=1.0
Type=Application
Name=My App
Exec=/path/to/app
Icon=my-app-icon
Categories=Graphics;
```

```bash
# 图标安装位置
/usr/share/icons/hicolor/16x16/apps/my-app-icon.png
/usr/share/icons/hicolor/32x32/apps/my-app-icon.png
/usr/share/icons/hicolor/64x64/apps/my-app-icon.png
/usr/share/applications/my-app.desktop
```



## CMake 集成

```cpp
# Windows: 编译资源文件
if(WIN32)
    find_program(WINDRES windres)
    if(WINDRES)
        add_custom_command(
            OUTPUT app.res
            COMMAND ${WINDRES} app.rc -o app.res
            DEPENDS app.rc app.ico
        )
        target_sources(myapp PRIVATE app.res)
    endif()
endif()

# macOS: 创建应用程序捆绑包
if(APPLE)
    set(MACOSX_BUNDLE_ICON_FILE AppIcon.icns)
    set_source_files_properties(${MACOSX_BUNDLE_ICON_FILE} PROPERTIES
        MACOSX_PACKAGE_LOCATION Resources)
    set_target_properties(myapp PROPERTIES
        MACOSX_BUNDLE TRUE
        MACOSX_BUNDLE_ICON_FILE ${MACOSX_BUNDLE_ICON_FILE})
endif()
```
