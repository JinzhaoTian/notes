DirectX 是一套由微软开发的专门用于处理多媒体任务，特别是游戏和视频的应用程序 API 集合。

> [!info] 简单的比喻
> 假设一个游戏（比如一个3A大作）是一支交响乐团的总乐谱，而你的电脑硬件（CPU、显卡、声卡等）是演奏的乐手。
> - **没有指挥（DirectX）**：作曲家（游戏开发者）需要懂每一种乐器的具体演奏方法，并且要直接告诉每个乐手什么时候该做什么。这极其复杂、低效，且容易出错。
> - **有了一位指挥（DirectX）**：作曲家只需要写出标准的乐谱（调用DirectX的指令）。指挥（DirectX）看懂乐谱后，会负责指挥每一个乐手（驱动硬件）如何精确地演奏。这样作曲家的工作就变得简单高效，只需要和指挥沟通即可。
> 
> DirectX 就是这个至关重要的“指挥”。


## 组成部分

DirectX 不是一个单一的程序，而是一系列技术组件的集合，每个组件负责处理不同的任务：
1. **Direct3D**：专门负责处理 3D图形渲染。
	- 几乎所有 Windows 上的3D游戏都使用 Direct3D 来告诉显卡如何绘制游戏中的模型、纹理、光影等。
	- 直接与显卡驱动对话，是游戏画面的基石。
2. **Direct2D**：专注于 2D 图形的加速渲染，用于绘制用户界面、文字、矢量图形等。
3. **DirectCompute**：一种用于通用计算的 API ，允许程序（不仅仅是游戏）利用显卡（GPU）强大的并行计算能力来处理非图形任务，比如物理模拟、视频编码、人工智能运算等。
4. **DirectSound** (已逐渐被取代)：早期用于处理音频，特别是提供 3D 音效和硬件加速。
5. **XAudio2**：现代的游戏音频 API ，取代了 DirectSound，为游戏提供了低延迟、高性能的音频处理。
6. **DirectInput**：用于处理来自游戏控制器（如手柄、摇杆、方向盘、键盘、鼠标）的输入信号。
7. **XInput**：专门为 Xbox 360 及之后型号的 Xbox 手柄优化的输入 API，现在已成为 PC 游戏手柄输入的标准。
8. **DirectPlay** (已基本淘汰)：早期用于网络多人游戏的网络通信，现在游戏大多使用自己或第三方的网络库。

## 常见版本

1. **DirectX 9**：非常经典的版本，寿命极长，至今仍有少数老游戏依赖它。
2. **DirectX 10**：随 Windows Vista 发布，引入了全新的图形管线，但仅限于 Vista 及以上系统。
3. **DirectX 11**：一个非常成功和稳定的版本，在 DX10 的基础上大幅改进，提供了多线程渲染、曲面细分等强大功能，是多年来的主流选择。
4. **DirectX 12**：随 Windows 10 发布。它的最大特点是提供了**底层硬件访问**，将更多的控制权交给了开发者。这意味着高手可以更精细地优化游戏，榨干硬件的最后一丝性能，但开发难度也显著增加。
5. **DirectX 12 Ultimate**：这是 DX12 的超级版，统一了 PC（Windows 10/11）和 Xbox Series X/S 的图形功能，包含了光线追踪 tier 1.1、可变速率着色（VRS）、网格着色器等最新图形技术，是当前的最新标准。
