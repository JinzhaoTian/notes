QPS（Queries Per Second）是指系统**每秒能处理的查询或请求数量**，是衡量系统性能的核心指标之一，常用于评估 Web 服务器、数据库、缓存等服务的吞吐量。

```
QPS = 成功处理的请求数 / 统计时间（秒）
```

#### **典型 QPS 范围**

| 系统类型        | 典型 QPS 范围 | 备注                |
| ----------- | --------- | ----------------- |
| 静态网站（CDN）   | 10万+      | 无动态计算，直接返回文件      |
| Nginx（反向代理） | 5万~50万    | 取决于配置和硬件          |
| Redis（单节点）  | 10万~20万   | 简单 GET/SET 操作     |
| MySQL（单机）   | 1千~1万     | 简单查询，复杂 SQL 会大幅下降 |
| 秒杀系统（优化后）   | 10万~100万+ | 需缓存+异步+分布式架构      |
