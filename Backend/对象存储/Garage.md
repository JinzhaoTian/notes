Garage 是一款轻量级、开源的分布式对象存储服务，它最大的特点是兼容 [Amazon S3 API](../服务商/Amazon%20S3.md#Amazon%20S3%20API) 协议，这意味着你可以像使用 AWS S3 一样来使用 Garage，而数据完全由你自己掌控。

- 官网：[Garage](https://garagehq.deuxfleurs.fr/)
- 仓库：[Deuxfleurs/garage](https://git.deuxfleurs.fr/Deuxfleurs/garage)


## 核心特性

1. **核心定位**：专为中小规模自托管场景设计，适用于社区、小型组织或个人。
2. **高可用与容灾**：数据可在不同物理位置（如不同机房、城市）的节点间复制，即使部分服务器离线，服务仍可保持可用。
3. **设计目标**：追求轻量、简单、易操作，对硬件要求不高，并能高度容忍机器和网络故障。
4. **开源协议**：采用 AGPL v3 开源协议，可免费使用和修改。
5. **明确非目标**：并非追求极致性能，也非 100% 完整实现 S3 API。其复制模式采用多副本，而非纠删码。

## 技术架构亮点

1. **数据分布算法**：Garage 采用经过优化的算法来分配数据分区，旨在**最大化集群的有效存储容量**，并在节点变动时**最小化数据迁移量**。
2. **灵活的部署策略**：你可以设置**副本数量**（通常为3）和**区域分散因子**，确保数据副本分布在足够多的、不同的故障域（如不同机房）中，以抵御区域性故障。
3. **双域名设计**：在一些集成场景（如连接 Pixelfed）中，Garage 采用 API 端点和**内容分发端点**分离的架构，有利于管理流量和用户访问流量的分离与优化。
