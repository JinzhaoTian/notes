Ceph 是一个开源的、统一的、分布式存储系统，它在单一体系统集群中提供了对象存储、块存储和文件存储三种服务，具有高度可扩展性、可靠性和高性能。

Ceph 架构复杂，运维门槛高，适合有专业存储/运维团队的中大型企业，不太适合单机或小规模存储、对单次请求延迟极其敏感的业务、高频率小文件读写以及对运维简单性要求很高的中小团队。

## 核心特性

1. **统一的存储系统**：这是 Ceph 最大的亮点。一套 Ceph 集群可以同时提供：
    - **对象存储（Object Storage）**： 通过其原生的对象网关（RGW，兼容 Amazon S3 和 OpenStack Swift API）提供，适合存储图片、视频、备份等非结构化数据。
    - **块存储（Block Storage）**： 通过 RADOS 块设备（RBD）提供，可以为虚拟机（如 OpenStack，Proxmox，Kubernetes）或物理服务器提供像硬盘一样挂载的、可弹性伸缩的块设备，性能优异。
    - **文件系统存储（File Storage）**： 通过 Ceph 文件系统（CephFS）提供，提供一个符合 POSIX 标准的共享文件系统，可以被多个客户端同时挂载使用。
2. **无中心架构**：Ceph 没有传统的单点“元数据服务器”（除了 CephFS 需要可扩展的 MDS 集群来管理文件目录结构）。其数据寻址依赖于一个名为 **CRUSH** 的智能算法。
3. **高度可扩展与自愈**：采用“去中心化”的设计，理论上可以从一个节点轻松扩展到上千个节点，容量可达 EB 级别。数据自动分布在所有节点上，当有磁盘或节点故障时，集群能自动检测、迁移和恢复数据副本，确保高可用性。
4. **基于软件定义**：Ceph 完全运行在标准商用服务器和硬盘上，无需昂贵的专用硬件，降低了成本。
