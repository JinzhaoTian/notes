CDN（内容分发网络，Content Delivery Network）是一种分布式服务器网络，通过将内容缓存到全球各地的边缘节点，使用户能够从最近的服务器快速获取数据，从而提升网站或应用的访问速度、稳定性和安全性。

## 核心原理

1. **边缘节点（Edge Server）**
	- CDN在全球多个地理位置部署服务器节点，存储静态内容（如图片、视频、CSS/JS 文件等）的副本。用户访问时，自动连接到最近的节点，减少延迟。
2. **负载均衡**
	- 通过智能 DNS 或 Anycast 技术，将用户请求分配到最优节点，避免单一服务器过载。
3. **缓存机制**
	- 节点会缓存源站内容，减少直接回源（Origin Server）的频率，降低源站压力。


## 主要功能

- **加速内容传输**：缩短用户与服务器的物理距离，提升加载速度。
- **减轻源站负载**：通过缓存分散流量，保护源站免受高并发冲击。
- **防御网络攻击**：提供 DDoS 防护、WAF（ Web 应用防火墙）等安全功能。
- **支持动态内容**：部分 CDN 支持动态内容（如 API 请求）的优化传输。
- **节省带宽成本**：减少源站带宽消耗，尤其对大流量网站（如视频平台）至关重要。



## 应用场景

1. **静态资源分发**
	- 加速网页中的图片、样式表、JavaScript 文件等。
2. **视频/直播流媒体**
	- 降低缓冲时间，支持高清视频流畅播放。
3. **软件/游戏下载**
	- 大型文件分发给全球用户。
4. **电商促销**
	- 应对突发流量（如“双11”）。
5. **全球化业务**
	 - 让跨国访问更快速。




## 工作流程

1. 用户请求 `example.com/image.jpg`。
2. DNS 解析将请求指向最近的 CDN 节点。
3. 若节点有缓存（**缓存命中**），直接返回内容；若无（**缓存未命中**），CDN 从源站拉取并缓存。
4. 用户从边缘节点快速获取数据。

## 使用示例

1. **注册并登录 CDN 控制台**（如阿里云CDN、Cloudflare）
2. **添加加速域名**：
	- 输入需要加速的域名（如 `cdn.example.com`）
	- 选择加速区域（全球、仅国内、仅海外等）
3. **配置源站**：
	- 设置源站 IP 或域名（如 `origin.example.com`）
4. **设置缓存策略**：
	- 定义哪些文件需要缓存（如 `.jpg, .css, .js`）
	- 设置缓存时间（TTL）
5. **配置HTTPS**（可选）：
	- 上传 SSL 证书或使用 CDN 提供的免费证书（如 Cloudflare ）
6. **DNS解析**：
	- 在域名 DNS 管理后台，添加 CNAME 记录，指向 CDN 服务商提供的地址（如 `xxxx.cdnprovider.com`）
7. **测试CDN是否生效**：
	- 使用 `ping` 或 `curl` 检查是否解析到 CDN 节点
	- 访问网站，查看资源是否从 CDN 加载
