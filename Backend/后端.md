后端开发（Backend Development）是软件开发中专注于服务器端逻辑、数据库交互和系统架构的部分，与[前端开发](../Frontend/前端.md)（用户界面和交互）相对应。

后端开发的核心是处理数据存储、业务逻辑、安全性和性能，确保前端应用能高效、稳定地运行。

## 开发流程

1. 选择合适的技术路线：比如对于小型的项目，可以选择前后端技术栈一致的技术路线，比如TypeScript + React + MUI + Express + Sequenlize 的全栈开发形式
2. 数据库：
	1. 在开发时要记录建库 SQL 脚本，保存下来，每次对表结构进行更新都要记录修改的 SQL 脚本。
	2. 部署时，可以导出表结构的 SQL 脚本。
	3. 开发时，要选用合适的 ORM ，不建议在开发时使用 ORM 建库。
