Gateway HA（High Availability，高可用性）是指通过部署冗余网关实例、消除单点故障，来确保网络或 API 入口在面对故障时仍能提供不间断服务的能力，其核心目标是最大限度地减少停机时间，保证网络服务的连续性和稳定性。

## 核心实现

实现 Gateway HA 主要通过以下几种技术：

1. **集群部署与负载均衡**：部署多个网关实例构成集群，并在其前方部署负载均衡器（如 Nginx、LVS 或云服务商的 LB）。负载均衡器将流量分发到各个健康的网关实例上，当某个实例故障时，流量会自动切换到其他实例。
2. **主备（Active-Standby）模式**：集群中一个实例作为主节点（Active）处理所有流量，一个或多个实例作为备用节点（Standby）实时监控主节点状态。主备之间通过**心跳检测**或**健康检查**来维持联系。一旦主节点故障，备用节点会立即**接管（Failover）** 其工作。
3. **双活（Active-Active）模式**：集群中所有网关实例同时处理流量，负载均衡器将请求分发到各个实例。这种模式不仅提供了高可用性，还能水平扩展，提升整体处理能力。
4. **状态共享**：对于需要保持会话（Session）或状态的网关，必须将会话信息存储在外部的共享存储中（如 Redis ），而不是保存在单个网关实例的内存里。这样才能确保无论请求被分发到哪个网关实例，都能获取到正确的会话信息。
