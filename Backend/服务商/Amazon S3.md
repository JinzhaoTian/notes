Amazon S3（Simple Storage Service） 是亚马逊 AWS 提供的对象存储服务，是全球最流行、最成熟的云存储服务之一。

## 核心特性

1. **对象存储模式**
	- 以“对象”（文件+元数据）的形式存储数据
	- 通过唯一的 URL 或 Key 访问
	- 与传统的文件系统（目录结构）不同，但支持“文件夹”概念
2. **存储类别（分层存储）**
	- **标准存储**：频繁访问的数据
	- **智能分层**：自动优化存储成本
	- **低频访问**：不常访问但需快速检索的数据
	- **归档存储**：长期保存，检索时间较长（如 Glacier）
3. **核心概念**
	- **Bucket（桶）**：存储对象的容器（名称全球唯一）
	- **Object（对象）**：实际存储的文件
	- **Key（键）**：对象的唯一标识符（类似文件路径）
	- **Region（区域）**：数据存储的地理位置



## S3 兼容

非亚马逊 AWS 的对象存储服务，如果实现了与 Amazon S3 相同或相似的编程接口（API），就可以像使用真正的 Amazon S3 一样，用同样的代码、工具或 SDK 来操作这些存储服务。

### 核心含义

1. **标准与开源**：Amazon S3 的 API 因简洁实用，已成为业界事实上的标准。虽然亚马逊未正式开源其代码，但其 API 规范已被广泛接受和模仿。
2. **API 层面一致**：S3 兼容的核心是接口兼容，而非底层技术或服务完全对等。只要服务商实现了与 S3 一致的 API 调用方式，应用就能无缝对接。
3. **提供技术灵活性**：兼容性的主要目的是让开发者和企业能够复用已有的 S3 技术栈（如工具链、SDK），轻松将应用迁移到不同的云平台或私有环境，从而避免被单一云厂商“锁定”。


### 并非100%相同

声称“S3兼容”的服务**不一定实现了S3的全部功能**，不同服务商的兼容程度有差异。


## Amazon S3 API

Amazon S3 API 是一个基于 HTTP / REST 的接口，主要使用标准的 HTTP 方法（如 GET、PUT、DELETE）来管理存储桶（Bucket）和对象（Object）。

| 操作分类                        | 典型 API 操作 (HTTP方法)                                                                                                           | 核心作用                     |
| --------------------------- | ---------------------------------------------------------------------------------------------------------------------------- | ------------------------ |
| **存储桶 (Bucket) 操作**         | `PUT /{bucket-name}` (创建) <br>`GET /` (列举)<br>`HEAD /{bucket-name}` (检查)<br>`DELETE /{bucket-name}` (删除)                     | 创建、列举、查询信息或删除存储空间容器。     |
| **对象 (Object) 操作**          | `PUT /{bucket}/{key}` (上传)<br>`GET /{bucket}/{key}` (下载) <br>`HEAD /{bucket}/{key}` (获取元数据)<br>`DELETE /{bucket}/{key}` (删除) | 对象（文件）的上传、下载、删除以及元数据查询。  |
| **分块上传 (Multipart Upload)** | `POST /{bucket}/{key}?uploads` (初始化)<br>`PUT /...?partNumber...` (上传块)<br>`POST /...?uploadId...` (完成合并)                     | 用于**大文件**的可靠、高效上传。       |
| **高级管理操作**                  | `PUT/GET Bucket Lifecycle` (生命周期)<br>`PUT/GET Bucket ACL` (权限控制)<br>`CopyObject`/`UploadPartCopy` (复制)                       | 实现自动归档删除、权限设置、对象复制等高级功能。 |
