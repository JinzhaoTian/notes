
## 图的遍历

图的表示有两种：邻接表和邻接矩阵，用邻接矩阵一般会爆内存，所以可以使用邻接表。

### 深度优先搜索

1. 邻接矩阵：

邻接矩阵可以用一个二维数组来表示，简单点就可以表示成`vector<vector<``**int**``>>`。其中要注意的是无向图是对称的，所以边的关系要存两次`G[a][b] = G[b][a] = 1`。

```
void dfs(vector<vector<int>>& G, vector<bool>& visited, int i) {
    visited[i] = true;
    for (int j = 0; j < G.size(); ++j) {
        if (!visited[j] && G[i][j] == 1)
            dfs(G, visited, j);
    }
}

        if (!visited[i]) {

}

```

2. 邻接表：

邻接表可以表示成n个vector数组，即`vector<int> G[]`，注意和圆括号的区别。对于无向图的处理，需要存两次：`G[a].push_back(b); G[b].push_back(a);`

```
void dfs(vector<vector<int>>& G, vector<bool>& visited, int i) {
    visited[i] = true;
    for (int j = 0; j < G[i].size(); ++j) {
        if (!visited[j] && G[i][j] == 1)
            dfs(G, visited, j);
    }
}

void DFSTraverse(vector<int>& G[], int n) {
    vector<bool> visited(n, false);
    for (int i = 0; i < n; ++i) {
        if (!visited[i]) {
            dfs(G, visited, i);
        }
    }
}
```

## 拓扑排序

拓扑排序是将**有向无环图** G 的所有顶点排成一个线性序列，使得对图 G 中的任意两个顶点 u、v，如果存在边 u -> v，那么在序列中 u 一定在 v 前面，这个序列又被称为拓扑序列。

拓扑排序的应用：

1. 判断有向无环图

```
bool TopSort(vector<vector<int>> &G, int n, vector<int> &inDegree) {
    int num = 0;
    queue<int> que;
    // vector<int> ans;            // 如需输出
    for (int i = 0; i < n; ++i)
        if (inDegree[i] == 0)
            que.push(i);
    while (!que.empty()) {
        int u = que.front();
        // ans.push_back(u); 
        que.pop();
        for (int i = 0; i < G[u].size(); ++i) {
            int v = G[u][i];
            inDegree[v]--;
            if (inDegree[v] == 0)
                que.push(v);
        }
        G[u].clear();
        num++;
    }
    return num == n;
}
```
